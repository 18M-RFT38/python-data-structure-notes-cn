# Python 基础与数据结构笔记

给零基础初学者的 Python 学习笔记。从变量、控制流程和函数开始，逐步学习如何用 Python 写出栈、队列、查找和排序等数据结构与算法示例。

建议按编号阅读，边看边运行示例。已经熟悉 Python 基础的读者可以直接进入数据结构与算法部分。
