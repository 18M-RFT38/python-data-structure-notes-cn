# 基本概念
在计算机运行过程中，“下一条语句”决定了计算机是能够自动调整、自动反复操作，还是只能像计算器那样一步接着一步计算。
这种决定“下一条语句”的机制，在程序设计语言中称作“控制流程”。
## 三种结构
顺序结构：按照语句队列前后顺序来确定下一条将要执行的语句。
条件分支结构：根据当前情况来选择下一条语句的位置。
循环结构：周而复始地执行一系列语句。
![[file-20261006102153107.png|356]]
几乎所有的程序设计语言都提供了这三种控制流程。

简单类型和容器类型之间的关系，就像玻璃珠与盒
子、苹果与口袋。

容器类型是结构，将实体对象进行各种组织和编排。[[3.Python的概览#==容器==类型用来**组织这些值**|容器类型用来组织这些值]]

# 条件分支语句
条件分支让程序有了判断力。
根据计算机内部情况（如变量值），来决定下一步做
什么，这样的控制流程，就称为条件分支。
本质：根据预设条件来控制下一步该运行哪段语句
## 基本要素
1：预设的判断条件。
2：达成条件后执行的语句。
![[file-20261006103529144.png|244]]
## 扩展要素
1：当条件不满足时执行的语句。
2：多条件时哪个满足执行哪个的条件。
![[file-20261006103644027.png|339]]
## 实现
`if` `<逻辑表达式>` `:` 
    `<语句块1>`
    …….
else:
	`<语句块2>`
if和else都是 **“保留字”** 。
	保留字（reserved word），又称关键字，指在高级语言中已定义过的字。程序员**不可**将其作为**变量名、过程名或函数名**使用。
“逻辑表达式”是指所有运算的结果为逻辑类型(True或False）的表达式。
“语句块”就是条件满足后执行的一组语句。
冒号表示语句层次。
语句块缩进。

各种类型中某些值会自动被转换为False，其它值则是True。
>[!Tips]
None。数值型0,0.0。空字符串""。空容器[],(),{},set()
为False。

# 循环结构
## 基本概念
让计算机执行冗长单调的重复性任务。
根据需要对一系列操作进行设定次数或者设定条件的
重复，这样的控制流程，就称作循环结构。
作用：能持续对大量数据进行处理。或者在长时间里对一些未知状况进行连续监测循环结构。
## 基本要素
循环前提和执行语句。
在执行这组语句之前，计算机会检查**循环前提**是否存在，只要存在，就会反复执行这组语句，直到**循环前提**消失。
![[file-20261006110515049.png|276]]
### 循环前提的类型
从**某个容器或者潜在的数据集**中逐一获取数据项，什么时候取不到数据项了，循环的前提就消失。^2c6fe2

只要**逻辑表达式计算结果为真（True）**，循环的前提就存在，什么时候逻辑表达式计算结果（False）循环的前提就消失了。 ^13e45b
### 与条件分支结构的区别
循环结构会多次检查循环前提。即循环结构会多次的执行循环前提的语句。

## 扩展要素
当循环前提消失，停止执行这组语句的时候，执行一次另一组语句。
![[file-20261006111357844.png|200]]

## 条件循环
循环前提是。[[11.控制流程#^13e45b|逻辑表达式]]。
用while循环语法实现。
```python
while <逻辑表达式>:
    <语句块>
    break #跳出循环，会直接结束整个while循环
    continue #略过余下循环语句，重新执行上方的循环前提语句。
    <语句块>
else：#条件不满足退出循环，则执行
    <语句块>
```
在python中，while和else都是保留字。
逻辑表达式：指所有运算的结果为逻辑类型(True或False）的表达式。
语句块：一组语句。

![[file-20261006112535881.png|215]]
## 嵌套循环
双重甚至多重的循环。
>[!Example]
![[file-20261006112636469.png]]
3x+1问题：任何一个正整数。如果是一个偶数，就把它除以2。如果是一个奇数，就让它乘以3再加1。那么任何一个正整数在这种操作下，最后形成了一个序列，最终都会掉到4→2→1 这样的循环陷阱里，最终等于1。
 
 中断程序运行：ctrl+c
### 嵌套循环中的跳出和继续
continue语句和break语句
![[file-20261006143921568.png|308]]
都只能在循环内部使用。
均作用于离它们最近的一层循环。
break是跳出当前循环并结束本层循环。
continue是略过余下循环语句并接着下一次循环。

## 迭代循环
循环前提是[[11.控制流程#^2c6fe2|容器或数据集]]。
>[!Tips]
>1. 迭代的动作：一轮一轮循环访问，**一次拿一个元素**。
>2. 能被迭代的东西叫**可迭代对象**：字符串、列表这些都属于。
>3. 负责逐个产出元素的那个东西，叫负责逐个产出元素的那个东西，叫**迭代器**。

用for循环语法实现。
```python
for <循环变量> in <可迭代对象> :
	<语句块1>
	break #跳出循环
	continue#略过余下循环语句
else ：#迭代完毕，则执行
	<语句块2>
```
for、in和else都是“保留字”。
### 可迭代对象
可迭代对象，表示从这个数据对象中可以逐个取出数据项赋值给“循环变量”。
>[!note]
>可迭代对象有很多类型，如字符串、列表、元组、字典、集合等，也可以有后面提到的生成器、迭代器等。

### range（）函数
range(终点)
返回一个从0开始到终点的数列。

range（起点,终点)
从0以外的任何整数开始构建数列。

range(起点,终点,步长)
修改数列的步长，通过将**步长设置为负数**能够实现反向数列，相应地，终点要大于起点。

range构建的数列，包含起点整数，而不包含终点整数（左闭右开）。

range类型的对象，可以直接当作序列。
可以转换成list或者tuple等容器类型。
