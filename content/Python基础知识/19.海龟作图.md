**turtle module** 
Python内置，随时可用
其意象为模拟海龟在沙滩上爬行而留下的足迹
# 海龟作图的基本方法
turtle模块
内置模块，从LOGO语言借鉴而来
属性：位置、方向、画笔（颜色、线条宽度等）
指令
画笔运动命令：前/后移动、左/右转动、作画速度等
画笔控制命令：抬起/放下、画笔宽度、画笔颜色、填充颜色等
>[!notes] 基础命令
>turtle.Pen() / turtle.Turtle() 类（构造器）：创建海龟画笔对象
>turtle.done() 函数：结束作图
>turtle.Screen() 函数（返回窗口单例对象）：创建窗口
>画笔运动命令（移动、转向——均为海龟画笔对象 t 的方法）
>t.forward(n) / t.fd(n) 方法：向前移动 n 像素
>t.backward(n) / t.bk(n) 方法：向后移动 n 像素
>t.left(角度) 方法：向左转指定角度
>t.right(角度) / t.rt(角度) 方法：向右转指定角度
>画笔控制命令（线条样式——均为海龟画笔对象 t 的方法）
>t.pencolor("blue") 方法：设置画笔颜色
>t.pensize(5) 方法：设置线条粗细
>t.penup() / t.pu() 方法：抬笔，移动不画线
>t.pendown() / t.pd() 方法：落笔，移动会画线
>t.fillcolor("red") 方法：设置填充颜色
>t.begin_fill() 方法：开始填充
>t.end_fill() 方法：结束填充
# 常见图形
## 画三角形
```python
import turtle  # 导入turtle模块
p = turtle.Pen()  # 创建一支画笔（海龟）
p.pencolor('blue')  # 设置画笔颜色为黑色
p.pensize(5)  # 设置画笔的粗细为5
p.forward(100)  # 最初画笔（海龟）朝向正右方，向前画长度为100的直线
p.left(120)  # 画笔（海龟）向左转120度
p.forward(100)  # 向前画长度为100的直线
p.left(120)  # 画笔（海龟）向左转120度
p.forward(100)  # 向前画长度为100的直线
p.left(120)  # 画笔（海龟）向左转120度
```

# 调用递归画树
分形树代码
```python
# 导入turtle海龟绘图模块
import turtle

# 定义递归画树函数
# branchLen：当前枝干长度；t：海龟画笔对象
def tree(branchLen,t):
    # 递归终止条件：枝干长度大于5才继续画，否则直接返回（基线条件，防止无限递归）
    if branchLen > 5:
        # 向前画主干，长度branchLen（调用forward方法）
        t.forward(branchLen)
        # 海龟向右转20°，准备画右侧子树枝（调用right方法）
        t.right(20)
        # 递归调用：画右子树，枝干长度减少15
        tree(branchLen-15,t)
        # 海龟向左转40°（相对于上一步，相当于向左回摆20°，朝向左侧分支方向，调用left方法）
        t.left(40)
        # 递归调用：画左子树，枝干长度减少15
        tree(branchLen-15,t)
        # 海龟向右转20°，恢复到主干原来的角度（调用right方法）
        t.right(20)
        # 画笔后退，回到当前枝干起点（回溯，保证位置正确返回上层递归，调用backward方法）
        t.backward(branchLen)

# 主函数，初始化画布与画笔
def main():
    # 调用Turtle类创建海龟画笔对象t
    t = turtle.Turtle()
    # 调用Screen函数创建画布窗口对象
    myWin = turtle.Screen()
    # 海龟向左旋转90度，让画笔朝上（原本默认朝右），用来画向上生长的树（调用left方法）
    t.left(90)
    # 抬笔，移动时不画线（调用up方法）
    t.up()
    # 向后移动100像素，把树根下移，给上方树木留出空间（调用backward方法）
    t.backward(100)
    # 落笔，恢复绘图（调用down方法）
    t.down()
    # 设置画笔颜色为绿色（调用color方法）
    t.color("green")
    # 调用tree函数，画主干初始长度75的分形树
    tree(75,t)
    # 点击窗口时才关闭画布（调用窗口对象myWin的exitonclick方法）
    myWin.exitonclick()

# 执行主函数，启动绘图
main()
```
![[file-20261018112709246.png|270]]
>[!attention] 注意海龟作图的次序
>先画树干，再画右树枝，最后画左树枝：与递归函数里的流程一致
>1.  **递归思想** ：一棵树 = 一段主干 + 右小树 + 左小树；小树继续拆分成更小的树枝，直到枝干长度≤5 停止。
>2.  **回溯关键点** ：画完左右分支后，backward退回到枝干起点、角度复原，上层递归才能继续绘图。
>3.  **绘图顺序** ：主干 → 右分支递归 → 左分支递归 → 返回起点。
