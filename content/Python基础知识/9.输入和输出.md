# 来料输入 input（）函数
用户给程序提供什么值是无法预测的。
因此在编写程序时，不知道变量的具体值。
解释器最终要指怎么知道变量的值呢？所以就有了input（）函数。

**input(prompt)**
可选参数prompt：显示一段提示信息prompt，等待用户输入。prompt是给用户的提示，用于人和人之间的交互。
input（）函数的**返回值是字符串**。
如果想要别的类型。使用转换函数。
![[file-20261004170637837.png]]
```python
#输入示例
>>> yname = input ("Please input your name")
**Please input your name** Tom Hanks
>>> yname
'Tom Hanks'
```
# 产品展示 print（）函数
打印各变量的值输出。

print(sep,end,file,…)
## 参数
sep：表示变量之间用什么字符串隔开，缺省是空格。（separate）
end：表示以这个字符串结束，缺省为换行。比如想要print在一行，可以改为空串“ ”。
file：指定了文本将要发送到的文件、标准流或者其他类似文件的对象。缺省是sys.stdout
```python
#输出示例
>>> print (1, 23, 'Hello')#函数里用逗号隔开
1 23 Hello#输出默认用空格隔开
>>> print (1, 23, 'Hello', end='')
1 23 Hello#后面不再有换行
>>> print (1, 23, 'Hello', sep=',')
1,23,Hello#输出改用逗号隔开
```
# 格式化字符串
print（）函数默认把对象打印到stdout流，并且添加了一些自动的格式化。（可以自定义分隔符和行末符）
>[!Tips]
stdout（标准输出流）：程序向外输出**正常信息**的通道，默认就是输出到你的终端 / 屏幕。
## 基本格式
在字符串中占位：“%d %s %f”
后面用一个元组一一对应每一个%？：%（v1，v2）
```python
#格式化字符串示例
>>> '%d %s' % (23, 'Hello')
'23 Hello'
>>> '%d' % (23,)#单个元素后面也要加字符
'23'
>>> '(%4d):K:%s' % (12, 'Hello')#%4d表示这个输出的数值类型要占4个字符宽度，默认空格补位
'(  12):K:Hello'
>>> '(%04d):K:%10s' % (12, 'Hello')#%04d表示这个数值占4个字符宽度，而且用0来补位，不用空格补位（加入前导0的操作）
'(0012):K:     Hello'
```
## 现在的常用用法
str.format()方法,了解即可。
`"{d} {s}".format(a,b)`
f-string法【首选，最推荐】
`（f"{变量}"）`
```python
>>> f'({12:4d}):K:{"Hello"}'#：4d表示占4个字符宽度
'(  12):K:Hello'

>>> f'({12:04d}):K:{"Hello":10s}'#：04d表示占4个字符宽度，用0补位
'(0012):K:     Hello'
#通用模板：f'{变量:格式说明}'
```
