# 搜索引擎蜘蛛
爬虫是按照一定规则，自动地提取并保存网页中信息的程序。
就想蜘蛛沿着网络抓取猎物：通过一个节点之后，顺着该节点的连线继续爬行到下一个节点，最终爬完整个网络的全部节点。
通过向网站发起请求获取资源，提取其中有用的信息。

# requests库
## Python里的HTTP库
Python实现的一个简单易用的HTTP库。
支持HTTP持久连接和连接池、SSL证书验证、cookies处理、流式上传等。
向服务器发起请求并获取响应，完成访问网页的步骤。
是简洁、容易理解，是最友好的网络爬虫库。

## http请求类型
调用以下 `requests` 模块函数发起请求，**返回的是一个 `response` 对象** [[20.对象是什么？#对象的基本概念|对象]]：

`requests.request()` 函数：构造一个请求，支撑以下各方法的基础函数
`requests.get()` 函数：获取HTML网页（对应HTTP的GET请求）
`requests.head()` 函数：获取HTML网页头信息（对应HTTP的HEAD请求）
`requests.post()` 函数：提交POST请求（常用于提交表单或上传数据）
`requests.put()` 函数：提交PUT请求
`requests.patch()` 函数：提交局部修改请求
`requests.delete()` 函数：提交删除请求
`requests.options()` 函数：获取http请求

## response对象
包含服务器返回的所有信息，例如状态码、编码形式、文本内容等；也包含请求的 `request` 信息。

`.status_code` 属性：HTTP请求的返回状态（如 `200` 表示连接成功，`404` 表示失败）
`.text` 属性：HTTP响应内容的字符串形式（即页面对应的HTML源码字符串）
`.content` 属性：HTTP响应内容的二进制形式（常用于爬取图片、音视频等非文本文件）
`.encoding` 属性：（从HTTP header中）分析响应内容的编码方式
`.apparent_encoding` 属性：（从内容中）分析响应内容的编码方式（备选编码，更加准确）

### 代码演示：获取网页与处理编码
```python
# 导入 requests 模块
>>> import requests
# 调用 requests 模块的 get() 函数向百度发起请求，返回 Response 实例对象 r
>>> r = requests.get("[http://www.baidu.com](http://www.baidu.com)")
# 访问 r 对象的 status_code 属性，查看 HTTP 响应状态码（200 代表请求成功）
>>> r.status_code
200
# 访问 r 对象的 text 属性，获取响应内容的字符串形式（HTML 源码）
>>> r.text
```
![[file-20261025185129367.png]]
>[!notes] 
>1. **HTML 文档特征**：`r.text` 属性返回的是一整串包含 `<!DOCTYPE html>…` 标签的字符串。
>2. **注意末尾 `<title>` 标签里的乱码**：仔细看截图中 `<title>ç\x99¾å°…` 这一段——原本应该是中文“百度一下，你就知道”，但因为此时默认的 `.encoding` 属性值是 `'ISO-8859-1'`（不支持中文），导致 `.text` 属性在解码网页时出现了**中文乱码**。

```python
# 访问 r 对象的 encoding 属性：查看从 HTTP 响应头（header）中猜测的编码方式
>>> r.encoding
'ISO-8859-1'
# 访问 r 对象的 apparent_encoding 属性：查看从网页具体内容中分析出的真实编码方式
>>> r.apparent_encoding
'utf-8'
# 修改 r 对象的 encoding 属性，将其重新赋值为正确的 "utf-8" 编码
>>> r.encoding = "utf-8"
# 再次访问 r 对象的 text 属性，此时使用 utf-8 重新解码响应内容
>>> r.text
```
![[file-20261025185310226.png]]
>[!notes]
>1. **乱码修复对比**：将`r.encoding` 属性赋值为 `"utf-8"` 后，此时 `<title>百度一下，你就知道</title>` 已经能够正常显示中文！
>2. **爬虫解决中文乱码的标准套路**：当发现 `r.text` 中文乱码时，直接写 `r.encoding = r.apparent_encoding`（将从内容分析出的真实编码赋值给对象的 `encoding` 属性），即可解决绝大多数网页乱码问题。

## 定制请求头与设置代理
### 定制请求头
`requests` 的请求接口（函数）有一个名为 `headers` 的关键字参数，向它传递一个字典来完成请求头定制。
（常用于伪装浏览器 `User-Agent` 绕过基础反爬）

### 设置代理
一些网站设置了同一IP访问次数的限制，可以在发送请求时指定 `proxies` 关键字参数来替换代理，解决这一问题。
### 案例代码
```python
# 定义代理 IP 字典 proxies，分别指定 http 和 https 协议对应的代理服务器地址与端口
proxies = {
    "http": "[http://10.10.10.10:1010](http://10.10.10.10:1010)",
    "https": "[http://10.11.10.14:1011](http://10.11.10.14:1011)",
}
# 调用 requests 模块的 get() 函数，通过关键字参数 proxies 传入代理字典
r = requests.get(url, proxies = proxies)
```

# Beautiful Soup
## 页面解析器
使用 `requests` 库下载了网页并转换成字符串后，需要一个解析器来处理HTML和XML，解析页面格式，提取有用的信息。

在代码中通常通过 `from bs4 import BeautifulSoup` 导入，并调用 `BeautifulSoup()` 类（构造器）创建解析对象
[[21.类的定义与调用|类的定义与调用]]。

## 解析器类型
**python标准库**：调用 `BeautifulSoup(markup, "html.parser")` 类（构造器）
优势：Python的内置标准库，文档容错能力强。

**lxml HTML解析器**：调用 `BeautifulSoup(markup, "lxml")` 类（构造器）
优势：速度快，文档容错能力强（需额外安装 `lxml` 库）。

**lxml XML解析器**：调用 `BeautifulSoup(markup, ["lxml-xml"])` 或 `BeautifulSoup(markup, "xml")` 类（构造器）
优势：速度快，唯一支持XML的解析器。

**Html5lib**：调用 `BeautifulSoup(markup, "html5lib")` 类（构造器）
优势：最好的容错性，以浏览器的方式解析文档，生成HTML5格式的文档。

## 搜索方法
以下均为 `BeautifulSoup` 解析对象（或 `Tag` 标签对象）的实例方法：

`find_all(name, attrs, recursive, string, **kwargs)` 方法
返回文档中符合条件的所有 `tag`（标签对象），返回结果是一个 **列表**。

`find(name, attrs, recursive, string, **kwargs)` 方法
相当于在 `find_all()` 方法中设置关键字参数 `limit = 1`，只返回符合条件的 **第一个结果**（单个 `Tag` 对象，若未找到则返回 `None`）。

`name` 参数：对标签名称的检索字符串（如传入 `'a'` 查找所有超链接 `<a>` 标签，或传入 `'div'` 查找块级标签）。
`attrs` 参数：对标签属性值的检索字符串或字典（如匹配 `id`、`class` 等HTML属性）。
`recursive` 参数：布尔值，设置是否对子孙节点全部检索，默认为 `True`（若设为 `False` 则仅检索直接子节点）。
`string` 参数：检索标签 `<>…</>` 中间夹着的非属性文本字符串内容。

## 第二步：爬取页面
通过 `requests` 库向目标站点发送请求，若对方服务器正常响应，能够收到一个 `response` 对象，它包含了服务器返回的所有信息。

```python
# 导入 requests 模块
import requests
# 定义目标网址字符串变量 url（腾讯新闻首页）
url = "[http://news.qq.com/](http://news.qq.com/)"
# 调用 requests.get() 函数发送请求，传入关键字参数 timeout = 30（设置超时时间为30秒，防止程序死等），返回 Response 对象 r
r = requests.get(url, timeout = 30)
# 访问 r 对象的 text 属性获取网页 HTML 字符串，并调用内置函数 print() 打印输出
print(r.text)
```

## 第三步：解析页面
针对不同类型的数据，采取不同的解析与处理方式：
HTML代码：使用网页解析器（此处使用 `bs4` 进行解析）
Json数据：使用 `json` 模块，转换成 Json 对象
二进制数据：以 `wb`（二进制写模式）形式写入文件 [[17.文件文本读写#文件的写操作]]，再做进一步处理

代码演示：使用 bs4 提取腾讯新闻标题与链接
```python
# 从 bs4 模块中导入 BeautifulSoup 类
from bs4 import BeautifulSoup

# 调用 BeautifulSoup 类（构造器），传入网页源码属性 r.text，指定使用 'lxml' 解析器，创建解析对象 soup
soup = BeautifulSoup(r.text, 'lxml')

# 调用 soup 对象的 find_all() 方法，查找所有标签名为 'div' 且 class 属性为 'text' 的标签对象，返回列表并遍历
# 注意：因为 class 是 Python 的保留关键字，所以在 bs4 中必须加下划线写成关键字参数 class_ = 'text'
for news in soup.find_all('div', class_ = 'text'):
    # 调用当前 div 标签对象 news 的 find() 方法，在其中查找第一个 'a'（超链接）子标签对象，赋值给 info
    info = news.find('a')
    # 调用内置函数 len() 判断找到的 a 标签对象 info 内容长度是否大于 0（过滤掉空的无效标签）
    if len(info) > 0:
        # 调用 Tag 对象 info 的 get_text() 方法，提取 <a>...</a> 标签内部夹着的纯文本（即新闻标题）
        title = info.get_text()
        # 调用 Tag 对象 info 的 get() 方法获取其 'href' 属性的值（即新闻链接 URL），并调用 str() 函数（类构造器）转为字符串
        link = str(info.get('href'))
        # 调用内置函数 print() 拼接并打印新闻标题
        print('标题：' + title)
        # 调用内置函数 print() 拼接并打印新闻链接，末尾加上 '\n' 换行符使每条新闻之间空一行
        print('链接：' + link + '\n')
```
![[file-20261025190531416.png]]
>[!notes] 
>1. **为什么写 `class_ = 'text'`？** 因为 `class` 在 Python 里是定义类的关键字（`class Student:`），直接写 `class='text'` 会报语法错误，所以 BeautifulSoup 规定用 **`class_`（末尾加下划线）** 作为关键字参数来匹配 HTML 的 `class` 属性。
>2. **Tag 对象的两个核心提取方法**（务必记住）：
`info.get_text()` **方法**：提取标签里面夹着的**文字**（对应图3右红框的新闻标题）。
`info.get('href')` **方法**：类似字典的 `.get()` 方法 [[6.容器类型#标签索引|字典get方法]]，用于提取标签身上某个 **HTML 属性的值**（对应图3左红框 `href="…"` 里的网址链接）。
