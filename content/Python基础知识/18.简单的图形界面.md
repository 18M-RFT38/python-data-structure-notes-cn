# 图形用户界面(GUI)
全称： **Graphical User Interface** 
中文：图形用户界面
GUI是人机交互的图形化界面设计，包括展示数据用的小控件、输入的方法、菜单、按钮以及窗口等
用户通过鼠标、键盘等输入设备操纵屏幕上的图标或菜单选项，来执行选择命令、调用文件、启动程序等日常任务。
# easygui
easygui模块 可以显示各种对话框、文本框、选择框与用户交互
easygui是一个第三方的库，所以需要进行安装和导入。
安装：打开  **cmd / PowerShell / 终端** ，输入pip install easygui
导入：import easygui as eg
eg.egdemo()函数 # 弹出easygui全套演示窗口
![[file-20261018100655459.png|342]]
## easygui常用函数
### 消息窗口
easygui.msgbox ()函数 显示一条消息和提供一个 "OK" 按钮
用户可以指定任意的消息和标题，甚至重写 "OK" 按钮的内容
![[file-20261018101025357.png|289]]
### 按钮选项
easygui.choicebox ()函数 为用户提供了一个可选择的列表，使用序列（元祖或列表）作为选项
![[file-20261018101433263.png|326]]
### 显示文本
easygui.textbox ()函数 用于显示文本内容
text 参数可以是字符串、列表或元组类型
![[file-20261018101509742.png|327]]
### 输入密码
easygui.passwordbox ()函数 类似于 enterbox ()函数，
但是用户输入的内容是用 "*" 显示出来
![[file-20261018101601356.png|364]]
### 打开文件
easygui.fileopenbox ()函数 返回用户选择的文件名 (带完整路径)
Default 参数指定了一个默认路径
![[file-20261018101629644.png|366]]
### 简单实例
```python
# 导入easygui库，起别名g，方便后续调用
import easygui as g
# 导入sys模块，用于程序退出
import sys

# while 1：无限循环，1代表条件恒为真，会一直循环
while 1:
    # 弹出消息提示框，展示欢迎文字
    g.msgbox('嗨，欢迎进入第一个GUI制作的小游戏~')
    
    # 定义提示文字
    msg = '你希望学习到什么知识呢？'
    # 定义窗口标题
    title = '互动小游戏'
    # 定义选择框里面的选项列表
    choices = ['琴棋书画', '四书五经', '程序编写', '逆向分析']
    # 弹出选择列表框，让用户选择，选中的结果存入choice变量
    choice = g.choicebox(msg, title, choices)
    
    # 注释：把choice转为字符串，防止用户点取消得到None，拼接时报错
    # note that we convert the choice to string, in case the user
    # cancelled the choice, and we got None.
    
    # 弹出消息框，显示用户刚才选中的内容，窗口标题为“结果”
    g.msgbox('你的选择是: ' + str(choice), '结果')
    
    # 定义下一个弹窗的提示文本
    msg = '你希望重新开始小游戏么？'
    # 窗口标题
    title = '请选择'
    
    # ccbox()函数是【继续/取消】二选一对话框，返回布尔值True/False
    # 点【继续】返回True，点【取消】返回False
    if g.ccbox(msg, title):     # Show a Continue/Cancel dialog
        pass                    # 用户选择继续，pass代表什么都不做，直接回到while循环开头，重新玩
    else:
        sys.exit(0)             # 用户选择取消，调用sys.exit(0)函数，终止整个程序
```
>[!notes] sys：Python 自带标准库，负责程序运行、退出、解释器相关操作，不用安装。
>sys.exit(0)函数：终止整个 Python 程序，直接退出
>括号里的0：代表正常退出（约定：0 = 正常结束；非 0 = 异常退出）
>执行这一行，代码直接停止，不再继续跑 while 循环。
>sys.argv属性（变量）：获取命令行运行时传入的参数
>sys.path属性（变量）：Python 寻找模块的搜索路径
>sys.version属性（变量）：查看当前 Python 版本
