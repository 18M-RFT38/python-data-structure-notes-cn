# Web应用
## 基本概念与架构
 Web应用已经成为目前最热门的应用软件形式。
 Web应用通过 **Web服务器** 提供服务，客户端采用 **浏览器** 或者 **遵循HTTP协议的客户端**。

# 框架的基本概念
## 什么是框架
 Web服务器会处理与浏览器客户端交互的 **HTTP协议具体细节**，但对具体内容的处理还需要自己编写代码。
一个Web框架至少要具备 **处理浏览器客户端请求** 和 **服务端响应** 的能力。

## 框架的特性
 **路由**：解析URL并找到对应的服务端文件或者Python服务器代码。
 **模板**：把服务端数据合并成HTML页面。
 **认证和授权**：处理用户名、密码和权限。
 **Session**：处理用户在多次请求之间需要存储的数据。

 特性说明：框架可能具备这些特性中的一种或多种（例如轻量级框架自带核心路由与模板，认证与表单等通过扩展插件实现）。

# Flask框架
## Python里的Web开发框架
Flask是一种非常容易上手的Python Web开发框架，功能强大，支持很多专业Web开发需要的扩展功能（如Facebook认证和数据库集成）。
只需要具备基本的Python开发技能，就可以开发出一个Web应用来。
![[file-20261025145048467.png|304]]
## 小例子：一个Web服务器测试
在浏览器中访问 `http://127.0.0.1:5000/`，这个服务器会返回一行文本：
```python
from flask import Flask

# 调用 Flask() 类（构造器）创建 Web 应用实例对象 app
app = Flask(__name__)

# 调用 app 对象的 route() 装饰器方法，将根路径 "/" 绑定到视图函数 hello()
@app.route("/")
def hello(): # 定义处理请求的视图函数
    return "Hello World!"

if __name__ == "__main__":
    # 调用 app 对象的 run() 方法启动内置开发服务器
    app.run()
```

![[file-20261025145139940.png]]

# 表单插件Flask-WTF
## 关于表单的扩展库
使用Flask-WTF时，每个表单都抽象成一个 **类** [[21.类的定义与调用|类的定义与调用]]，继承自 `Form` 父类 [[24.类的继承|类的继承]]。
### 后端处理代码 (`app.py`)
```python
from flask_wtf import Form
from wtforms import StringField
from wtforms.validators import DataRequired

# 定义表单子类 MyForm，继承自 Form 类
class MyForm(Form):
    # 调用 StringField() 类（构造器）定义文本字段属性
    # 传入 DataRequired() 类（构造器）创建的非空验证器对象
    user = StringField('Username', validators=[DataRequired()])

from flask import Flask, render_template

# 调用 Flask() 类（构造器）实例化应用对象
app = Flask(__name__)
# 设置 app 对象的 secret_key 属性（用于 CSRF 加密防护）
app.secret_key = '1234567'

# 调用 app.route() 装饰器方法绑定路径并指定支持的请求方式
@app.route('/login', methods=('GET', 'POST'))
def login(): # 定义登录视图函数
    # 调用 MyForm() 类（构造器）实例化表单对象 form
    form = MyForm()
    # 调用 form 对象的 validate_on_submit() 方法检验是否提交且通过验证
    if form.validate_on_submit():
        # if form.user.data == 'admin': （访问字段对象的 data 属性）
        # 访问 form 对象的 data 字典属性获取提交的用户名
        if form.data['user'] == 'admin':
            return 'Admin login successfully!'
        else:
            return 'Wrong user!'
    # 调用 render_template() 函数渲染 HTML 模板并传入 form 对象
    return render_template('login.html', form=form)

if __name__ == "__main__":
    # 调用 app 对象的 run() 方法启动服务器
    app.run()
```

>[!attention] 版本与安全补充说明
>1. **CSRF 密钥**：使用 Flask-WTF 时必须配置 `app.secret_key` 属性，用于生成隐藏的防跨站请求伪造（CSRF）令牌。
>2. **类名更新**：在新版 `Flask-WTF` 中，基类 `Form` 已推荐使用 `FlaskForm` 替代（`from flask_wtf import FlaskForm`）。

### 前端模板代码 (`login.html`) 与渲染效果
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>登录表单</title>
</head>
<body>
<!-- 调用 url_for() 函数动态生成 login 视图函数对应的 URL -->
<form method="POST" action="{{ url_for('login') }}">
    <!-- 调用 form 对象的 hidden_tag() 方法生成隐藏的 CSRF Token 字段 -->
    {{ form.hidden_tag() }}
    <!-- 访问 user 字段的 label 属性渲染标签；调用 form.user() 方法渲染输入框 -->
    {{ form.user.label }}: {{ form.user(size=20) }}
    <input type="submit" value="Submit">
</form>
</body>
</html>
```
