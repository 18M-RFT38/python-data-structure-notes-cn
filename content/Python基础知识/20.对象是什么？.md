# 对象的基本概念
## 万物皆对象
Python 中的所有事物都是以对象形式存在，从简单的数值类型，到复杂的代码模块，都是对象。
## 对象（object）
既表示客观世界问题空间中的某个具体事物（实体），又表示软件系统解空间中代表这个事物的基本元素（抽象后的结果）。
[[3.Python的概览#^01f0a4|抽象]]

**对象 = 属性 + 方法** 
对象以 id 作为标识，既包含数据（属性），也包含代码（方法），是某一类具体事物的特殊实例。
数据/属性：静态 → 特征
方法/代码：动态 → 动作
![[file-20261019215446546.png|331]]
>[!notes]
> id(object)函数：返回对象的 **内存地址（唯一标识 id）** ，是这个对象在内存里的编号。返回值：整数，代表对象在内存中的地址
>type(object)函数（元类）：返回对象所属的 **类型（类 class）** ，看这个对象是什么种类。返回值：类型对象（class）
>dir(object)函数：列出对象上 **所有可用的属性、方法名称** ，返回一个字符串列表。可以查看这个对象能做什么（方法）、有什么特征（属性），就是对象 “里面有什么东西”。
>里面带__xxx__的是 Python 内置的特殊魔法属性 / 方法；不带双下划线的是普通属性和方法。
# 创建对象
对象是 **类的实例** ，是 **程序的基本单元** 
要创建一个新的对象，首先必须 **定义一个类** ，用以指明该类型的对象所包含的内容（属性和方法）
同一类(class)的对象具有相同的属性和方法，但属性值和id不同
## 对象的名称
赋值语句给予对象以名称，对象可以有多个名称（变量引用），但只有一个id
例：a = complex(1, 2)
b = 1
c =1
但是bc的id一样。

对象实现了属性和方法的封装，是一种数据抽象机制
>[!tips] 
>封装：把属性和方法打包塞到同一个对象里。内部细节对外部隐藏了 。所以 不用关心方法的底层代码，直接调用即可（例：Maier.meow()）
## 封装带来的好处
提高了软件的重用性、灵活性、扩展性

重用性：每一个类可new很多对象，重复用一套代码
灵活性：对象独立，修改对象内部，不影响外部调用
扩展性：后续新增功能，直接新增子类，不用大面积改代码
# 对象属性和方法的引用
## 引用形式
<对象名>.<属性名> 或 <对象名>.<方法名>()
可以跟一般的变量一样用在赋值语句和表达式中
```python
"abc".upper() # 引用字符串对象的方法
(1+2j).real   # 引用复数对象的属性
(1+2j).imag   # 引用复数对象的属性
```
## 动态特性
Python 语言动态的特征，使得对象可以随时增加或者删除属性或者方法。
```python
print(f3.fx, f3.fy)
f3.fz = 3.4 #Python动态特点：对象可以现场新增属性直接用'对象.新属性 = 值'来赋值
print(f3.fz)
del f3.fz #删除属性：del 对象.属性
---#输出
0.0 4.5 
3.4
```
# 面向对象编程
## 面向对象编程
(OOP，Object-Oriented Programming）
是一种程序设计范式，同时也是一种程序开发方法。
程序中包含各种独立而又能互相调用的 **对象** 。每个对象都能接受、处理数据并将数据传递给其他对象。
>[!tips]  **思路：谁来做？** 
> **对象是主角** 。数据、动作都在对象里
>把【数据(属性) + 操作数据的函数(方法)】打包为一个对象。
>对象之间通过互相“发消息”（调用对象的方法）来调用。
>例：Maier.feed(0.3)
## 传统程序设计（面向过程）
将程序看作一系列函数或是指令的集合。
>[!tips]  **思路：怎么做？** 
> **函数是主角** ，数据是传来传去的“原料”
>把整个任务拆解为一步步的函数（步骤），数据单独放在外部。
>函数接收数据 → 处理 → 返回结果 → 输出
