# 基本概念
 **特殊方法(special method)**  也被称作魔术方法(magic method)
在类定义中实现一些特殊方法，可以方便地使用python中一些内置操作
>[!notes] 
>python 自带一堆 **现成符号和函数** ：+、-、*、print()、len()。
>这些符号本来只能对数字、字符串、列表这种内置类型生效。
>比如：1+2、"a"+"b"、len([1,2,3])，直接能用。
>但是！ **你自己新建的类，造出来的对象，Python 根本不认识。** 
>你直接写 对象1 + 对象2，Python 会懵：两个这个对象相加，要怎么算？它不知道规则，直接报错。
> **特殊方法（魔术方法）的作用：你自己写一套规则，告诉 Python，遇到这个内置操作的时候该干什么。** 

所有特殊方法的名称以两个下划线__开始和结束。
# 构造与解构
```python
# 导入os.path里面的join函数，作用：把文件夹路径和文件名拼在一起，变成完整路径
from os.path import join

# 创建一个类，名字叫FileObject
class FileObject:
    '''给文件对象进行包装从而确认在删除时文件流关闭'''
    # 这一段是类的说明文字，告诉别人这个类是干嘛的

    # 构造方法 __init__  【创建这个类的对象的时候，自动运行这一段代码】
    # self：代表新建出来的对象本身
    # filepath='~'：文件夹路径，不给参数的话默认是用户主目录
    # filename='sample.txt'：文件名，不给参数的话默认sample.txt
    def __init__(self, filepath='~', filename='sample.txt'):
        # join(filepath, filename) 拼接路径+文件名
        # open(..., 'r+') 以【可读可写】的方式打开文件
        # self.file 把打开好的文件，存到我们新建的对象身上，后面可以拿来用
        self.file = open(join(filepath, filename), 'r+')

    # 析构方法 __del__ 【这个对象没人用、被销毁的时候，自动运行这一段代码】
    def __del__(self):
        # 关闭打开的文件，释放电脑的文件资源
        self.file.close()
        # 删除对象身上保存的file属性
        del self.file
```
## 对象构造器
\_\_init\_\_(self, […])
对象的构造器，实例化对象时调用
创建对象的时候，自动运行这个方法，用来给对象装属性
**初始化方法（**  **__init__**  **），就把它当做默认要写的代码就行** 。写类的时候， **绝大多数情况都要写**  **__init__** ，就当成写类的标配代码。
## 析构器
\_\_del\_\_(self, […])
销毁对象时调用
对象没人用了、要被 Python 回收销毁的时候，自动执行
# 用于算术运算的特殊方法
## 算术操作符
- __add__(self, other)：使用+操作符
- __sub__(self, other)：使用-操作符
- __mul__(self, other)：使用*操作符
- __div__(self, other)：使用/操作符
```python
# 把外面写好的add函数，赋值给__add__特殊方法
# 作用：让这个类支持 + 加法运算符，obj1 + obj2 就会调用add函数
__add__ = add

# 定义__str__特殊方法：print(对象) 的时候自动执行，控制打印出来长啥样
def __str__(self):
    # 返回字符串，格式 F<横向力fx,纵向力fy>
    return "F<%s,%s>" % (self.fx, self.fy)

# 定义__mul__特殊方法：支持 * 乘号，对象 * 数字 的时候自动运行
def __mul__(self, n):
    # 把力的两个分量fx、fy，都乘以数字n，得到新的x、y
    x, y = self.fx * n, self.fy * n
    # 返回新的Force力对象，存放大倍数之后的新力
    return Force(x, y)

# 定义__eq__特殊方法：支持 == 判断，判断两个力对象是否相等
def __eq__(self, force2):
    # \ 代表代码换行，只要fx相等 并且 fy也相等，两个力才算相同
    return (self.fx == force2.fx) and \
           (self.fy == force2.fy)
```

```python
# 操作符使用，测试我们刚才写好的Force类里面的魔术方法
# f1和f2是两个已经创建好的力对象

# 执行f1 + f2，会自动调用__add__方法，算出两个力相加的结果，存进f3
f3 = f1 + f2
# 打印结果，%s会自动调用f3的__str__，输出F<x,y>格式
print("Fadd=%s" % (f3,))

# 执行f1 * 4.5，自动调用__mul__，力乘以倍数，得到新的力对象放到f3
f3 = f1 * 4.5
# 打印乘法的结果，同样调用__str__显示内容
print("Fmul=%s" % (f3,))

# 比较 f1 == f2，自动调用__eq__方法，判断两个力是否完全相同，打印全部信息
print("%s==%s? -> %s" % (f1, f2, f1 == f2))

Fmul=F<0.0,4.5>
F<0,1>==F<3,4>? -> False
```
## 反运算
当左操作数不支持相应的操作时被调用
- \_\_radd\_\_(self, other)
- \_\_rsub\_\_(self, other)
- \_\_rmul\_\_(self, other)
- \_\_rdiv\_\_(self, other)
>[!example]
>也就是说，比如在a+b的情况下，默认是a.\_\_add\_\_(b)，但是a这个对象的类里没有定义\_\_add\_\_或者会报错，**python就会试着调用反向魔术方法**（去找b里的\_\_radd\_\_），此时a+b变成了b.\_\_radd\_\_(a)

# 其他特殊方法
## 字符串操作
不仅数字类型可以使用像+(__add__())和-(__sub__())的数学运算符，例如字符串类型可以使用+进行拼接，使用*进行复制。
- \_\_str\_\_(self)：自动转换为字符串
- \_\_repr\_\_(self)：返回一个用来表示对象的字符串
- \_\_len\_\_(self)：返回元素个数
