# 比较几种数据结构
>[!note]
使用方括号[]创建列表。
使用圆括号()创建元组。
使用花括号{}创建字典。

每种类型中，都可以通过`方括号[]`对单个元素进行访问。
但是对于列表和元组，方括号里的是**整形的偏移量**。
对于字典，方括号里的是**键**。
但是它们都是**返回元素的值**。
# 建立大型的数据结构
将这些内置的数据结构自由地组合成更大、更复杂的结构。
创建自定义数据结构的过程中，唯一的限制来自于这些内置数据类型本身。
## 列表/元组
### 创建三个不同的列表
```python
alist = [1,2,3]
blist = ['hello','python']
clist = [True,False]
```
### 嵌套列表/元组
```python
list_of_lists = [[1,2,3],['hello','python'],[True,False]]
tuple_of_lists = ([1,2,3],['hello','python'],[True,False])
```
也可以嵌套别的容器
## 字典
### 嵌套字典
 **字典的元素**可以是**任意类型**，甚至可以是字典。
```python
dict_of_lists = {'num':[1,2,3],
'word':['Hello','Python'],
'bool':[True,False]}
```
**字典的键值**可以是任意的**不可变类型**。
>[!Example]
用元组作坐标，映射/关联元素。开发电子地图程序。
```python
#列表嵌套
>>> alist=[ [23, 34, 45], [True, 'ab']]
>>> alist[0][2]
45
#字典嵌套列表
>>> bands={'Marxes': ['Moe', 'Curly'], 'KK': [True, 'moon']}
>>> #用key按键取值出字典里的value列表后，又用列表的偏移量索引取值出列表中的元素。
>>> bands['KK'][0]
True
#用坐标来关联地点
>>> poi={(100,100): 'Zhongguancun', (123,23): 'Pizza'}
>>> poi[(100,100)]
'Zhongguancun'
```
