# 代码错误类型

## 意外错误
代码运行可能会发生各种意外错误。

程序的逻辑错误、用户输入不合法等都会引发异常，从而导致程序崩溃。
以上这些错误一旦发生，会引起程序中止退出。
如果希望掌控意外，就需要利用 Python 提供的**异常处理机制**，**在可能出错误的地方设置陷阱捕捉错误**，在异常出现时及时捕获并处理。

## 常见错误类型
### 未知的变量属性：AttributeError
调用了对象不存在的属性或方法。
```python
>>> alist = [1, 2, 3, 4]
>>> alist.sorted()
Traceback (most recent call last):
  File "<pyshell#19>", line 1, in <module>
    alist.sorted()
AttributeError: 'list' object has no attribute 'sorted'
```
尝试在一个列表对象上调用不存在的 `sorted` 属性。
### 语法错误：SyntaxError
代码不符合 Python 语法规范。
```python
>>> print "Hello World"
SyntaxError: Missing parentheses in call to 'print'
```
在 Python 3 中调用 `print` 缺少括号。

# 捕捉错误
## try-except 语句
利用 `try-except` 语句可以为代码设置陷阱，捕获并处理异常。
```python
try:
    <检测语句>
except <错误类型> [as e]:
    <处理异常>
```
- **`try:`**  为缩进的代码设置陷阱。
- **`except:`**  处理错误的代码。
针对不同异常可以设置多个 except 分支来进行精细化处理。
## try-else 语句
```python
try:
    <检测语句>
except <错误类型> [as e]:
    <处理异常>
else:
    <语句块>
```
- **`else:`**  检测语句**没有出错**时执行的代码。
- 如果 `try` 块内的代码成功执行且未触发任何异常，就会跳过 `except` 语句块执行 `else` 块。
## try-finally 语句
```python
try:
    <检测语句>
except <错误类型> [as e]:
    <处理异常>
else:
    <语句块>
finally:
    <语句块>
```
- **`finally:`**  **无论出错否，都执行的代码**。
- 如果 `try` 语句块运行没有出现错误，会跳过 `except` 语句块，执行 `finally` 语句块的内容。
## 综合实例演示

```python
try:
    print('try...')
    r = 10 / 'xyz'
    print('result:', r)
except TypeError as e:
    print('TypeError:', e)
#运行 `r = 10 / 'xyz'` 时，因为整数不能除以字符串，触发了 `TypeError` 异常。随后进入对应的 `except TypeError as e:` 分支进行处理并打印了错误信息。
except ZeroDivisionError as e:
    print('ZeroDivisionError:', e)
else:#由于发生了异常，跳过了 `else` 块。
    print('no error!')
finally:#最后必定执行 `finally` 块，打印 `finally...`。
    print('finally...')
print('END')#异常被成功捕捉并处理，程序**未中止退出**，继续正常运行并打印最后的 `END`。
#---输出结果---
try...
TypeError: unsupported operand type(s) for /: 'int' and 'str'
finally...
END
```
