# Pillow库
Python里的图像处理库
PIL: Python Image Library 
功能强大，可以对图像做各种处理。 
包括：缩放、裁剪、旋转、滤镜、文字、调色板等等。
> [!notes] 
原版 PIL 库已停止维护，现在普遍使用的是其友好的分支版本 **Pillow**，通常在代码中依旧通过 `from PIL import …` 的方式进行导入。

# 图像处理步骤

## 打开图像
`Image.open(<路径+图像名+文件格式>)` 
模块级函数
Pillow库能自动根据文件内容确定格式。
若图片在程序目录下，则不需要附带路径，直接将图像名+文件格式作为参数。（相对路径）

# PIL图像操作
## 缩略图
`thumbnail(size, Image.ANTIALIAS)` 方法
- 参数 `size` 为一个元组，指定生成缩略图的大小。
- 直接对内存中的原图进行了修改，但是修改完后的图片需要保存。
- 处理后的图片不会被拉伸（保持原始比例）。 !
> [!notes] 
版本说明 
高版本 Pillow 中，`Image.ANTIALIAS` 常量（属性）已被废弃或重命名为 `Image.Resampling.LANCZOS`

## 模糊效果
应用滤镜的方法演示：
```python
from PIL import Image, ImageFilter

# 打开一个jpg图像文件，注意是当前路径：
im = Image.open('test.jpg') # 调用 Image.open() 函数
# 应用模糊滤镜：
im2 = im.filter(ImageFilter.BLUR) # 调用图像对象的 filter() 方法，传入 BLUR 滤镜属性
im2.save('blur.jpg', 'jpeg') # 调用 save() 方法
```

## 添加文字
在图像上绘制文字的方法演示：
```python
from PIL import Image, ImageDraw, ImageFont

# 打开程序目录下的图片cat
img = Image.open('cat.jpg')
# 设置待添加文字大小为100，字体为宋体
# 调用 ImageFont.truetype() 函数（或工厂方法）创建字体对象
font = ImageFont.truetype('simsun.ttc', 100) 
# 在img上创建可绘图对象draw
draw = ImageDraw.Draw(img) # 调用 ImageDraw.Draw() 类构造器创建画笔对象
# 添加红色文字“可爱的小猫”
draw.text((100, 10), '可爱的小猫', (255, 0, 0), font=font) # 调用画笔对象 draw 的 text() 方法
# 保存照片
img.save('cat1.jpg', 'jpeg')
```

# 小程序：PIL生成验证码
这是一个综合性案例，利用 Pillow 的绘画、文字、滤镜生成网站常见的图形验证码。
## 阶段 1：导入模块与随机函数定义
```python
from PIL import Image, ImageDraw, ImageFont, ImageFilter
import random

# 定义生成随机字母的函数：
def rndChar():
    return chr(random.randint(65, 90)) # 调用 random 模块的 randint() 函数

# 定义生成随机颜色1的函数 (用于背景噪点，色彩较亮):
def rndColor():
    return (random.randint(64, 255), \
            random.randint(64, 255), \
            random.randint(64, 255))

# 定义生成随机颜色2的函数 (用于字体颜色，色彩较暗):
def rndColor2():
    return (random.randint(32, 127), \
            random.randint(32, 127), \
            random.randint(32, 127))
```

## 阶段 2：创建画布与噪点填充、文字输出、模糊处理
```python
# 240 x 60:
width = 60 * 4
height = 60
# 调用 Image.new() 函数（工厂方法）在内存中创建一个新的空白图像对象
image = Image.new('RGB', (width, height), (255, 255, 255))

# 创建Font对象:
font = ImageFont.truetype('Arial.ttf', 36)
# 创建Draw对象:
draw = ImageDraw.Draw(image)

# 填充每个像素(生成背景噪点):
for x in range(width):
    for y in range(height):
        draw.point((x, y), fill=rndColor()) # 调用 draw 对象的 point() 方法打点

# 输出文字:
for t in range(4):
    draw.text((60 * t + 10, 10), rndChar(), font=font, fill=rndColor2()) # 调用 text() 方法写入

# 模糊(增加机器识别难度):
image = image.filter(ImageFilter.BLUR) # 调用 filter() 方法
image.save('code.jpg', 'jpeg') # 调用 save() 方法
```
