# 普通文件
普通文件 数据持久化的最简单类型
仅仅是在一个文件名下的字节流，把数据从文件读入内存，从内存写入文件。
## 打开文件
### open () 函数
f = open(filename,mode,buffering)
- f：open () 返回的文件对象
- filename：文件的字符串名
- mode：可选参数，打开模式和文件类型
- buffering：可选参数，文件的缓冲区，默认为 - 1
### mode-文件的打开模式
mode 第一个字母表明对其的操作：
- 'r' 表示读模式
- 'w' 表示写模式
- 'x' 表示在文件不存在的情况下新创建并写文件
- 'a' 表示在文件末尾追加写内容
- '+' 表示读写模式
mode 第二个字母是文件类型
- 't' 表示文本类型
- 'b' 表示二进制文件
## 文件的读写和访问
```python
>>> f=open("my.txt", "w")
#写入列表
>>> f.writelines(["apple\n", "pie\n"])
>>> f.close()

>>> f=open("my.txt", "r")
#只读模式 返回所有行
>>> f.readlines()
['apple\n', 'pie\n']
>>> f.close()
```
### 文件的写操作
f.write(str)方法
f.writelines(strlist)方法：写入字符串列表
### 文件的读操作
f.read()方法
f.readline()方法：返回一行
f.readlines()方法：返回所有行、列表
## 文件的关闭
文件打开后要记得关闭
关闭的作用是终止对外部文件的连接，同时将缓存区的数据刷新到硬盘上
### 调用 close () 方法
f.close()
或使用 **上下文管理器 (context manager)**  确保在退出后自动关闭文件
```python
with open('textfile','rt') as myfile:
    myfile.read()
    #注意缩进
```
# 结构化文本文件CSV
CSV:Comma-Separated Values
纯文本文件，以 "," 为分隔符

特点：
- 值没有类型，所有值都是字符串
- 不能指定字体颜色等样式
- 不能指定单元格的宽高，不能合并单元格
- 没有多个工作表
- 不能嵌入图像图表
## 文件读取
reader
re = csv.reader()函数
接受一个可迭代对象（比如 csv 文件），能返回一个生成器，可以从其中解析出内容

DictReader
re = csv.DictReader()类
与 reader 类似
但返回的每一个单元格都放在一个元组的值内
## > 文件写入
w = csv.writer()函数
w.writerow(rows)方法
当文件不存在时，自动生成
支持单行写入和多行写入

字典数据写入
w = csv.DictWriter()类
w.writeheader()方法
w.writerow(rows)方法
# 结构化文本文件 Excel
openpyxl 模块
- 用来读写扩展名为 xlsx/xlsm/xltx/xltm 的文件
- Workbook 类是对工作簿的抽象
- Worksheet 类是对表格的抽象
- Cell 类是对单元格的抽象文件写操作
## 操作之前先导入第三方库
安装： pip install openpyxl
导库： from openpyxl import Workbook
## 创建 Excel 文件
一个 Workbook 对象代表一个 Excel 文档，实例化该类并通过 wb.active 属性获取一个 Worksheet 对象后才能打开一个表
```python
from openpyxl import Workbook
wb = Workbook()
ws = wb.active#激活一个活动工作表
```
## 读取 Excel 文件
load_workbook(filename)函数
```python
from openpyxl import load_workbook
wb = load_workbook(filename)#读取已有文件
ws = wb.active
```
## 获取单元格信息
获取 Cell 对象
```python
c = wb['sheet']['A1']
#或者按行列读取
c = wb['sheet'].cell(row=1,column=1) # .cell()方法
```
- c.coordinate属性 ：返回单元格坐标
- c.value属性 ：返回单元格的值
- c.row属性 ：返回单元格所在的行坐标
- c.column属性 ：返回单元格所在列坐标
# 结构化文本文件PDF
轻松处理 pdf 文件的库 – PyPDF2
- 包含了  **PdfFileReader、PdfFileMerger、PageObject 和 PdfFileWriter**  四个主要类
- 能进行读写、分割、合并、文件转换等多种操作
- 只能从  **PDF 文档中提取文本并返回为字符串** ，而无法提取图像、图表或其他媒体
## 读取 PDF 文件
pdfFileReader 类
```PYTHON
readFile = open('test.pdf','rb')#打开了文件
pdfFileReader = PdfFileReader(readFile)
```
.getNumPages ()方法: 计算 PDF 文件总页数
.getPage (index)方法: 检索指定编号的页面
## PDF 文件的写操作
```python
writeFile = 'output.pdf'
pdfFileWriter = PdfFileWriter()
```
pdfFileWriter 类
.addPage (pageObj)方法: 根据每页返回的 PageObject，写入到文件
.addBlankPage ()方法: 在文件的最后一页后面写入一个空白页，保存到新文件
## 合并多个文档
PdfFileMerger类
```PYTHON
pdf_merger = PdfFileMerger()
pdf_merger.append('python2018.pdf')#增加（.append()方法）
pdf_merger.merge(20, 'insert.pdf')#合并（.merge()方法）
pdf_merger.write('merge.pdf')#写入（.write()方法）
```
## 单个页面操作
PageObject 类
.extractText ()方法: 按照顺序提取文本
.getContents ()方法: 访问页面内容
.rotateClockwise (angle)方法: 顺时针旋转
.scale (sx,sy)方法: 改变页面大小
