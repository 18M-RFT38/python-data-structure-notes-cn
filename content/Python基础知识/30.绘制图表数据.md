# numpy库
## 基本概念与优势
numpy是Python用于处理大型矩阵的一个速度极快的数学库。
可以做向量和矩阵的运算，包括各种创建矩阵的方法，以及一般的矩阵运算、求逆、求转置。
它的很多底层的函数都是用C写的，可以得到在普通Python中无法达到的运行速度。
numpy对象中能够存放相同类型的这些数据。
![[file-20261025192340646.png|262]]
## numpy矩阵计算与对象属性
### 矩阵计算
创建矩阵：`a = np.matrix([])`（调用 `np.matrix()` 类构造器创建矩阵对象）
矩阵求逆：`a.I` 属性（访问矩阵对象的逆矩阵属性）
矩阵转置：`a.T` 属性（访问矩阵对象的转置矩阵属性）
矩阵乘法：`a * b`（通过运算符重载执行矩阵乘法 [[22.类定义中的特殊方法#用于算术运算的特殊方法|算术特殊方法]]）或调用 `np.dot(a, b)` 函数

### 对象属性
`a.shape` 属性：数组形状，矩阵则为n行m列（返回表示维度的元组 [[6.容器类型#列表和元组|元组]]）
`a.size` 属性：对象元素的个数
`a.dtype` 属性：指定当前numpy对象的整体数据类型

>[!attention] 区分属性与方法
>在 numpy 矩阵对象中，求逆 `a.I`、转置 `a.T` 以及查看维度 `a.shape`、元素个数 `a.size`、数据类型 `a.dtype` 后面均**不带括号**，它们都是矩阵对象的**属性**而非方法
> [[20.对象是什么？#对象属性和方法的引用|对象属性和方法的引用]]。

## 代码演示：矩阵运算与属性调用
```python
>>> import numpy as np
# 调用 np.matrix() 类（构造器）创建 2x2 矩阵对象 a
>>> a = np.matrix([[1, 2], [3, 4]])

# 访问 a.I 属性求逆矩阵
>>> a.I
matrix([[-2. ,  1. ],
        [ 1.5, -0.5]])

# 访问 a.T 属性求转置矩阵
>>> a.T
matrix([[1, 3],
        [2, 4]])

# 逆矩阵与原矩阵相乘（受二进制浮点数精度误差影响，左下角为极小值 1.11e-16）
>>> a.I * a
matrix([[ 1.00000000e+00,  0.00000000e+00],
        [ 1.11022302e-16,  1.00000000e+00]])

# 调用 np.matrix() 类（构造器）创建矩阵对象 b 并做矩阵乘法
>>> b = np.matrix([[7, 6], [5, 4]])
>>> a * b
matrix([[17, 14],
        [41, 34]])

# 访问矩阵对象 a 的形状、大小与数据类型属性
>>> a.shape
(2, 2)
>>> a.size
4
>>> a.dtype
dtype('int64')
```

# matplotlib绘图库
## 基本概念与功能
matplotlib是Python的一个绘图库。它包含了大量的工具，可以使用这些工具创建各种图形。
支持简单的散点图、折线图，甚至三维图形、动画等。
![[file-20261025192611658.png|242]]
matplotlib功能异常强大，Python科学计算社区经常使用它完成数据可视化的工作。
官方示例画廊：http://matplotlib.org/gallery.html

# 绘制函数图像基本思路
## 基本思路
通过将图像上一些点的坐标连接起来，即可绘制函数的近似图像，当点越多时，所绘图像越接近函数图像。
### numpy库的linspace()函数生成数组

语法格式：`numpy.linspace(<start>, <stop>, <num>)` 函数
功能：生成一个存放等差数列的数组（`ndarray` 数组对象），数组元素为浮点型。
参数说明：包含三个参数，分别是数列起始值 `<start>`、终止值 `<stop>`（默认包含自身）、数列元素个数 `<num>`。
### matplotlib库的plot()函数用来画图
调用 `matplotlib.pyplot.plot()` 函数，
可以根据坐标点绘制线条，还可以设定图形颜色、线条线型、以及做标注等。
## 简单函数图形
### 单个简单图形
```python
import matplotlib.pyplot as plt
import numpy as np

# 简单的绘图
# 调用 np.linspace() 函数生成 0 到 2π 之间的 50 个等差数列点（np.pi 为圆周率常量属性）
x = np.linspace(0, 2 * np.pi, 50)

# 如果没有第一个参数 x，图形的 x 坐标默认为数组的索引
# 调用 np.sin() 函数计算正弦值，并调用 plt.plot() 函数绘制曲线
plt.plot(x, np.sin(x))

# 调用 plt.show() 函数显示图形窗口
plt.show()
```
![[file-20261025192839406.png|232]]
### 多个简单图形
在同一次 `plt.plot()` 函数调用中传入多组 `x, y` 坐标参数，即可在同一张画布上绘制多条函数曲线：
```python
import matplotlib.pyplot as plt
import numpy as np

# 调用 np.linspace() 函数生成横坐标数组
x = np.linspace(0, 2 * np.pi, 50)

# 调用 plt.plot() 函数同时绘制 sin(x) 和 sin(2x) 两条曲线
plt.plot(x, np.sin(x),
         x, np.sin(2 * x))

# 调用 plt.show() 函数显示图形
plt.show()
```

## 定制线形与标签图例

### plot()函数的绘制样式参数表示
颜色

| **颜色**   | **表示方法** | **颜色**      | **表示方法** |
| -------- | -------- | ----------- | -------- |
| blue（蓝）  | `'b'`    | yellow（黄）   | `'y'`    |
| cyan（青）  | `'c'`    | white（白）    | `'w'`    |
| green（绿） | `'g'`    | red（红）      | `'r'`    |
| black（黑） | `'k'`    | magenta（洋红） | `'m'`    |

线型与点型表示方法

|**线型**|**表示方法**|**点型**|**表示方法**|
|---|---|---|---|
|实线|`'-'`|圆形|`'o'`|
|短线（虚线）|`'--'`|叉 / 十字|`'x'`、`'+'`|
|短点相间线（点划线）|`'-.'`|三角形（上/下/左/右）|`'^'`、`'v'`、`'>'`、`'>'`|
|虚点线|`':'`|五角星|`'*'`|

### 定制线型
```python
import matplotlib.pyplot as plt
import numpy as np

# 自定义曲线的外观
x = np.linspace(0, 2 * np.pi, 50)

# 调用 plt.plot() 函数：'r-o' 表示红色实线带圆点标记，'g--' 表示绿色短虚线
plt.plot(x, np.sin(x), 'r-o',
         x, np.cos(x), 'g--')

# 调用 plt.show() 函数显示图形
plt.show()
```

### 标签图例
坐标轴标签
`plt.xlabel()` 函数：设置横坐标轴（x轴）的文本标签（例如 plt.xlabel('Rads')）。
`plt.ylabel()` 函数：设置纵坐标轴（y轴）的文本标签（例如 plt.ylabel('Amplitude')）。
  
图形标题
`plt.title()` 函数：设置整个图形顶部的标题（例如 plt.title('Sin and Cos Waves')）。
## 散点图和直方图

### 散点图
scatter(x, y)函数
调用 `plt.scatter(x, y)` 函数绘制散点图，其中 `(x, y)` 是点的横纵坐标序列。
```python
import matplotlib.pyplot as plt
import numpy as np

# 简单的散点图
x = np.linspace(0, 2 * np.pi, 50)
y = np.sin(x)

# 调用 plt.scatter() 函数绘制散点图
plt.scatter(x, y)
# 调用 plt.show() 函数显示图形
plt.show()
```
![[file-20261025193307770.png|196]]
### 直方图
hist(x, n)函数
调用 `plt.hist(x, n)` 函数绘制直方图，其中 `x` 是横坐标数据集，`n`是条状图的数量（即统计区间的柱子个数）。
```python
import matplotlib.pyplot as plt
import numpy as np

# 直方图
# 调用 np.random.randn() 函数生成 1000 个服从标准正态分布的随机数
x = np.random.randn(1000)

# 调用 plt.hist() 函数绘制包含 50 个条状柱子的直方图
plt.hist(x, 50)
# 调用 plt.show() 函数显示图形
plt.show()
```
