# 概念引入
## 模块就是程序
每个扩展名是.py的Python程序都是一个独立的模块（module）。
模块能定义函数、类、变量，让你能够有逻辑的组织你的python代码。
可以被import导入。
## 组织模块
包（package）是放在一个文件夹里的模块集合。
旧版python需要文件夹里有  __init__.py才叫包。3.3版本后无限制。
# 调用模块化的工具
## 模块引用方式
import <模块> [as<别名>]
将模块中的函数等名称导入当前的程序。
在调用模块中的函数的时候，需要加上函数命名空间。
as可以给导入的命名空间替换一个新的名字。
即调用函数时必须写引用方法：<模块>.<函数>
```python
import random as rd
print(rd.randint(1,10))
```
另一种方式
from<模块>  import <函数>
引用模块中的某个函数。
调用时不需要再加上命名空间。
```python
form random import randint
print(randint(1,10))
```
>[!Example] 命名空间就是名字的容器，用来区分同名函数、变量、防止名字冲突。
>模块calc.py中有函数add（）。
>那么calc（这个py文件名）模块就自带一个命名空间。
>所以命名空间在调用模块的语境下指模块名。

# 扩展命名空间
## 命名空间（namespace）
表示标识符（identifier）的可见范围。
一个标识符可以在多个命名空间中定义，在不同命名空间中的含义互不相干。
dir(<名称>)函数:列出名称的属性
help(<名称>)函数:显示出参考手册
