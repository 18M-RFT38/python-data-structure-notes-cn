# 列表排序
[[6.容器类型#重新组织]]
## 列表方法 sort()
`sort()` 是列表对象自带的方法，会**对原列表进行就地（in-place）排序，直接改变原列表内容**。
**数字列表**：默认按升序（从小到大）排列。
**降序控制**：通过传入参数 `reverse = True`，可以改为降序排列。
```python
>>> num = [4, 2, 7, 0, 1]
>>> num.sort()
>>> num
[0, 1, 2, 4, 7]
>>> num.sort(reverse = True)
>>> num
[7, 4, 2, 1, 0]
```

**字符串列表**：默认按照字母表 ASCII 顺序升序排列。
```python
>>> name = ['John', 'Connor', 'Bruce', 'Arthur', 'Edward']
>>> name.sort()
>>> name
['Arthur', 'Bruce', 'Connor', 'Edward', 'John']
```
# 内置排序函数
## 通用函数 sorted()
`sorted()` 是 Python 内置的通用函数，接受一个可迭代对象作为参数。
**与 `sort()` 的核心区别**：`sorted()` **不改变原列表内容**，而是返回一个新的、排好序的列表副本。
```python
>>> name = ['John', 'Connor', 'Bruce', 'Arthur', 'Edward']
>>> sorted_name = sorted(name)
>>> sorted_name
['Arthur', 'Bruce', 'Connor', 'Edward', 'John']
>>> name
['John', 'Connor', 'Bruce', 'Arthur', 'Edward']
```

> [!attention] 
> 元素类型约束 
> 只有当列表中的所有元素都是**同一种类型**（或者彼此之间支持大小比较）时，`sort()` 方法和 `sorted()` 函数才会正常工作；否则会抛出类型错误。

# 特殊方法

## 特殊方法 `__lt__`

由于 Python 的可扩展性，每种数据类型都可以通过定义特殊方法（魔术方法）来支持内置操作。
**定义格式**：
```python
def __lt__(self, other):
```
`lt` 是英文 **L**ess **T**han（小于）的缩写。只要类中定义了特殊方法 `__lt__`，该类的任何自定义对象都可以使用 `<`进行大小比较。
> [!notes] 比较语法糖与参数绑定机制
> 
> 1. **语法糖解构**：写 `a < b` 本质上就是执行 `a.__lt__(b)`。
>     
> 2. **左右操作数对应**：
>     
>     - 谁在 `<` 的**左边**，谁就是主动发起调用的对象本身，传给第一个参数 **`self`**。
>         
>     - 谁在 `<` 的**右边**，谁就是作为客体参与比较的外部对象，传给第二个参数 **`other`**。
>

# 可扩展的“大小”比较及排序

## 自定义对象排序的底层契约
Python 内置的排序算法（如 `sort()` 方法）在对自定义对象列表进行排序时，**只引用 `<` 比较符（即底层的 `__lt__` 方法）来判断两个对象的前后顺序**。

**返回 `True`**：Python 认为 `self` 比 `other` “小”，**`self` 应该排在 `other` 前面**。
**返回 `False`**：Python 认为 `self` 不比 `other` “小”，**`self` 应该排在 `other` 后面**。

> [!tips] 
`__lt__` 本质上定义的是“前后次序” 不需要把 `__lt__` 局限为数学上的数值大小，它是在回答一个问题：“在排序时，`self` 是否应该排在 `other` 前面？” 只要希望某种情况下排在前面，就让该逻辑条件返回 `True`。

```python
class Student:
    def __init__(self, name, grade):
        self.name, self.grade = name, grade
        
    # 内置 sort 函数只引用 < 比较符来判断前后
    def __lt__(self, other):
        # 成绩比 other 高的，排在 other 前面
        # 只需要一条 return 语句：当自身成绩大于对方时返回 True
        return self.grade > other.grade
        
    # Student 的易读字符串表示
    def __str__(self):
        return "(%s,%d)" % (self.name, self.grade)
        
    # Student 的正式字符串表示，让它跟易读表示相同
    __repr__ = __str__
```

> [!question] 为什么想按成绩“从高到低”排序，`__lt__` 里面要写 `>`（大于）？
>  排序算法通过 `a < b`（即 `a.__lt__(b)`）询问：“`a` 应该排在 `b` 前面吗？”
>  当写了 `return self.grade > other.grade` 时：若自身成绩高于对方，则返回 `True`。
 算法收到 `True`，便将成绩更高的对象排在前面，从而自动实现了成绩由高到低的降序排列。
## 构造列表与排序检验
```python
# 构造一个 Python List 对象
s = list()

# 添加 Student 对象到 List 中
s.append(Student("Jack", 80))
s.append(Student("Jane", 75))
s.append(Student("Smith", 82))
s.append(Student("Cook", 90))
s.append(Student("Tom", 70))
print("Original:", s)

# 对 List 进行排序（调用内置 sort 方法）
s.sort()

# 查看结果，已经按照成绩从高到低排好序
print("Sorted:", s)
#---输出结果--
Original: [(Jack,80), (Jane,75), (Smith,82), (Cook,90), (Tom,70)]
Sorted: [(Cook,90), (Smith,82), (Jack,80), (Jane,75), (Tom,70)]
>>> s[0] < s[1]
True
```

可以直接检验对象之间的大小：`s[0] < s[1]` 会触发 `s[0].__lt__(s[1])`，返回布尔值 `True`。
除了 `__lt__`，类中还可以根据需求实现 `__gt__`（大于）、`__eq__`（等于）等富比较方法。

如果需要改为按照姓名首字母在字典表里的顺序排列，只需将比较依据切换为字符串：
```python
class Student:
    def __init__(self, name, grade):
        self.name, self.grade = name, grade
        
    def __lt__(self, other):
        # 姓名字母顺序在前的，排在前面
        return self.name < other.name
        
    def __str__(self):
        return "(%s,%d)" % (self.name, self.grade)
        
    __repr__ = __str__
#---输出结果--
Original: [(Jack,80), (Jane,75), (Smith,82), (Cook,90), (Tom,70)]
Sorted: [(Cook,90), (Jack,80), (Jane,75), (Smith,82), (Tom,70)]
```
