## 浮点数
操作与整数类似。
浮点数受到17位 **有效数字** 的限制。（IEEE标准）
超过17位可以使用科学记数法。
特性：进制转换导致精度误差。
对于浮点数的相等运算要谨慎，可以用差值比较。
## 复数
复数的运算支持所有常见运算。
形式：a+b **i** (由于i太像数字1，所以用j替代。)
提取实部属性：（1+2j） **.real** 
提取虚部属性：（1+2j） **.imag** 
复数之间只能作 **相等比较** 。
应用：求平面上两个点（包括原点）的距离。abs()函数：abs((a+bj)-(c+dj))

# 逻辑类型 bool型
逻辑值仅包括真True和假False两个。
非真即假。
用来配合if/while等语句做条件判断。
![[file-20261003192635979.png|255]]
## 逻辑运行
and和or是双目运算，即由两个逻辑类型真值进行运算。
not是单目运算，作用于一个逻辑类型真值。
优先级：not>and>or
但是有优先级的情况下，最好还是用括号括起来，方便阅读。
这里的真值是指真假值，即布尔真值。
### 与运算 and
“并且”
and连接的两个真值需要同时为真，结果才为真。==（全真为真）==
### 或运算 or
“或者”
or连接的两个真值只要有一个为真，计算结果就为真。==（一真为真）==
### 非运算 not
“否定”
not连接的一个真值，非真为假，非假为真。
##### 各种类型对应的真（假）值
###### 整数、浮点数、复数类型
0是“假”。
所有非0的数值，都是“真”。
###### 字符串类型
空串“”是”假“，所有非空串都是”真“。（包括” “里是一个空格。）
###### 所有的序列类型（包括字符串）
空序列是”假“，所有的非空序列都是”真“。
###### 空值 空类型 None
表示无意义，不知道。为”假“。

# 字符串类型
字符串就是把一个个文字的字符”串起来“的数据。
	从0开始，从左到右编号。
	反向编号：最后一个是-1，倒数第二个是-2…
	用这种整数编号，可以从字符串中抽取任何一个字符。

	多行字符串用三个连续单引号‘’‘开始，用三个连续单引号’‘’结束。

```python
"abc"
‘abc'
'''abc 
def
ghi'''
```

### 删除空格
str.strip方法：去掉字符串前后所有空格。
str.lstrip方法：去掉字符串前/左方所有空格。
str.rtrip方法：去掉字符串后/右方所有空格。
### 判断字母数字
str.isalpha方法：判断字符串是否全部由字母构成。
str.isdigit方法：判断字符串是否全部由数字构成。
str.isalnum方法：判断字符串是否仅包含数字和字母，而不包含特殊字符。
### 其他高级操作
split方法：分割。astr.split（sep,maxsplit)。返回一个列表。
	sep分隔符，默认是任意空白（空格、多个空格、制表符、换行）
	写sep=‘ ’（‘一个空格’） 的话会只按一个空格分，要是字符串里有连续空格，会分割出空字符串。
maxsplit控制最大切多少次。默认是maxsplit=-1，代表全部分割。
	maxsplit=1，分割一次，得两段。maxsplit=2，分割两次，得三段。
rsplit方法：从右往左分割，其他同上。
join方法：合并。‘一个分隔符’.join（一个只含字符串的序列）
	括号里的序列不能有纯数值型元素。
	
```python
#字符串拆分组合操作
astr = 'Tom and Jerry'
astr_list = astr.split(sep =' ', maxsplit = 2)
astr_list.reverse()
print(' '.join(astr_list))
Jerry and Tom
```

upper/lower/swapcase方法：大小写相关

## 序列是什么
字符串是一种序列。
序列：能够按照整数顺序排列的数据。
序列的内部结构：可以通过0开始的连续整数来索引单个对象。
对字符串的操作也是对序列的操作。
即：
可以执行切片，获取序列的一部分。
可以用len（）函数来获取序列中包含多少元素。
可以用加法连接更长的序列。
可以用乘法来重复多次，成为更长的序列。
可以用in操作来判断某个元素是否在序列中存在。
