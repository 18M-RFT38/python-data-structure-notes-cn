# 什么是类
类(class)是对象的模版，封装了对应现实实体的性质和行为。
我们把世界当中一个个实体，提取同一类型事物共有的特性，做成模板，这个模板就称之为 **类** 。

实例对象(Instance Objects)是类的具体化。
类比： **类 = 模具，对象 = 用模具造出来的零件** 。

类给面向对象编程三大核心特性提供实现手段： **封装性、继承性、多态性** 。
和函数相似，类是一系列代码的封装。
Python约定： **类名大写字母开头，函数小写字母开头，用来区分** 。
# 定义类
使用class语句来写类，格式：
```python
class <类名>:
    <一系列方法的调用>
```
类的初始化写法：
```python
class <类名>:
    def __init__(self, <参数表>):
    def <方法名>(self, <参数表>):
```
__init__()是特殊方法名。是初始化方法（构造方法），用来根据类的定义创建实例对象； **第一个参数必须是self** 。
# 调用类
<类名>(<参数>)
调用类就会创建一个对象（ **必须写括号！** ）

obj = <类名>(<参数表>)
这行代码返回一个对象实例。
类方法里面的 self，指的就是这个对象实例！
>[!notes]
> 写类定义的时候，Python 还不知道你将来会创建哪一个具体的对象，但类里的方法又必须能够操作那个刚造出来的对象。
> **self**  **的本质就是“我自己”或“当前正在操作的这个对象”。**

用.操作符，调用对象里面的方法。
示例：
```python

t.left(90)
```
# 类的定义与调用
```python
# 定义一个名为 Force 的类，用来描述「力」这个物理对象
class Force:  # 力
    # 构造方法：创建实例对象时自动调用，用来初始化对象属性
    # self 代表当前实例本身；x,y 是力在x、y方向上的分量
    def __init__(self, x, y):  # x,y方向分量
        # 给实例绑定两个属性：fx（x方向分量）、fy（y方向分量）
        self.fx, self.fy = x, y

    # 实例方法：打印当前这个力的分量
    def show(self):  # 打印出力的值
        # 格式化输出，打印 Force<fx的值,fy的值>
        print("Force<%s,%s>" % (self.fx, self.fy))

    # 实例方法：实现两个力的矢量合成（相加）
    # force2 是另外一个 Force 类的实例对象
    def add(self, force2):  # 与另一个力合成
        # 合力x分量 = 当前力的x分量 + 第二个力的x分量
        x = self.fx + force2.fx
        # 合力y分量 = 当前力的y分量 + 第二个力的y分量
        y = self.fy + force2.fy
        # 返回一个新的Force实例，代表合成后的合力
        return Force(x, y)

# ===== 下面是测试代码 =====
# 生成第一个力对象 f1：x分量0，y分量1
f1 = Force(0, 1)
# 调用show方法，打印f1的分量，输出 Force<0,1>
f1.show()

# 生成第二个力对象 f2：x分量3，y分量4
f2 = Force(3, 4)

# 调用f1的add方法，传入f2，将两个力合成，得到合力f3
f3 = f1.add(f2)
# 打印合力f3，输出 Force<3,5>
f3.show()
```
