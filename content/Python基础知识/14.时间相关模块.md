# datetime模块
## 主要的类
可对date、time、datetime三种时间模式进行单独管理。
datetime.date() 处理日期 年月日
datetime.time() 处理时间 时分秒、毫秒
datetime.datetime() 处理日期+时间
datetime.timedelta() 处理时段（时间间隔）
## 获取当前时间
### 获取今天的日期
datetime.date.today()类方法 得到今天的年月日
datetime.datetime.now()类方法 得到今天的年月日+时分秒
### 修改日期格式
使用strftime()方法或 datetime.datetime.isoformat()方法 格式化。
### 时间戳/纪元时间
时间戳是指格林威治时间1970b年01月01日00时00分00秒起，至现在的总秒数。
![[IMG_2265.jpeg]]
#### 将日期转换成时间戳
timetuple（）方法 将时间转换成struc_time格式。
time.mktime（）函数 返回用秒数来表示时间的浮点数。
#### 将时间戳转换成日期
datetime.date.fromtimestamp() 类方法
## 时间上的加减法
两个时间的相加是无意义的。但是相减（间隔）是有意义的。
### timedelta（）类
用timedelta（）类（实例化对象），表示两个时间点的间隔。

# calendar模块
跟日历相关的若干函数和类。
可以生成文本形式的日历。
## 常用函数
calendar.calendar(<年>)
calendar.month(<年>,<月>)
calendar.prmonth(<年>,<月>)
calendar.prcal(<年>)
## 制作电子日历
### 一个月 月历
calendar.month(<年>,<月>)函数 返回多行字符串
calendar.prmonth(<年>,<月>)函数 相当于print（calendar.month(<年>,<月>)）
![[IMG_2267.jpeg]]
### 一整年 年历
calendar.calendar(<年>)函数 返回多行字符串。
calendar.prcal(<年>)函数 相当于print（calendar.calendar(<年>)）
![[IMG_2268.jpeg]]
## 将日历列表化
calendar.monthcalendar()函数 返回某一年的某一个月份日历，是一个嵌套列表。
最里层的列表含有七个元素，代表一周（从周一到周日）。
如果没有本月的日期，则为0。
![[IMG_2269.jpeg]]
## 与日历相关的计算
### 判别闰年
普通闰年：能被4整除，但不能被100整除的年份
世纪闰年：能被400整除的年份
calendar.isleap(<年>)函数
![[IMG_2270.jpeg]]
### 其他计算
计算某月从周几开始，一共多少天。
从0开始，依次为周一、周二…
calendar.monthrange(<年>,<月>)函数

计算某天是周几
calendar.weekday(<年>,<月>,<日>)函数
返回0～6，依次对应周一到周日。
![[IMG_2271.jpeg]]
# time模块
## 获取时间戳
[[14.时间相关模块#时间戳/纪元时间]]
time.time()函数
```python
t1 = time.time()
a = 0
for i in range(n):
    a += i
print(a)
t2 = time.time()
print(t2-t1)
```
