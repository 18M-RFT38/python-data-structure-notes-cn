# 基本线性结构与操作
线性数据结构（Linear DS）将数据项以某种 **线性的次序** 组织起来
[[301~302.线性结构及栈抽象数据类型#什么是线性结构|什么是线性结构]]。

**栈（Stack）**：维持了数据项 **后进先出（LIFO）** 的次序 ，`Stack` 类的基本操作包括 `push()` 实例方法、`pop()` 实例方法、`isEmpty()` 实例方法。
[[301~302.线性结构及栈抽象数据类型#抽象数据类型Stack]]

**队列（Queue）**：维持了数据项 **先进先出（FIFO）** 的次序，`Queue` 类的基本操作包括 `enqueue()` 实例方法、`dequeue()` 实例方法、`isEmpty()` 实例方法。
 [[308~309.队列抽象数据类型与热土豆问题#抽象数据类型Queue]]

**双端队列（Deque）**：可以同时具备 **栈和队列** 的功能 ，`Deque` 类的主要操作包括 `addFront()` 实例方法、`addRear()` 实例方法、`removeFront()` 实例方法、`removeRear()` 实例方法、`isEmpty()` 实例方法。

# 扩展：顺序存储和链式存储
**顺序存储**：利用一整块 **连续的内存空间** 依次存放数据项（如 Python 内置的 `list` 类型。）
 [[205~206.Python数据类型的性能#List列表数据类型]]
现代内存（RAM）通过 **行地址和列地址（Row/Column Address Selection）** 直接交叉寻址，访问任意位置花费的时间都完全相同，支持 $O(1)$ 随机访问 ；但插入或删除元素需批量平移后续数据，开销为 $O(n)$。
[[202.大O表示法|大O表示法]]

**链式存储**：节点分散在 **任意不连续的内存空间** 中，依靠节点的 `next` 引用属性串联维系次序。
[[313~314.无序表抽象数据类型及其python实现#链式存储的基本思想]]
插入或删除已知位置的节点只需修改引用指向（局部操作为 $O(1)$），但按位置查找元素必须像 **磁带** 一样从表头 `head` 属性出发顺着引用链逐个遍历，访问耗时为 $O(n)$。

# 扩展：高级链表
## 常见扩展链表
**双链表（双向链表）**：不同于[[313~314.无序表抽象数据类型及其python实现#采用链表实现无序表|单向链表]]，节点不光有指向后继的 `next` 引用属性，还有指向前驱的 `prev` 引用属性，支持前后双向遍历。
（可用于实现双端队列 [[312.双端队列抽象数据类型及python实现]]）


**循环链表**：表尾节点的 `next` 引用属性不再指向 `None`，而是指回表头 `head` 属性形成闭环。
（适用于约瑟夫/热土豆等轮转场景 ）

**多重链表**：每个节点包含 **多个 `next` 引用属性**（如同时包含按学号排序的 `nextById` 属性与按姓名排序的 `nextByName` 属性），由不同头指针（`listById`、`listByName`）分别引导，使同一份数据节点无需复制即可同时维持多种有序次序 
[[315.有序表抽象数据类型及其python实现|有序表抽象数据类型及Python实现]]。‘

**二叉链表**：每个节点包含 `[lchild | data | rchild]`（数据属性 `data` 与左、右子节点引用属性 `lchild`、`rchild`），将链表从“一对一”的线性结构过渡到“一对多”的树形结构
[[604.树的链表实现]]。

附上多重节点作为理解的材料：
```python
# 多重链表的结点
class StudentMListNode(object): # 定义多重链表节点类（构造器）
    def __init__(self, data): # 定义构造方法 __init__()
        self.data = data          # 设置实例属性 data，存放学生数据项
        self.nextById = None      # 设置实例属性 nextById，指向按学号排序的下一节点引用
        self.nextByName = None    # 设置实例属性 nextByName，指向按姓名排序的下一节点引用
```
