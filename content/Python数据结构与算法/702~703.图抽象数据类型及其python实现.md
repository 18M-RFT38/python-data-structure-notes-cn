# 抽象数据类型：ADT Graph
## ADT Graph 的接口定义
按照[[106~107.抽象和实现|抽象数据类型（ADT）]]的逻辑层定义，ADT Graph 规定了图结构需要对外提供的核心操作接口。

`Graph()` **类构造器**：创建一个空的图实例对象。
`addVertex(vert)` **实例方法**：将顶点 `vert` 加入图中。
`addEdge(fromVert, toVert)` **实例方法**：添加一条从 `fromVert` 指向`toVert` 的无权有向边。
`addEdge(fromVert, toVert, weight)` **实例方法**：添加一条从 `fromVert` 指向 `toVert` 且权重为 `weight` 的带权有向边（在 Python 实现中通过默认参数合并为同一个 `addEdge()` 方法）。
`getVertex(vKey)` **实例方法**：在图中查找名称（编号）为 `vKey` 的顶点。
`getVertices()` **实例方法**：返回图中所有顶点的集合。
`in` **运算符**：按照 `vert in graph` 的语句形式，判断顶点是否存在于图中，返回布尔值 `True` 或 `False`（底层依赖类的 `__contains__()` **特殊方法**）。
## ADT Graph 的两种主要实现形式
同一抽象数据类型可以采用不同的底层数据结构来实现，ADT Graph 主要有**邻接矩阵（Adjacency Matrix）**和 **邻接列表（Adjacency List）** 两种经典实现方案，各有优劣，需根据具体应用场景加以选择。
### 邻接矩阵（Adjacency Matrix）
邻接矩阵采用二维矩阵表示图，矩阵的每一行和每一列都代表图中的一个顶点。

如果两个顶点之间有边相连，就在对应的行列位置设定分量值：
无权边将矩阵分量标注为 `1`（相连）或 `0`（不相连）；
带权边则直接将边的权重保存为矩阵分量值。
![[file-20261121204401777.png|368]]

**优点**：邻接矩阵实现法非常简单，可以很容易地查出任意两个顶点之间是如何相连的（时间复杂度 $O(1)$）。
**缺点**：如果图中的边数很少，存储效率会非常低下，矩阵中充斥着大量空位，成为“**稀疏（sparse）**”矩阵。
>[!attention] 为什么实际问题很少直接用邻接矩阵？
>邻接矩阵固定占用 $O(|V|^2)$ 的存储空间。
>而现实中大多数问题所对应的图都是**稀疏**的，边的数量 $|E|$ 远远少于 $|V|^2$ 这个量级，使用邻接矩阵会造成严重的空间浪费。
### 邻接列表（Adjacency List）
邻接列表是**稀疏图**更高效的实现方案，空间复杂度仅为 $O(|V| + |E|)$。；
![[file-20261121204523621.jpeg|301]]
它通过两级结构来组织整张图：
外层的 `Graph` 对象维护一个包含所有顶点的主列表（`master list`，对应 `vertList` **实例属性**）和顶点计数器（`numVertices` **实例属性**）；
主列表中的每个顶点键再分别指向一个独立的 `Vertex` 对象，该对象内部保存自身编号 `id` 以及一个记录所有相邻顶点及边权的字典 `adj`。
# 图抽象数据类型的 Python 实现
采用邻接列表方案实现 ADT Graph，需要定义 `Vertex` **类**和 `Graph` **类**（参考[[21.类的定义与调用|类的定义与调用]]与[[22.类定义中的特殊方法|类定义中的特殊方法]]）。
## 顶点类 `class Vertex`
`Vertex` **类**封装了单个顶点的编号信息，以及该顶点向外连接的所有邻接边与权重信息。

```python
# 定义顶点类 Vertex，表示图中的单个节点
class Vertex:

    # 定义构造方法 __init__()，形参 key 接收顶点编号
    def __init__(self, key):
        self.id = key              # 实例属性：保存当前顶点的编号标识
        self.connectedTo = {}      # 实例属性：字典对象，存储 {邻居 Vertex实例对象: 边权重}

    # 定义实例方法 addNeighbor()，添加一条指向邻居顶点 nbr 的有向边（默认权重 0）
    def addNeighbor(self, nbr, weight=0):
        # 注意：nbr 是另一个 Vertex 类的实例对象，直接作为 connectedTo 字典的键
        self.connectedTo[nbr] = weight

    # 定义特殊方法 __str__()，定义调用内置函数 print() 或 str() 时的输出格式
    def __str__(self):
        # 通过列表推导式遍历 connectedTo 字典的键（即各个邻居 Vertex 对象 x），读取其 x.id 属性（编号）
        return str(self.id) + ' connectedTo: ' \
            + str([x.id for x in self.connectedTo])

    # 定义实例方法 getConnections()，返回connectedTo字典里所有的键，即与当前顶点相连的邻居 Vertex 实例对象
    def getConnections(self):
        return self.connectedTo.keys()

    # 定义实例方法 getId()，返回当前顶点的编号属性
    def getId(self):
        return self.id

    # 定义实例方法 getWeight()，根据传入的邻居 Vertex 对象 nbr 返回对应边的权重
    def getWeight(self, nbr):
        return self.connectedTo[nbr]
```
### `Vertex` 类核心机制拆解
`nbr` **局部形参 / 字典键**：它是一个 `Vertex` **类的实例对象**，直接作为 `self.connectedTo` [[6.容器类型|字典]]的键（key），对应的值是边的权重 `weight`。

`x.id` **实例属性读取**：在 `__str__()` **特殊方法**的[[26.推导式与生成器|列表推导式]] `[x.id for x in self.connectedTo]` 中，`x` 是从字典键里取出的 `Vertex` 实例对象，`x.id` 只是读取该顶点对象自带的 `self.id` **实例属性**（顶点编号），**它并不是 `connectedTo` 字典里的键（key）**。

`getConnections(self)` **实例方法**：执行 `return self.connectedTo.keys()`。调用字典的 `.keys()` **方法**会返回当前顶点在 `self.connectedTo` 字典里命中的全部键，也就是该顶点所相连的一个或多个邻居 `Vertex` 实例对象（`nbr`）。
## 图 `Graph` 类
`Graph` **类**保存了包含所有顶点的主表（花名册），负责统一管理顶点的创建、查询、建边与整图遍历。

```python
# 定义图类 Graph，管理图中所有顶点和边
class Graph:

    # 定义构造方法 __init__()，初始化空图
    def __init__(self):
        self.vertList = {}         # 实例属性：花名册字典，结构为 {int编号: Vertex实例对象}
        self.numVertices = 0       # 实例属性：记录图中顶点的总数

    # 定义实例方法 addVertex()，新加顶点；形参 key 为代表顶点编号的数字
    def addVertex(self, key):
        self.numVertices = self.numVertices + 1
        newVertex = Vertex(key)        # 调用 Vertex() 类构造器创建顶点对象，key 赋值给 newVertex.id
        self.vertList[key] = newVertex # 将局部变量 key 作为字典键，newVertex 对象作为字典值存入花名册
        return newVertex

    # 定义实例方法 getVertex()，通过数字编号 n 在花名册中查找顶点
    def getVertex(self, n):
        if n in self.vertList:
            return self.vertList[n]    # 存在则返回对应的 Vertex 实例对象
        else:
            return None                # 不存在则返回常量 None

    # 定义特殊方法 __contains__()，支持 `n in g` 成员判断语句
    def __contains__(self, n):
        return n in self.vertList

    # 定义实例方法 addEdge()，添加从起点编号 f 到终点编号 t 的有向边（默认权重 cost=0）
    def addEdge(self, f, t, cost=0):
        # 若起始顶点或目标顶点尚未登记在花名册中，先调用 addVertex() 实例方法自动新建
        if f not in self.vertList:
            nv = self.addVertex(f)
        if t not in self.vertList:
            nv = self.addVertex(t)
        # 核心语句：先用编号从花名册取出起点与终点对象，再调用起点对象的 addNeighbor() 方法登记邻居
        self.vertList[f].addNeighbor(self.vertList[t], cost)

    # 定义实例方法 getVertices()，返回花名册中所有顶点的编号（字典键）
    def getVertices(self):
        return self.vertList.keys()

    # 定义特殊方法 __iter__()，使 Graph 实例支持 for 循环遍历
    def __iter__(self):
        # 调用内置函数 iter()，返回花名册中所有值（即全部 Vertex 实例对象）的迭代器
        return iter(self.vertList.values())
```
### `Graph` 类核心机制拆解
`self.vertList` **实例属性**：一个字典对象，相当于整张图的“**花名册**”，结构为 `{int 编号 : Vertex 实例对象}`。

`addVertex(self, key)` **实例方法**：局部变量 `key`（形参，代表顶点编号的数字）同时发挥了两个作用——先传给 `Vertex(key)` **类构造器**生成 `newVertex` 对象，使 `key` 成为 `newVertex.id` **实例属性**；
紧接着执行 `self.vertList[key] = newVertex`，把局部形参 `key` 作为 `self.vertList` 字典的键，把 `newVertex` 顶点对象作为字典的值登记进花名册。

`getVertex(self, n)` **实例方法**：传入数字编号 `n`，去 `self.vertList` 字典里查找，存在则返回对应的 `Vertex` 对象，不存在则返回常量 `None`。

`__contains__(self, n)` **特殊方法**：定义 `n in g` 的行为，判断编号 `n` 是否存在于 `self.vertList` 字典的键中。

`addEdge(self, f, t, cost=0)` **实例方法**：形参 `f` 和 `t` 分别是起点和终点的数字编号。
方法先检查这两个编号是否已在花名册里，不存在就调用 `self.addVertex()` **实例方法**新建，然后执行核心建边语句 `self.vertList[f].addNeighbor(self.vertList[t], cost)`。

理解了上面的对照关系后，`self.vertList[f].addNeighbor(self.vertList[t], cost)` 这行代码就不再令人迷惑了：
第一步，`self.vertList[f]` 通过起点编号 `f` 从花名册拿到**起点 `Vertex` 对象**。
第二步，`self.vertList[t]` 通过终点编号 `t` 从花名册拿到**终点 `Vertex` 对象**（作为参数 `nbr`）。
第三步，让起点 `Vertex` 对象调用自己的 `addNeighbor()` **实例方法**，把终点 `Vertex` 对象和边权重 `cost` 写入起点内部的 `connectedTo` 字典，完成邻居登记。
## 实例演示与遍历控制流
### 创建图、添加顶点与有向边
```python
# 调用 Graph() 类构造器创建空图对象 g
g = Graph()

# 循环调用 addVertex() 实例方法，加入编号为 0 ~ 5 的 6 个顶点
for i in range(6):
    g.addVertex(i)

# 查看花名册字典 g.vertList（课件中为 Python 2 写法 print g.vertList）
print(g.vertList)

# 输出：
{
0: 0 connectedTo: [], 
1: 1 connectedTo: [], 
2: 2 connectedTo: [],
3: 3 connectedTo: [], 
4: 4 connectedTo: [], 
5: 5 connectedTo: []
}
```
### 双层循环遍历图中所有边
![[file-20261121210415327.png|203]]
```python
# 调用 addEdge() 实例方法，按课件示例图添加 9 条带权有向边
g.addEdge(0, 1, 5)
g.addEdge(0, 5, 2)
g.addEdge(1, 2, 4)
g.addEdge(2, 3, 9)
g.addEdge(3, 4, 7)
g.addEdge(3, 5, 3)
g.addEdge(4, 0, 1)
g.addEdge(5, 4, 8)
g.addEdge(5, 2, 1)
# 外层 for 循环触发 Graph.__iter__() 特殊方法，每次取出一个 Vertex 实例对象赋给变量 v
for v in g:
    # 内层调用 v.getConnections() 实例方法，取出 v 相连的所有邻居 Vertex 实例对象赋给变量 w
    for w in v.getConnections():
        # 分别调用 v 和 w 的 getId() 实例方法获取顶点编号，并用内置函数 print() 格式化输出
        print("(%s, %s)" % (v.getId(), w.getId()))
```
运行结果依次打印出图中全部 9 条有向边：
![[file-20261121210612082.png|60]]
>[!notes] 
>若在 Python 3 中直接打印字典 `print(g.vertList)` 时，字典内对象默认调用 `__repr__()` 而非 `__str__()`，若想看到 `0 connectedTo: […]` 效果，需逐个 `print(v)` 或额外定义 `__repr__()` 特殊方法。
