# 二叉堆操作的实现
二叉堆（Binary Heap）在逻辑上是一棵 [[608.优先队列和二叉堆#树的平衡性与完全二叉树|完全二叉树]]，分为最小堆（父节点 $\le$ 子节点）与最大堆。
本节实现的是**最小堆**，底层使用 Python 列表 `list` 按层序存储节点。
## 二叉堆初始化（`__init__`）
采用一个列表来保存堆数据，其中表首下标为 `0` 的项无用。
为了后续代码可以使用简单的整数乘除法来定位父子节点，仍保留下标 `0` 的占位元素 `[0]`。

有效节点从下标 `1` 开始编号时，对于任意下标为 $i$（$i \ge 1$）的节点：
**父节点**下标为 `i // 2`（整数向下取整除法）。
**左子节点**下标为 `2 * i`。
**右子节点**下标为 `2 * i + 1`。

```python
class BinHeap:                  # 类定义：创建一个名为 BinHeap 的二叉堆类
    def __init__(self):         # 构造方法（特殊实例方法）：在实例化对象时自动执行初始化
        self.heapList = [0]     # 实例属性：底层存储列表，下标 0 占位不用，有效数据从下标 1 开始
        self.currentSize = 0    # 实例属性：记录当前堆中有效节点的数量（不含下标 0）
```

> [!tips] Python 语法角色提示
> `class BinHeap:` 是**类定义**；
> `def __init__(self):` 是**构造方法**，创建 `heap = BinHeap()` 时自动调用。
> `self.heapList` 与 `self.currentSize` 是绑定在具体对象上的**实例属性**，类内部的所有**实例方法**均通过 `self.` 访问和修改它们。

## 插入操作：`insert(key)` 方法与上浮 `percUp`
### 核心原理
为了保持[[608.优先队列和二叉堆#树的平衡性与完全二叉树|完全二叉树]]的性质，新 `key` 应先直接添加到列表末尾（对应完全二叉树最底层最右侧的空位）。
新 `key` 加在末尾后，对其它路径的堆次序没有影响，但对于新节点到根节点的路径可能破坏“堆”次序。
（例如将 `7` 插入到 `18` 下方，而 `7 < 18`）
![[file-20261118132932302.png|283]]
![[file-20261118133130989.png|290]]

解决方法是将新 `key` 沿着到根节点的路径不断与父节点比较并交换，直到“上浮”到其正确位置。
![[file-20261118133206490.jpeg|359]]
新节点 `7` 添加到末尾后形成路径 `7 -> 18 -> 9 -> 5`，先与 `18` 交换（`swap`），再与 `9` 交换（`swap 2`），最终停在 `5` 的左子节点位置。
```python
    def percUp(self, i):                                # 实例方法：将下标 i 的节点向上调整（上浮）
        while i // 2 > 0:                               # 只要当前节点还有父节点（父节点下标 >= 1）
            if self.heapList[i] < self.heapList[i // 2]:# 若子节点值小于父节点值（违背最小堆性质）
                tmp = self.heapList[i // 2]             # 局部变量 tmp 暂存父节点值
                self.heapList[i // 2] = self.heapList[i]# 子节点值上移到父节点位置
                self.heapList[i] = tmp                  # 原父节点值下移到子节点位置
            i = i // 2                                  # 更新当前跟踪下标为父节点下标，沿路径向上继续检查

    def insert(self, k):                                # 实例方法：向堆中插入新元素 k
        self.heapList.append(k)                         # 调用列表内置方法 append()，将新 key 添加到末尾
        self.currentSize = self.currentSize + 1         # 实例属性 currentSize 加 1
        self.percUp(self.currentSize)                   # 调用实例方法 percUp()，让刚插入的新 key 上浮
```

> [!notes] 控制流拆解（调用栈视角）
> 调用 `heap.insert(7)` 时，先通过列表内置方法 `append()` 将 `7` 追加到 `heapList` 末尾并将实例属性 `currentSize` 加 1；
> 随后 `insert()` 调用实例方法 `self.percUp(self.currentSize)`；
> `percUp()` 进入 `while` 循环，持续比较 `heapList[i]` 与 `heapList[i // 2]`，若更小则交换并让 `i` 减半上移，直至 `i // 2 == 0` 到达根节点后退出。
## 删除最小元素：`delMin()` 方法与下沉 `percDown`
### 核心原理
整个堆中最小的 `key` 始终是根节点 `heapList[1]`。
移走根节点后，为了保持[[608.优先队列和二叉堆#树的平衡性与完全二叉树|完全二叉树]]的性质，用最后一个节点`heapList[currentSize]`来代替根节点，并将列表末尾弹出。

替换上去的新根节点通常较大，破坏了“堆”次序。
解决方法是将新的根节点沿着一条路径“**下沉**”，**直到比两个子节点都小**（或到达叶节点）。
“下沉”路径的选择规则是：如果当前节点比子节点大，那么**选择较小的子节点**进行交换。
![[file-20261118133603006.jpeg|326]]
![[file-20261118133722424.jpeg|426]]
演示追踪（`27` 代替 `5`）：移走 `5` 后将末尾 `27` 移到根节点空位；
`swap 1` 中 `27` 对比子节点 `9` 和 `11`，选较小的 `9` 交换；
`swap 2` 中 `27` 对比新子节点 `14` 和 `18`，选较小的 `14` 交换；`swap 3` 中 `27` 对比新子节点 `33` 和 `17`，选较小的 `17` 交换，最终停在叶节点位置。
> [!attention] 为什么要与“较小的”子节点交换？
> 如果父节点同时大于左、右两个子节点，只有把**更小的**那个子节点换上来作为新父节点，才能保证新父节点同时小于等于另一个子节点，从而维持整棵子树的最小堆次序。


```python
    def percDown(self, i):                              
        while (i * 2) <= self.currentSize:              # 只要当前节点至少有左子节点（未到叶节点）左孩子的下标没有超出元素总数，即左孩子存在。完全二叉树若没有右孩子，一定先没有左孩子！
            mc = self.minChild(i)                       # 调用实例方法 minChild()，找出较小子节点的下标 mc
            if self.heapList[i] > self.heapList[mc]:    # 若当前节点大于较小子节点（违背最小堆性质）
                tmp = self.heapList[i]                  # 交换较小节点和当前节点位置
                self.heapList[i] = self.heapList[mc]   
                self.heapList[mc] = tmp               
            i = mc                                      # 更新跟踪下标为子节点下标 mc，沿路径向下继续检查

    def minChild(self, i):                              # 实例方法（辅助方法）：返回下标 i 的较小子节点下标
        if i * 2 + 1 > self.currentSize:                # 若右子节点下标越界（说明只有左子节点）完全二叉树只要右孩子不存在，左孩子一定是最后一个节点，一定存在。
            return i * 2                                # 直接返回唯一的左子节点下标
        else:                                           # 左右子节点都存在时
            if self.heapList[i * 2] < self.heapList[i * 2 + 1]:
                return i * 2                            # 左子节点更小，返回左子节点下标
            else:
                return i * 2 + 1                        # 右子节点更小或相等，返回右子节点下标

    def delMin(self):                                   # 实例方法：删除并返回堆中最小元素（堆顶）
        retval = self.heapList[1]                       # 局部变量 retval 保存堆顶最小值，准备最后返回
        self.heapList[1] = self.heapList[self.currentSize] # 用最后一个节点覆盖堆顶
        self.currentSize = self.currentSize - 1         # 实例属性 currentSize 减 1
        self.heapList.pop()                             # 调用列表内置方法 pop() 删除原最后一个节点
        self.percDown(1)                                # 调用实例方法 percDown(1)，让新堆顶从下标 1 开始下沉
        return retval                                   # 返回被移走的最小元素
```
## 建堆操作：`buildHeap(alist)` 方法
### 核心原理
从无序表生成“堆”有两种思路：
方案一（逐个 `insert`）：将无序表中的数据项逐个 `insert(key)` 到堆中，总代价为 $O(n \log n)$。
方案二（下沉法 `buildHeap`）：从最后一个节点的父节点（`len(alist) // 2`）开始倒序向前逐个执行 `percDown`，因叶节点无需下沉，能够将总代价控制在 **$O(n)$**。


![[file-20261118134815294.png|517]]
演示追踪（无序表 `[9, 6, 5, 2, 3]`）：
初始树为 `[0, 9, 6, 5, 2, 3]`，起始下标 `i = 5 // 2 = 2`。
当 `i = 2` 时对6执行 `percDown(2)`，6下沉与较小的2交换；
当 `i = 1` 时对（根节点）9执行 `percDown(1)`，`9` 先下沉与较小的 `2` 交换，
9下沉到下标 `2` 后继续对比 6 和 3 并与 3 交换，9 沉到叶节点，没有孩子了，下沉结束。
最终得到合法最小堆 `[0, 2, 3, 5, 6, 9]`。

```python
    def buildHeap(self, alist):                         # 实例方法：根据传入的无序列表 alist 原地建堆
        i = len(alist) // 2                             # 调用内置函数 len()，计算最后一个非叶节点的下标（最后一个叶节点的父节点）
        self.currentSize = len(alist)                   # 设置实例属性 currentSize
        self.heapList = [0] + alist[:]                  # 在列表头部拼接 [0]，并用切片 alist[:] 浅拷贝原列表
        print(len(self.heapList), i)                    # 调用内置函数 print() 打印调试信息
        while (i > 0):                                  # 从最后一个父节点开始，倒序遍历到根节点（下标 1）
            print(self.heapList, i)
            self.percDown(i)                            # 调用实例方法 percDown(i) 对当前子树执行下沉调整
            i = i - 1                                   # 下标减 1，处理前一个非叶节点
        print(self.heapList, i)
```

> [!tips] 为什么 `buildHeap` 的时间复杂度是 $O(n)$ 而不是 $O(n \log n)$？
> 在完全二叉树中，约有一半的节点是叶节点（无需下沉，代价为 0），越靠近底层的节点数量越多但最大下沉高度很小，只有极少数靠近根节点的节点下沉高度接近 $\log n$。
> 将所有节点的最大下沉次数按层求和（错位相减级数），总操作次数不超过 $2n$，因此时间复杂度为线性级 $O(n)$。

> [!notes] 细节提醒：`alist[:]` 的作用
> `self.heapList = [0] + alist[:]` 中使用切片拷贝 `alist[:]` 并与 `[0]` 拼接，会创建一个全新的列表对象，避免后续堆调整直接修改外部传入的原始列表 `alist`。
## 思考与改进
### 课堂代码改进点（`percUp` / `percDown` 优化）
> [!attention] 改进方向一：提前终止循环（剪枝）
> 课堂原版 `percUp` 和 `percDown` 在满足堆次序后（`else` 情况），依然会把 `while` 循环跑完直到根节点或叶节点，做了多余的空转。
> 加上 `else: break` 可以立即结束调整。

> [!tips] 改进方向二：Pythonic 元素交换
> 原代码使用临时变量 `tmp` 进行三行交换，Python 中可直接用元组解包 `a, b = b, a` 一行完成交换，更简洁易读。

```python
    def percUp_improved(self, i):                       # 改进版实例方法：上浮
        while i // 2 > 0:
            if self.heapList[i] < self.heapList[i // 2]:
                self.heapList[i], self.heapList[i // 2] = self.heapList[i // 2], self.heapList[i]
                i = i // 2
            else:
                break                                   # 已满足最小堆次序，提前终止循环

    def percDown_improved(self, i):                     # 改进版实例方法：下沉
        while (i * 2) <= self.currentSize:
            mc = self.minChild(i)
            if self.heapList[i] > self.heapList[mc]:
                self.heapList[i], self.heapList[mc] = self.heapList[mc], self.heapList[i]
                i = mc
            else:
                break                                   # 已比两个子节点都小，提前终止循环
```
# 利用二叉堆实现 [[514.排序算法小结#^659754|堆排序]]（$O(n \log n)$）
## 基于 `BinHeap` 类实现（最直观）
直接复用前面写好的 `BinHeap` 类，先用 `buildHeap` 建堆（$O(n)$），再循环调用 $n$ 次 `delMin()` 依次取出最小值（$O(n \log n)$）。
总时间复杂度为 $O(n \log n)$，空间复杂度为 $O(n)$
（需新建 `BinHeap` 对象与结果列表 `sorted_list`）。
```python
def heap_sort(alist):                                   # 独立函数（非类方法）：接收无序列表 alist，返回升序新列表
    bh = BinHeap()                                      # 实例化 BinHeap 类，自动调用 __init__() 构造方法
    bh.buildHeap(alist)                                 # 调用实例方法 buildHeap()，以 O(n) 代价建最小堆
    sorted_list = []                                    # 局部变量：用于按顺序存放每次弹出的最小值
    while bh.currentSize > 0:                           # 只要堆中还有元素（读取实例属性 currentSize）
        sorted_list.append(bh.delMin())                 # 调用 delMin() 取出堆顶最小值，并调用列表方法 append() 存入结果
    return sorted_list                                  # 返回排好序的新列表
```
## 原地堆排序（In-place Heap Sort，进阶改进）
推荐观看：[4分钟学堆排序(手机动画版)_哔哩哔哩_bilibili](https://www.bilibili.com/video/BV1sek9YBELe/?spm_id_from=333.337.search-card.all.click&vd_source=89aa4049c7b20aa1ae05a47b577806c3) 
[堆排序（大根堆 小根堆）_哔哩哔哩_bilibili](https://www.bilibili.com/video/BV1jP411h7mf/?spm_id_from=333.337.search-card.all.click&vd_source=89aa4049c7b20aa1ae05a47b577806c3)

如果不想额外创建 `BinHeap` 对象和 `sorted_list`，可以直接在原列表 `alist` 上操作（**0-indexed** 下标体系，空间复杂度降至 $O(1)$）。
核心技巧是**升序排列 用 “最大堆”** （大根堆）：先把 `alist` 原地建成最大堆（最大值在下标 `0`），再每次把堆顶最大值 `alist[0]` 与当前堆末尾元素 `alist[end]` 交换归位，随后把堆的有效长度减 1 并对新堆顶执行一次下沉调整。
相应的，如果要**降序排列**，就使用**小根堆**。
> [!tips] 两种堆排序方案对比
> 方案 A（基于 `BinHeap`）代码量极少，直接复用课程类方法，适合理解二叉堆应用；
> 方案 B（原地堆排序）空间复杂度为 $O(1)$，是算法考试与面试中标准的堆排序实现。
> 
> 注意下标从 `0` 开始时，节点 `i` 的左子节点为 `2*i + 1`，右子节点为 `2*i + 2`，最后一个非叶节点为 `n // 2 - 1`。

```python
def sift_down(alist, root, end):                        # 独立辅助函数：在 0-indexed 列表中对下标 root 执行最大堆下沉
    while root * 2 + 1 <= end:                          # 左子节点下标为 2*root+1，若未越界则继续
        child = root * 2 + 1                            # 局部变量 child：先假设左子节点是较大子节点
        if child + 1 <= end and alist[child] < alist[child + 1]:
            child += 1                                  # 若右子节点存在且更大，则指向右子节点
        if alist[root] < alist[child]:                  # 若父节点小于较大子节点（违背最大堆性质）
            alist[root], alist[child] = alist[child], alist[root] # 交换下沉
            root = child                                # 继续向下跟踪
        else:
            break                                       # 已满足最大堆性质，提前结束

def heap_sort_inplace(alist):                           # 独立函数：原地堆排序（直接修改原列表 alist，升序）
    n = len(alist)                                      # 调用内置函数 len() 获取列表长度
    # 第一步：从最后一个非叶节点 (n // 2 - 1) 开始倒序建最大堆，耗时 O(n)
    for start in range(n // 2 - 1, -1, -1):             # 调用内置函数 range() 生成倒序下标
        sift_down(alist, start, n - 1)                  # 调用辅助函数 sift_down() 建堆

    # 第二步：依次将堆顶最大值交换到当前末尾，并缩小堆范围重新下沉，耗时 O(n log n)
    for end in range(n - 1, 0, -1):
        alist[0], alist[end] = alist[end], alist[0]     # 堆顶最大值归位到末尾 end
        sift_down(alist, 0, end - 1)                    # 对前 end 个元素重新恢复最大堆
    return alist
```
