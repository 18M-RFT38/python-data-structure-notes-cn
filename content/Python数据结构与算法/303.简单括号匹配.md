# 简单括号匹配
## 括号的应用场景与优先级
在日常计算和编程中，算术表达式经常包含括号。例如 
`(5+6)*(7+8)/(4+3)`
这里的括号用来显式指定表达式各项的计算优先级。

部分函数式编程语言（如 Lisp）在定义函数时会大量依赖括号组织代码。
例如 `(defun square(n) (* n n))`，通过嵌套括号定义了一个用于计算平方值的函数。

## 括号平衡规则
在语法解析中，括号的使用必须遵循“平衡”规则。
**开闭对应**：每一个开括号（左括号）要恰好对应一个闭括号（右括号）。
**正确嵌套**：每对开闭括号必须保持正确的嵌套次序。
![[file-20261027224753414.png|345]]

识别括号是否正确匹配，是许多编程语言编译器与解释器的基础语法分析算法。
## 括号匹配识别算法设计
构造括号匹配识别算法的核心逻辑：从左到右依次扫描括号字符串，最新打开的左括号，应该匹配最先遇到的右括号。
也就是说，第一个打开的左括号（最早出现），应该匹配最后一个闭合的右括号（最后遇到）。
这种次序反转的特征（后进先出，LIFO），正好与 [[301~302.线性结构及栈抽象数据类型#什么是栈|栈（Stack）]] 的运行机制高度吻合。
![[file-20261027224827911.png|313]]
>[!notes] 算法判定准则
>从左至右扫描字符串：
>遇到左括号时，将其放入栈顶；
>遇到右括号时，从栈顶弹出左括号进行抵消；若此时栈已为空，说明闭括号多余，直接判定失衡；
>扫描完毕后，栈中必须为空；若栈非空，说明开括号多余，判定失衡。

![[file-20261027224940224.png|347]]
## 简单括号匹配算法代码实现
基于前面封装的 `pythonds` 模块中的 `Stack` 类，编写括号匹配检查函数。
```python
from pythonds.basic.stack import Stack

def parChecker(symbolString):
    # 调用 Stack() 类（构造器）创建空栈对象 s
    s = Stack()
    # 设置平衡标志布尔变量 balanced，初始为 True
    balanced = True
    # 设置字符扫描索引变量 index，初始为 0
    index = 0
    
    # 调用 len() 内置函数获取字符串长度，在未越界且仍保持平衡时循环
    while index < len(symbolString) and balanced:
        symbol = symbolString[index]
        if symbol == "(":
            # 遇到左括号，调用 s 对象的 push() 方法将其入栈
            s.push(symbol)
        else:
            # 遇到右括号，调用 s 对象的 isEmpty() 方法检查栈是否为空
            if s.isEmpty():
                # 栈空说明没有对应的左括号，平衡标志置为 False
                balanced = False
            else:
                # 栈不为空，调用 s 对象的 pop() 方法弹出栈顶左括号
                s.pop()

        index = index + 1

    # 扫描结束：若平衡标志为 True 且调用 s.isEmpty() 方法结果为 True（栈已清空），则返回 True
    if balanced and s.isEmpty():
        return True
    else:
        return False

# 调用 print() 内置函数输出测试用例结果
print(parChecker('((()))')) # 输出 True
print(parChecker('(()'))    # 输出 False
```

>[!tips] 算法复杂度分析
>该算法仅需从左至右线性遍历一次长度为 $n$ 的字符串，每次遇到括号执行的入栈（push）或出栈（pop）操作均为 $O(1)$ 常数时间，因此整体时间复杂度为 $O(n)$；空间复杂度取决于最大嵌套层数，最坏情况下为 $O(n)$。

# 更多种括号的匹配
## 混合括号场景
在实际编程与工程应用中，往往会遇到多种类型的括号混合使用：
Python 中定义列表使用的方括号 `[]`
定义字典与集合使用的花括号 `{}`
定义元组与算术表达式使用的圆括号 `()`

当这些不同种类的括号混合嵌套时，不仅数量需要平衡，更需要严格保证各自开闭类型的同类匹配。
![[file-20261027225055898.png|265]]
## 通用括号匹配算法改造思路
相较于单一圆括号的匹配检测，通用括号匹配算法需要在处理逻辑上进行以下两点关键调整：
**左括号入栈**：扫描到任意一种开括号（`(`、`[`、`{`）时，均调用 `push()` 方法入栈保存。
**右括号类型校验**：扫描到任意一种闭括号（`)`、`]`、`}`）时，不仅需要判断栈是否为空，还必须调用 `pop()` 方法取出栈顶的左括号，并额外判断弹出的左括号与当前右括号是否属于同一类型。
```python
from pythonds.basic.stack import Stack

def parChecker(symbolString):
    s = Stack()
    balanced = True
    index = 0
    while index < len(symbolString) and balanced:
        symbol = symbolString[index]
        if symbol in "([{":
            s.push(symbol)#左括号入栈
        else:
            if s.isEmpty():
                balanced = False
            else:
                top = s.pop()#右括号检验并出栈
                if not matches(top, symbol):
                    balanced = False
        index = index + 1
    if balanced and s.isEmpty():
        return True
    else:
        return False

def matches(open, close):
    opens = "([{"
    closers = ")]}"
    return opens.index(open) == closers.index(close)

# 测试示例
print(parChecker('{{([][])}()}'))
print(parChecker('[{()]'))
```
## 扩展应用：层次结构化文档的标记校验
栈对嵌套匹配的处理能力不仅局限于符号括号。
HTML 和 XML 这类层次结构化文档中，各种标签（如 `<html>…</html>`、`<head>…</head>`、`<body>…</body>`）本质上也是成对出现的开闭标记。

验证 HTML/XML 语法结构的合法性、构建 DOM 语法树以及提取嵌套标签内容，其底层算法逻辑完全可以通过栈来实现。
![[file-20261027225341811.png|290]]
>[!notes] 标记校验对应关系
>遇到起始标签（如 `<div>`）时压入栈中；
>遇到闭合标签（如 `</div>`）时弹出栈顶标签并比对标签名是否一致；
>以此类推完成整篇文档的格式合法性验证。
