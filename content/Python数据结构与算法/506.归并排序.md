# 归并排序Merge Sort
## 分治策略在排序中的应用
归并排序是典型的 [[401.什么是递归|递归算法]]，体现了 **分治策略** 在排序中的应用。
核心思路是将数据表持续分裂为两半，对两半分别进行归并排序。
## 递归三要素
**基本结束条件**：数据表仅有 `1` 个数据项，自然是排好序的。
**缩小规模**：将数据表分裂为相等的两半，规模减为原来的二分之一。
**调用自身**：将两半分别调用自身排序，然后将分别排好序的两半进行归并，得到最终排好序的数据表。

## 第一阶段：分裂过程（类比二叉树结构）
初始数据表为 `[54, 26, 93, 17, 77, 31, 44, 55, 20]`。

第2层分裂：继续切分为 `[54, 26]`、`[93, 17]` 以及 `[77, 31]`、`[44, 55, 20]`。

第3层及到底分裂：持续对半分裂，直到所有子列表仅包含单个数据项（即 `[54]`、`[26]`、`[93]`、`[17]`、`[77]`、`[31]`、`[44]`、`[55]`、`[20]`），触发递归基本结束条件。
## 第二阶段：拉链式交错归并过程
第1层归并：将相邻的单元素子表比较合并，得到有序子表 `[26, 54]`、`[17, 93]`、`[31, 77]` 和 `[20, 55]`（`[44]` 准备与 `[20, 55]` 归并）。

第2层归并：`[26, 54]` 与 `[17, 93]` 归并为 `[17, 26, 54, 93]`；
`[44]` 与 `[20, 55]` 归并为 `[20, 44, 55]`。

第3层归并：`[31, 77]` 与 `[20, 44, 55]` 归并为 `[20, 31, 44, 55, 77]`。

最终归并：左半部有序表 `[17, 26, 54, 93]` 与右半部有序表 `[20, 31, 44, 55, 77]` 交错归并，得到完整有序表 `[17, 20, 26, 31, 44, 54, 55, 77, 93]`。
# 归并排序的Python代码实现
## 标准归并排序代码（基于索引指针）
通过维护左半部索引变量 `i`、右半部索引变量 `j` 和结果列表索引变量 `k`，以拉链式交错方式将左右半部从小到大归并回原列表中：
```python
def mergeSort(alist): # 定义归并排序函数 mergeSort()
	print("Splitting ", alist) # 调用内置 print() 函数打印分裂过程
    
    # 基本结束条件：调用内置 len() 函数获取列表长度，大于 1 时才继续分裂
    if len(alist) > 1:
        # 调用内置 len() 函数并使用整除运算符 // 计算中间位置索引变量 mid
        mid = len(alist) // 2
        # 使用列表切片操作获取左半部子列表对象 lefthalf 与右半部子列表对象 righthalf
        lefthalf = alist[:mid]
        righthalf = alist[mid:]

        # 递归调用 mergeSort() 函数自身，分别对左右半部进行排序
        mergeSort(lefthalf)
        mergeSort(righthalf)

        # 初始化左半部索引变量 i、右半部索引变量 j、原列表写入索引变量 k
        i = j = k = 0
        # 拉链式交错把左右半部从小到大归并到结果列表中
        while i < len(lefthalf) and j < len(righthalf):
            if lefthalf[i] < righthalf[j]:
                alist[k] = lefthalf[i]
                i = i + 1
            else:
                alist[k] = righthalf[j]
                j = j + 1
            k = k + 1

        # 归并左半部剩余项
        while i < len(lefthalf):
            alist[k] = lefthalf[i]
            i = i + 1
            k = k + 1

        # 归并右半部剩余项
        while j < len(righthalf):
            alist[k] = righthalf[j]
            j = j + 1
            k = k + 1
	    print("Merging ", alist) # 调用内置 print() 函数打印归并结果
```
## 另一个归并排序代码（更Pythonic）
利用 Python 列表对象的 `pop()` 实例方法、`append()` 实例方法与 `extend()` 实例方法，省去手动维护 `i`、`j`、`k` 三个索引变量的代码。
```Python
def merge_sort(lst): # 定义归并排序函数 merge_sort()
    # 递归结束条件：调用内置 len() 函数判断长度小于等于 1 时直接返回
    if len(lst) <= 1:
        return lst

    # 分解问题，并递归调用
    middle = len(lst) // 2
    # 递归调用 merge_sort() 函数，排好左半部与右半部
    left = merge_sort(lst[:middle])   # 左半部排好序
    right = merge_sort(lst[middle:])  # 右半部排好序

    # 合并左右半部，完成排序
    merged = [] # 创建空列表对象 merged 用于存放归并结果
    while left and right:
        if left[0] <= right[0]:
            # 调用 left/right 列表对象的 pop(0) 实例方法弹出首元素
            # 调用 merged 列表对象的 append() 实例方法追加到结果末尾
            merged.append(left.pop(0))
        else:
            merged.append(right.pop(0))

    # 调用 merged 列表对象的 extend() 实例方法，一次性追加剩余非空半部的所有元素
    merged.extend(right if right else left)
    return merged
```

> [!tips] 
> 两种实现方式的语法对比 **标准实现**：直接在原列表对象 `alist` 上通过索引赋值覆写，逻辑贴近底层数组操作。 
> **Pythonic 实现**：通过 `left.pop(0)` 实例方法和 `merged.extend()` 实例方法极大简化了归并代码，且使用 `<=` 保证了相等元素的相对次序（体现排序稳定性）。
> 但需注意 `list.pop(0)` 实例方法在 Python 中本身具有 $O(k)$ 的元素移动开销。
# 归并排序：算法分析
## 时间复杂度分析
将归并排序分为两个过程来分析：**分裂** 和 **归并**。 

**分裂的过程**：借鉴 [[502.二分查找算法及分析|二分查找]] 中的分析结果，是对数复杂度，时间复杂度为 $O(\log n)$。 
**归并的过程**：相对于分裂的每个部分，其所有数据项都会被比较和放置一次，所以是线性复杂度，其时间复杂度是 $O(n)$。 **综合考虑**：每次分裂的部分都进行一次 $O(n)$ 的数据项归并，总的时间复杂度是 $O(n \log n)$。
## 切片操作与空间复杂度考量
**切片操作的优化**：为了时间复杂度分析精确起见，可以通过 **取消切片操作**，改为传递两个分裂部分的起始点和终止点索引，也是没问题的，只是算法可读性稍微牺牲一点点。 
**空间复杂度开销**：归并排序算法使用了 **额外 1 倍的存储空间** 用于归并，即空间复杂度为 $O(n)$。
> [!attention] 特大数据集排序注意点 
> 归并排序需要额外 1 倍存储空间的特性，在对 **特大数据集** 进行排序的时候必须要考虑进去（可能引发内存空间不足问题）。
## 改进实现：取消切片操作（传递起止索引）
在 Python 中，列表切片操作 `alist[:mid]` 和 `alist[mid:]` 本质上会分配新列表并拷贝元素，产生额外的 $O(k)$ 时间与空间开销。 
通过传递子区间的起始索引变量 `start` 与终止索引变量 `end`，并预先分配一个全局共享的辅助列表对象 `temp`，可以彻底消除切片开销，使分裂过程严格达到常数级 $O(1)$ 单步分割、整体严格保持 $O(n \log n)$ 时间复杂度与 $O(n)$ 额外空间复杂度：
```Python
def merge_sort_no_slice(alist): # 定义入口函数 merge_sort_no_slice()
    # 调用内置 len() 函数获取列表长度属性，预先创建等长的辅助列表对象 temp（额外 1 倍存储空间）
    temp = [0] * len(alist)
    # 调用内部递归辅助函数 _merge_sort()，传入初始起始索引 0 与终止索引 len(alist) - 1
    _merge_sort(alist, temp, 0, len(alist) - 1)
    return alist

def _merge_sort(alist, temp, start, end): # 定义传递起止索引的递归排序函数 _merge_sort()
    # 基本结束条件：当子区间起始索引变量 start 小于终止索引变量 end 时（即包含至少 2 个元素）才继续分裂
    if start < end:
        # 使用整除运算符 // 计算当前区间的中点索引变量 mid
        mid = (start + end) // 2

        # 递归调用 _merge_sort() 函数自身，通过传递起止索引分裂左半部 [start, mid] 与右半部 [mid + 1, end]
        _merge_sort(alist, temp, start, mid)
        _merge_sort(alist, temp, mid + 1, end)

        # 初始化左半部起点索引变量 i、右半部起点索引变量 j、辅助列表写入索引变量 k
        i = start
        j = mid + 1
        k = start

        # 拉链式交错比较左右半部元素，从小到大暂存到辅助列表对象 temp 中
        while i <= mid and j <= end:
            if alist[i] <= alist[j]:
                temp[k] = alist[i]
                i = i + 1
            else:
                temp[k] = alist[j]
                j = j + 1
            k = k + 1

        # 归并左半部剩余项到辅助列表对象 temp 中
        while i <= mid:
            temp[k] = alist[i]
            i = i + 1
            k = k + 1

        # 归并右半部剩余项到辅助列表对象 temp 中
        while j <= end:
            temp[k] = alist[j]
            j = j + 1
            k = k + 1

        # 调用内置 range() 函数（构造器）生成索引序列，将排好序的区间 [start, end] 从辅助列表 temp 拷回原列表 alist
        for idx in range(start, end + 1):
            alist[idx] = temp[idx]
```
