# 图的基本概念
## 中文“图画”与英文词义辨析
就像“羊”在英文中并不是一个单独的词，中文的“图画”在英文中有多个意义大不相同的对应单词：
`painting`：用画刷画的油画。
`drawing`：用硬笔画的素描或线条画。
`picture`：真实形象所反映的画，如照片等（如 `take picture`）。
`image`：由印象而来的画，例如遥感影像称为 `image`（因为是经过传感器印象而来）。
`figure`：轮廓图的意思，指某个侧面的轮廓（因此有 `figure out` 的说法）。
`diagram`：抽象的概念关系图，如电路图、海洋环流图、类层次图。
`chart`：由数字统计而来的柱状图、饼图、折线图。
`map` 指地图，`plot` 指地图上的一小块。

`graph`：重在由一些==基本元素构造==而来的图，如点、线段等。
## 图与树的关系及现实应用
**图（Graph）** 是比 [[601~602.树的定义与相关术语|树]] 更为一般的结构，同样由节点和边构成；实际上，树是一种具有特殊性质的图（连通且无圈的图）。

图可以用来表示现实世界中很多事物，例如道路交通系统、航班线路、互联网连接，以及大学中课程的先修次序（如 `Math-151`、`CS-150` 到 `CS-220`、`CS-490` 的先修依赖网络）。
![[file-20261121150143667.png|493]]

一旦对图相关问题进行了准确描述，就可以采用处理 **图** 的标准 **算法** 来解决那些看起来很艰深的问题。
对于人脑而言，识别模式能够轻而易举地判断地图中不同地点的相互关联；但如果用图来表示地图，计算机就能解决很多地图专家才能解决的问题，甚至远远超越。
互联网是由成千上万计算机连接起来的复杂网络，同样可以通过**图算法**确定计算机之间达成通讯的最短、最快或最有效路径。
>[!tips] 建模思维
> 现实中的交通路网、社交关系、网页超链接与课程先修关系，在底层都可以统一抽象为 **“实体（顶点）+ 关系（边）”** 的图结构，从而复用最短路径、拓扑排序等通用图算法。

# 图的定义与相关术语

## 图的数学定义
一个图 $G$ 可以定义为有序二元组：

$$G = (V, E)$$

其中 $V$ 是**顶点的集合**，$E$ 是**边的集合**。
$E$ 中的每条边 $e = (v, w)$，满足 $v$ 和 $w$ 都是 $V$ 中的顶点。

如果是 **赋权图（Weighted Graph）**，则可以在 $e$ 中添加权重分量，写作 $(v, w, \text{weight})$。
由 $V$ 和 $E$ 的子集构成的图称为 **子图（Subgraph）**。
![[file-20261121150807513.png|225]]

>[!attention] 子图的合法性约束
> 若 $G' = (V', E')$ 是 $G = (V, E)$ 的子图，
> 除了满足 $V' \subseteq V$ 且 $E' \subseteq E$，
> 还必须保证 $E'$ 中每条边的两个端点都属于 $V'$，不能出现脱离顶点的“悬空边”。

**有向赋权图示例（6 个顶点及 9 条整数权重边）**：
$$V = \{V_0, V_1, V_2, V_3, V_4, V_5\}$$
$$E = \{(v_0, v_1, 5), (v_1, v_2, 4), (v_2, v_3, 9), (v_3, v_4, 7), (v_4, v_0, 1), (v_0, v_5, 2), (v_5, v_4, 8), (v_3, v_5, 3), (v_5, v_2, 1)\}$$
![[file-20261121150807513.png|183]]
## 术语表
### 顶点 Vertex（节点 Node）
顶点是图的基本组成部分。顶点具有名称标识 `Key`，也可以携带数据项 `payload`。
### 边 Edge（弧 Arc）
边作为 2 个顶点之间关系的表示，用于连接两个顶点。
边可以是无向或者有向的，相应的图称作 **无向图** 和 **有向图**。
![[file-20261121150549726.png|188]]
### 权重 Weight
为了表达从一个顶点到另一个顶点的“==代价==”，可以给边赋权。
例如公交网络中两个站点之间的“距离”、“通行时间”和“票价”都可以作为权重。
![[file-20261121150713494.png|151]]
### 路径 Path
图中的路径是由边依次连接起来的顶点序列。

无权路径的 **长度** 为**边的数量**；
带权路径的长度为**所有边权重的和**。

例如在示例图中，一条路径 $(v_3, v_4, v_0, v_1)$ 经过的边为 $\{(v_3, v_4, 7), (v_4, v_0, 1), (v_0, v_1, 5)\}$，其**无权长度为 $3$**，**带权路径长度为 $7 + 1 + 5 = 13$**。
![[file-20261121151055304.png|196]]
### 圈 Cycle 与有向无圈图 DAG
**圈（Cycle）** 是首尾顶点相同的路径，例如示例图中的 $(v_5, v_2, v_3, v_5)$ 就是一个圈。
![[file-20261121151211811.png|297]]

如果有向图中不存在任何圈，则称作 **有向无圈图（Directed Acyclic Graph，简称 DAG）**。[[601~602.树的定义与相关术语|树]]也是一种有向无圈图（把边看作从“父节点 $\to$ 子节点”的方向时），而且是无权的。
如果一个问题能表示成 DAG（例如大学课程的先修次序图），就可以用图算法很好地解决；反之，若依赖关系中出现圈，则会产生**循环依赖死锁**。

>[!notes] Python 实现预告
> 在后续的 Python 图结构实现中，通常基于字典（`dict`）构建邻接表来保存顶点与带权边关系，以兼顾稀疏图的存储效率与邻接点查询性能。
