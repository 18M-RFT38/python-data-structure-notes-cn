# 树的遍历（Tree Traversals）
## 基本概念与非线性特征
对一个数据集中的所有数据项进行访问的操作称为 **“遍历（Traversal）”**。
线性数据结构中，对其所有数据项的访问比较简单直接，按照顺序依次进行即可。
树的非线性特点，使得遍历操作较为复杂。
## 三种深度优先遍历次序
我们按照对节点访问次序的不同来区分 **3种遍历**。
如果把树看作 **根节点（D）**、**左子树（L）**、**右子树（R）** 三个部分，且约定左子树总在右子树之前访问，则根据根节点被访问的时机分为：
**前序遍历（preorder）**：先访问根节点，再递归地前序遍历左子树，最后前序遍历右子树（**根 $\to$ 左 $\to$ 右**）。
**中序遍历（inorder）**：先递归地中序遍历左子树，再访问根节点，最后中序遍历右子树（**左 $\to$ 根 $\to$ 右**）。
**后序遍历（postorder）**：先递归地后序遍历左子树，再后序遍历右子树，最后访问根节点（**左 $\to$ 右 $\to$ 根**）。
## 前序遍历的例子：一本书的章节阅读
阅读一本书的各章节，就是一个典型的 **前序遍历** 过程。
按树形结构从根向下的阅读次序为：
Book -> Ch1 -> S1.1 -> S1.2 -> S1.2.1 -> S1.2.2 -> Ch2 -> S2.1 -> S2.2 -> S2.2.1 -> S2.2.2。
![[file-20261117213725504.png|310]]
每次到达一个节点，总是 **先读取当前章节标题（根）**，接着把左侧分支下的所有子节全部读完（左子树），再向右读取同级的下一个章节（右子树）。
# 树的遍历：递归算法代码
## 作为外部函数实现遍历
树本身是递归定义的结构（左、右子树本身也是二叉树），因此用递归函数实现树遍历的代码非常简洁。
**后序和中序遍历的代码仅需要调整语句顺序**（即调整打印根节点的时机）。
```python
# 定义前序遍历外部递归函数 preorder()，形参 tree 接收 BinaryTree 类的实例对象（或 None）
def preorder(tree):
    # 基本结束条件判断：当形参变量 tree 不为空（非 None）时执行；若为 None 则直接出栈返回
    if tree:
        # 1. 访问根节点：调用 tree 对象的 getRootVal() 实例方法获取当前节点数据，并调用内置函数 print() 输出
        print(tree.getRootVal())
        # 2. 遍历左子树：调用 tree 对象的 getLeftChild() 实例方法获取左孩子引用，传入 preorder() 函数自身递归调用
        preorder(tree.getLeftChild())
        # 3. 遍历右子树：调用 tree 对象的 getRightChild() 实例方法获取右孩子引用，传入 preorder() 函数自身递归调用
        preorder(tree.getRightChild())

# 定义后序遍历外部递归函数 postorder()
def postorder(tree):
    # 基本结束条件判断：当形参变量 tree 不等于 None 空对象时执行
    if tree != None:
        # 1. 遍历左子树：调用 tree 对象的 getLeftChild() 实例方法，传入 postorder() 函数自身递归调用
        postorder(tree.getLeftChild())
        # 2. 遍历右子树：调用 tree 对象的 getRightChild() 实例方法，传入 postorder() 函数自身递归调用
        postorder(tree.getRightChild())
        # 3. 访问根节点：待左、右子树全部出栈返回后，调用 getRootVal() 实例方法与内置函数 print() 输出根节点
        print(tree.getRootVal())

# 定义中序遍历外部递归函数 inorder()
def inorder(tree):
    # 基本结束条件判断：当形参变量 tree 不等于 None 空对象时执行
    if tree != None:
        # 1. 遍历左子树：调用 tree 对象的 getLeftChild() 实例方法，传入 inorder() 函数自身递归调用
        inorder(tree.getLeftChild())
        # 2. 访问根节点：待左子树出栈返回后，调用 getRootVal() 实例方法与内置函数 print() 输出根节点
        print(tree.getRootVal())
        # 3. 遍历右子树：调用 tree 对象的 getRightChild() 实例方法，传入 inorder() 函数自身递归调用
        inorder(tree.getRightChild())
```

>[!notes] 节点链表实现的前置接口说明
>上述代码中调用的三个 **实例方法** 来自 `BinaryTree` **类** [[21.类的定义与调用|类的定义与调用]] 的链表实现：
>`tree.getRootVal()` 实例方法：返回当前节点对象中存储的根数据值（即 `self.key` 实例属性）。
>`tree.getLeftChild()` 实例方法：返回当前节点对象的左子树引用（即 `self.leftChild` 实例属性，无左孩子时为 `None`）。
>`tree.getRightChild()` 实例方法：返回当前节点对象的右子树引用（即 `self.rightChild` 实例属性，无右孩子时为 `None`）。
## 在 BinaryTree 类内部作为实例方法实现
也可以直接在 `BinaryTree` **类** 中实现前序遍历的 **实例方法**。
此时 **需要加入子树是否为空的判断**（即在向下递归调用前检查 `self.leftChild` 和 `self.rightChild` 实例属性是否为 `None`）。

```python
# 在 BinaryTree 类内部定义前序遍历实例方法 preorder()，形参 self 代表当前树节点实例对象
def preorder(self):
    # 1. 访问根节点：直接读取 self 对象的 key 实例属性，并调用内置函数 print() 输出
    print(self.key)
    # 2. 遍历左子树：读取 self 对象的 leftChild 实例属性，判断左子树引用是否非空
    if self.leftChild:
        # 确认左子树存在后，调用 self.leftChild 节点对象的 preorder() 实例方法递归遍历
        self.leftChild.preorder()
    # 3. 遍历右子树：读取 self 对象的 rightChild 实例属性，判断右子树引用是否非空
    if self.rightChild:
        # 确认右子树存在后，调用 self.rightChild 节点对象的 preorder() 实例方法递归遍历
        self.rightChild.preorder()
```

>[!attention] 外部函数与内部实例方法的判空位置差异
>**外部函数 `preorder(tree)`**：参数 `tree` 可以接收 `None`（当到达叶节点底部调用 `getLeftChild()` 时传入 `None`），因此在函数入口第一行用 `if tree:` 统一判断基本结束条件。
>**内部实例方法 `self.preorder()`**：通过 `节点对象.preorder()` 语法调用，`self` 自身必定是已存在的节点对象；但如果叶节点的 `self.leftChild` 实例属性为 `None`，直接执行 `None.preorder()` 会触发 `AttributeError` 异常 [[25.例外处理|例外处理]]，因此必须在向下调用前先用 `if self.leftChild:` 和 `if self.rightChild:` 判空。
# 后序遍历：表达式求值
>[!tips] 前置背景补充：什么是“表达式解析树”？
>表达式解析树的 **两条 structural 规则** 就能直接看懂后面两段代码：
>**1. 叶节点（最底层没有孩子的节点）全部存放具体的数字**（如 `3`、`4`、`5`）。
>**2. 内部节点（有左右孩子的父节点）全部存放算术运算符**（如 `'+'`、`'-'`、`'*'`、`'/'`）。
>例如算式 `3 + (4 * 5)` 画成树：最顶上的根节点是 `'+'`，它的左孩子是叶节点 `3`，右孩子是内部节点 `'*'`（`'*'` 的左右孩子分别是叶节点 `4` 和 `5`）。
## 后序遍历求值原理与代码实现
回顾表达式解析树求值，实际上也是一个 **后序遍历（左 $\to$ 右 $\to$ 根）** 的过程：
要计算当前运算符节点的值，必须 **先算出左子树的结果（`res1`）**，**再算出右子树的结果（`res2`）**，**最后用根节点的运算符对 `res1` 和 `res2` 进行运算**。
采用后序遍历法重写表达式求值代码如下：

```python
import operator

# 定义后序遍历表达式求值外部递归函数 postordereval()，形参 tree 接收表达式解析树节点对象
def postordereval(tree):
    # 定义局部字典变量 opers，将运算符字符串映射为 operator 标准库模块中的运算函数对象
    opers = {'+':operator.add, '-':operator.sub, \
             '*':operator.mul, '/':operator.truediv}
    # 初始化局部变量 res1（保存左子树计算结果）与 res2（保存右子树计算结果）为 None
    res1 = None
    res2 = None
    # 基本结束条件判断：当形参变量 tree 非空（非 None）时执行；若 tree 为 None 则函数默认返回 None
    if tree:
        # 1. 左子树求值：调用 tree.getLeftChild() 实例方法获取左孩子，传入 postordereval() 函数自身递归求值并赋给局部变量 res1
        res1 = postordereval(tree.getLeftChild())
        # 2. 右子树求值：调用 tree.getRightChild() 实例方法获取右孩子，传入 postordereval() 函数自身递归求值并赋给局部变量 res2
        res2 = postordereval(tree.getRightChild())
        # 3. 根节点汇总：判断局部变量 res1 和 res2 是否均不为 None
        if res1 and res2:
            # 若 res1 和 res2 均有值（说明当前节点是运算符父节点）：
            # 调用 tree.getRootVal() 实例方法取出运算符字符作为键，从 opers 字典中获取对应运算函数并传入 (res1, res2) 调用，返回计算结果
            return opers[tree.getRootVal()](res1, res2)
        else:
            # 若 res1 和 res2 为 None（说明当前节点是没有孩子的数字叶节点）：
            # 直接调用 tree.getRootVal() 实例方法返回该叶节点存储的数字本身
            return tree.getRootVal()
```

>[!notes] 语法细节说明：`opers[…](res1, res2)` 与 `res1/res2` 分流机制
>**1. 字典映射函数调用**：[[15.算术相关模块|operator模块]] 中的 `operator.add` 是函数对象（加括号才调用）。当 `tree.getRootVal()` 返回 `'+'` 时，`opers['+']` 取出 `operator.add` 函数，紧接着后面的 `(res1, res2)` 就等价于执行 `operator.add(res1, res2)`，即计算 `res1 + res2`。
>**2. 叶节点与内部节点的自动分流**：当递归下探到最底层的 **数字叶节点** 时，它的左、右孩子都是 `None`，因此前两行递归调用 `postordereval(None)` 返回的 `res1` 和 `res2` 全是 `None`。接着 `if res1 and res2:` 判断为假，自动进入 `else:` 分支，把叶节点里的数字直接 `return` 给上一层父节点；而上一层 **运算符父节点** 拿到左右两个数字后，`if res1 and res2:` 判断为真，执行算术运算并向上返回结果。
# 中序遍历：生成全括号中缀表达式
## 中序遍历还原中缀表达式原理与代码
日常书写的算术式（如 `(3+5)`）把运算符写在两个数字中间，称为 **中缀表达式**。
采用 **中序遍历（左 $\to$ 根 $\to$ 右）** 递归算法访问表达式解析树，正好对应“左操作数 $\to$ 运算符 $\to$ 右操作数”的顺序；配合在访问左子树前拼上 `'('`、访问右子树后拼上 `')'`，即可生成保留运算优先级的 **全括号中缀表达式**。

```python
# 定义生成全括号中缀表达式的外部递归函数 printexp()，形参 tree 接收表达式解析树节点对象
def printexp(tree):
    # 初始化局部字符串变量 sVal 为空字符串 ""
    sVal = ""
    # 基本结束条件判断：当形参变量 tree 非空时执行拼接；若 tree 为 None 则直接返回空字符串 ""
    if tree:
        # 1. 遍历左子树：将左括号字符串 '(' 与递归调用 printexp(tree.getLeftChild()) 函数返回的左子树字符串相加拼接
        sVal = '(' + printexp(tree.getLeftChild())
        # 2. 访问根节点：调用 tree.getRootVal() 实例方法获取当前节点值，传入 str() 类（构造器）转为字符串后拼接到 sVal 末尾
        sVal = sVal + str(tree.getRootVal())
        # 3. 遍历右子树：递归调用 printexp(tree.getRightChild()) 函数获取右子树字符串，并在末尾拼接右括号 ')'
        sVal = sVal + printexp(tree.getRightChild()) + ')'
    # 返回当前子树拼接完成的表达式字符串 sVal
    return sVal
```
## 课后练习：修改代码去除数字外层的冗余括号
原代码中，当递归到达最底层的数字叶节点时，虽然左右孩子（`None`）返回空字符串 `""`，但依然会执行外层的 `'(' + … + ')'`，导致每个单独的数字也被套上了括号（如生成 `((3)+((4)*(5)))`）。
要去除数字上的多余括号，只需在拼接括号前判断当前节点是否为 **内部运算符节点**（即判断 `tree.getLeftChild()` 实例方法返回值是否非空），叶节点直接返回数字字符串即可：

```python
# 定义改进后的中缀表达式生成函数 printexp_clean()：仅对内部运算符节点加括号，数字叶节点不加括号
def printexp_clean(tree):
    # 初始化局部字符串变量 sVal 为空字符串 ""
    sVal = ""
    # 基本结束条件判断：当形参变量 tree 非空时执行
    if tree:
        # 调用 tree.getLeftChild() 实例方法判断是否存在左孩子（内部运算符节点必有孩子，数字叶节点无孩子）
        if tree.getLeftChild():
            # 内部运算符节点：在左、右子树外侧正常拼接 '(' 与 ')'
            sVal = '(' + printexp_clean(tree.getLeftChild())
            sVal = sVal + str(tree.getRootVal())
            sVal = sVal + printexp_clean(tree.getRightChild()) + ')'
        else:
            # 数字叶节点：不拼接括号，直接调用 str() 类（构造器）与 tree.getRootVal() 实例方法返回数字文本
            sVal = str(tree.getRootVal())
    # 返回拼接完成的表达式字符串 sVal
    return sVal
```
