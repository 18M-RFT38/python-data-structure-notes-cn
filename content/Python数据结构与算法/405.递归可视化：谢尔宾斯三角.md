# 谢尔宾斯基（Sierpinski）三角形
## 分形构造与维度特性
谢尔宾斯基三角形是一种经典的自相似分形构造 [[19.海龟作图#分形(fractal)的基本概念|分形的基本概念]]，在平面上称为 **谢尔宾斯基三角形**，在立体空间中则称为 **谢尔宾斯基金字塔**。
真正的谢尔宾斯基三角形是完全不可见的，其 **面积为 $0$**，但 **周长无穷**，属于介于一维和二维之间的 **分数维（约 $1.585$ 维）** 构造。
![[file-20261102150635613.png|289]]
# 谢尔宾斯基三角形：作图思路
## 自相似特性与有限阶近似
根据分形的 **自相似特性**，一个谢尔宾斯基三角形是由 **3个尺寸减半** 的谢尔宾斯基三角形按照 **“品”字形**（左下、正上、右下）拼叠而成。
由于在计算机绘图与现实中无法真正做出阶数趋于无穷（$\text{degree} \to \infty$）的谢尔宾斯基三角形，因此只能绘制 **$\text{degree}$（阶数）有限** 的近似图形。
![[file-20261102150657709.png|246]]
## 基于递归三定律的作图分解
对照 [[401.什么是递归#递归“三定律”|递归三定律]]，在 $\text{degree}$ 有限的情况下，作图过程可拆解为以下三个核心要素：
![[file-20261102151329546.png|172]]
### 基本结束条件（最小规模）
当 $\text{degree} = 0$ 时，图形就是一个普通的实心 **等边三角形**，无需再继续拆分，直接绘制完成后退出，这就是递归的 **基本结束条件**。
### 向基本结束条件演进（减小规模）
$\text{degree} = n$ 的三角形，是由 3 个 $\text{degree} = n - 1$ 的三角形按照“品”字形拼叠而成。
同时，这 3 个 $\text{degree} = n - 1$ 的子三角形 **边长均为 $\text{degree} = n$ 的三角形的一半**。每次递归调用时将阶数减 $1$（`degree - 1`）并取各边中点使边长减半，即实现了问题规模的减小。
### 调用自身
在完成当前阶数外轮廓等边三角形的绘制后，按 **左（左下角）→ 上（顶角）→ 右（右下角）** 的次序，分别调用绘制函数自身去完成 3 个 $\text{degree} - 1$ 阶子三角形的绘制。
# 谢尔宾斯基三角形：代码实现
## 完整 Python 源码（`turtle` 模块）
利用内置的 `turtle` 模块 [[19.海龟作图|海龟作图]] 与 [[6.容器类型|字典]] 存储顶点坐标，实现 `degree = 5` 的彩色谢尔宾斯基三角形绘制：

```python
# 导入内置的 turtle 海龟作图模块
import turtle

# 定义谢尔宾斯基三角形递归作图函数 sierpinski()
# degree：当前递归阶数变量；points：存储当前三角形三个顶点坐标的字典变量
def sierpinski(degree, points):
    # 定义局部颜色列表变量 colormap，按索引映射不同 degree 阶数对应的填充颜色
    colormap = ['blue', 'red', 'green', 'white', 'yellow', 'orange']
    # 调用自定义函数 drawTriangle()，根据 points 字典变量与 colormap[degree] 颜色字符串绘制当前等边三角形
    drawTriangle(points, colormap[degree])
    # 最小规模判断（基本结束条件）：当 degree == 0 时条件不成立，直接退出当前函数调用
    if degree > 0:
        # 减小规模并按【左 -> 上 -> 右】次序递归调用 sierpinski() 函数自身
        # 1. 绘制左下角（left）的 degree - 1 阶子三角形，调用 getMid() 函数取中点使边长减半
        sierpinski(degree - 1,
                   {'left': points['left'],
                    'top': getMid(points['left'], points['top']),
                    'right': getMid(points['left'], points['right'])})
        # 2. 绘制正上方（top）的 degree - 1 阶子三角形，调用 getMid() 函数取中点使边长减半
        sierpinski(degree - 1,
                   {'left': getMid(points['left'], points['top']),
                    'top': points['top'],
                    'right': getMid(points['top'], points['right'])})
        # 3. 绘制右下角（right）的 degree - 1 阶子三角形，调用 getMid() 函数取中点使边长减半
        sierpinski(degree - 1,
                   {'left': getMid(points['left'], points['right']),
                    'top': getMid(points['top'], points['right']),
                    'right': points['right']})

# 定义绘制实心等边三角形的辅助函数 drawTriangle()
# points：三个顶点坐标的字典变量；color：填充颜色字符串变量
def drawTriangle(points, color):
    # 调用海龟画笔对象 t 的 fillcolor() 实例方法，设置图形填充颜色为变量 color
    t.fillcolor(color)
    # 调用海龟画笔对象 t 的 penup() 实例方法抬起画笔，避免移动至起点时留下多余线条
    t.penup()
    # 调用海龟画笔对象 t 的 goto() 实例方法，移动到 points 字典变量中 'top' 键对应的顶角坐标元组
    t.goto(points['top'])
    # 调用海龟画笔对象 t 的 pendown() 实例方法落下画笔，准备绘线
    t.pendown()
    # 调用海龟画笔对象 t 的 begin_fill() 实例方法，开始记录闭合填充区域
    t.begin_fill()
    # 依次调用海龟画笔对象 t 的 goto() 实例方法，按 顶角 -> 左下角 -> 右下角 -> 顶角 走完闭合三角形轮廓
    t.goto(points['left'])
    t.goto(points['right'])
    t.goto(points['top'])
    # 调用海龟画笔对象 t 的 end_fill() 实例方法，完成闭合三角形的内部颜色填充
    t.end_fill()

# 定义计算两个点中点坐标的辅助函数 getMid()
# p1、p2：分别代表两个顶点二维坐标的元组变量 (x, y)
def getMid(p1, p2):
    # 通过索引 [0] 和 [1] 访问元组变量 p1、p2 的横纵坐标，计算均值并返回新的中点坐标元组
    return ((p1[0] + p2[0]) / 2, (p1[1] + p2[1]) / 2)

# 调用 turtle 模块的 Turtle() 类（构造器），实例化全局海龟画笔对象 t
t = turtle.Turtle()

# 定义最外层大三角形外轮廓三个顶点的字典变量 points（值为二维坐标元组）
points = {'left': (-200, -100),
          'top': (0, 200),
          'right': (200, -100)}

# 调用递归函数 sierpinski()，传入初始阶数 5 与顶点字典变量 points，绘制 degree=5 的谢尔宾斯基三角形
sierpinski(5, points)

# 调用 turtle 模块的 done() 函数，结束作图并保持画布窗口处于事件循环状态
turtle.done()
```

## 核心函数与语法角色解析
### `sierpinski(degree, points)` 递归主函数
`sierpinski()` 函数是整个分形作图的核心控制函数，内部首先调用 `drawTriangle()` 函数绘制当前层级的底色大三角形，随后在 `if degree > 0:` 分支中构造新的顶点字典字面量，并连续 3 次调用 `sierpinski()` 函数自身。
每次递归传入的子字典保留原三角形的一个角点（如左下角递归保留 `points['left']`），其余两个角点则通过调用 `getMid()` 函数取原边中点获得，从而精确框定出边长减半的左下、正上、右下三个子区域。

### `drawTriangle(points, color)` 绘图辅助函数
`drawTriangle()` 函数专门负责在画布上绘制单个指定顶点与填充色的三角形。
函数内部依次调用全局海龟画笔实例对象 `t` 的 `fillcolor()`、`penup()`、`goto()`、`pendown()`、`begin_fill()` 和 `end_fill()` **实例方法**，以绝对坐标寻址的方式连接 `'top'`、`'left'`、`'right'` 三个顶点，无需像分形树那样手动计算画笔旋转角度与回溯退步 [[19.海龟作图#调用递归画树|调用递归画树]]。

### `getMid(p1, p2)` 中点计算函数
`getMid()` 函数接收两个二维坐标元组变量 `p1` 和 `p2`，通过元组索引访问横坐标 `p1[0]`、`p2[0]` 与纵坐标 `p1[1]`、`p2[1]`，利用中点公式 $\left(\frac{x_1+x_2}{2}, \frac{y_1+y_2}{2}\right)$ 返回中点坐标元组。
# 递归调用树与颜色覆盖机制
## 为什么中心倒置三角形会呈现对应层级的颜色？
观察 `degree = 5` 的运行结果图与递归调用树可以发现，代码中 `drawTriangle()` 函数每次画出的都是 **尖朝上的正立三角形**，从未主动绘制过中心尖朝下的倒置三角形，但最终画面中心却呈现出清晰的彩色倒置三角形层级（如最中心的橙色大倒三角、次级的黄色倒三角、第三级的白色倒三角等）。
这一视觉效果源于 **“先画底层大三角形，后画上层子三角形覆盖”** 的绘图次序：
当执行最外层 `degree = 5` 时，`drawTriangle()` 函数先将整个外轮廓大三角形涂满橙色（`colormap[5]` 为 `'orange'`）。
随后进入 `degree = 4` 的三次递归调用，分别在左下（`left`）、正上（`top`）、右下（`right`）三个角落画上边长减半的黄色（`colormap[4]` 为 `'yellow'`）正立三角形，将原本橙色大三角形的三个角 **直接覆盖**。
正中央未被三个黄色子三角形覆盖的留白区域，自然显露出底层 `degree = 5` 涂上的橙色，并在几何上恰好围成一个尖朝下的倒置三角形。
## 递归调用树的深度优先执行次序
结合课件中的三叉递归调用树（每个节点分出 `left`、`top`、`right` 三个子分支）与 [[403.递归调用的实现|递归调用栈机制]]，程序并非按颜色层级（先把所有黄色画完再画白色）逐层作图，而是遵循 **深度优先（前序遍历）** 的压栈与出栈次序：
首先在根节点绘制最外层的大三角形（留出中心最大倒三角的底色）。
接着沿着最左侧的 `left` 分支一路向下递归压栈，依次在左下角叠加更小一号的底色三角形，直到触及最左下角 `degree = 0` 的最小蓝色三角形（`colormap[0]` 为 `'blue'`）。
当最左下角的 `degree = 0` 触发基本结束条件返回（出栈）后，程序才回退到上一层 `degree = 1` 节点，继续调用其 `top` 分支与 `right` 分支，把左下角这一簇“品”字形的三个蓝色最小三角形补齐，随后再逐级向上回溯并转向外层的 `top` 和 `right` 子树。
>[!tips] 谢尔宾斯基三角形与分形树递归的对比
>1. **定位方式不同**：分形树使用相对运动方法（`t.forward()`、`t.left()`、`t.right()`、`t.backward()`），因此必须在递归返回前严格恢复画笔位置与朝向；而谢尔宾斯基三角形使用绝对坐标跳转方法 `t.goto()`，每次绘图直接指定字典中的精确顶点坐标，无需编写显式的画笔退回代码。
>2. **分支数量不同**：分形树每次递归产生左、右 2 个子调用（二叉递归树），而谢尔宾斯基三角形每次按“左、上、右”产生 3 个子调用（三叉递归树），总调用次数随阶数呈 $3^n$ 指数级增长。
