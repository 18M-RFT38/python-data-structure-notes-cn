# 实现树：节点链接法
## 节点链接法的基本思想

除了嵌套列表之外，还可以采用节点链接法来实现树结构。
与线性链表中每个节点只指向下一个后继不同，树结构中的每个节点需要保存自身根节点的数据项，同时保存指向左子树和右子树的链接引用。
由于每个子树本身也是一棵完整的树，因此左右子树的链接引用指向的同样是树节点对象，从而通过引用嵌套形成层次化的树形结构。

## 定义 BinaryTree 类
为了用 Python 代码实现节点链接法，需要定义一个 `BinaryTree` 类（参考 [[21.类的定义与调用|类的定义与调用]]）。

该类通过 `__init__()` 特殊方法（构造方法）初始化三个实例属性。
实例属性 `self.key` 用于保存当前根节点的数据项 `rootObj`。
实例属性 `self.leftChild` 和 `self.rightChild` 分别用于保存指向左子树和右子树的引用（其值同样是 `BinaryTree` 类对象），初始化时均设为常量 `None`，表示当前节点尚未挂载左右子树。
```python
class BinaryTree:
    def __init__(self, rootObj):
        # 实例属性 key：保存根节点数据项
        self.key = rootObj
        # 实例属性 leftChild / rightChild：保存指向左、右子树的引用（BinaryTree 对象）
        self.leftChild = None
        self.rightChild = None
```
# BinaryTree 类的核心实例方法
## 插入子树：insertLeft() 与 insertRight()
### insert实例方法
**insertLeft(newNode)** 
`insertLeft()` 实例方法用于在当前节点的左侧插入一个新节点 `newNode`，其逻辑分为两种情况。

当 `self.leftChild` 实例属性为 `None`（即当前没有左子树）时，直接调用 `BinaryTree()` 类构造器创建新节点对象，并赋值给 `self.leftChild` 实例属性。

当 `self.leftChild` 实例属性不为 `None`（即当前已存在左子树）时，则需创建新节点 `t`，先将原左子树整体挂接到新节点 `t` 的 `leftChild` 实例属性下，再将父节点的 `self.leftChild` 实例属性指向新节点 `t`。
这相当于把原有的左子树整体向下一层“推”，让新节点插在当前节点与原左子树之间。

**insertRight(newNode)** 
`insertRight()` 实例方法的逻辑与 `insertLeft()` 实例方法完全对称，只是将操作的实例属性由 `leftChild` 替换为 `rightChild`。

```python
    def insertLeft(self, newNode):
        # 情况 1：当前无左子树，直接调用 BinaryTree() 类构造器创建新节点并挂载
        if self.leftChild == None:
            self.leftChild = BinaryTree(newNode)
        # 情况 2：当前已有左子树，将原左子树下推一层
        else:
            t = BinaryTree(newNode)        # 第 1 步：创建新节点对象，赋给局部变量 t
            t.leftChild = self.leftChild   # 第 2 步：新节点的 leftChild 实例属性先接管原左子树
            self.leftChild = t             # 第 3 步：父节点的 leftChild 实例属性再改指向新节点 t

    def insertRight(self, newNode):
        # 情况 1：当前无右子树，直接调用 BinaryTree() 类构造器创建新节点并挂载
        if self.rightChild == None:
            self.rightChild = BinaryTree(newNode)
        # 情况 2：当前已有右子树，将原右子树下推一层
        else:
            t = BinaryTree(newNode)        # 第 1 步：创建新节点对象，赋给局部变量 t
            t.rightChild = self.rightChild # 第 2 步：新节点的 rightChild 实例属性先接管原右子树
            self.rightChild = t            # 第 3 步：父节点的 rightChild 实例属性再改指向新节点 t
```

>[!attention] 
>赋值语句不可次序颠倒（防止断链与破坏树结构）
>在 `else` 分支中，`t.leftChild = self.leftChild` 与 `self.leftChild = t` 这两条赋值语句的顺序绝对不能颠倒。
>
>若先执行 `self.leftChild = t`，父节点原本指向原左子树的唯一引用线索会被立即覆盖，导致原左子树在内存中丢失（断链），紧接着 `t.leftChild = self.leftChild` 还会变成 `t.leftChild = t` 的自引用死循环，彻底破坏二叉树结构。
>
>这一防断链机制与 [[313~314.无序表抽象数据类型及其python实现#add(item) 方法：表头插入|无序表链表的 add() 方法]] 完全一致：都是先让新节点（`temp` 或 `t`）接管原有的后继/子树（`self.head` 或 `self.leftChild`），再让入口引用（`self.head` 或 `self.leftChild`）改指向新节点。
## 访问与修改节点：Getter 与 Setter 实例方法

为了在外部安全地获取子树引用以及读取、修改当前节点的数据项，`BinaryTree` 类提供了四个基础访问与修改实例方法。

`getRightChild()` 实例方法返回当前节点的 `self.rightChild` 实例属性（即右子树 `BinaryTree` 对象或 `None`）。

`getLeftChild()` 实例方法返回当前节点的 `self.leftChild` 实例属性（即左子树 `BinaryTree` 对象或 `None`）。

`setRootVal(obj)` 实例方法将参数 `obj` 赋值给 `self.key` 实例属性，用于修改当前节点保存的数据项。

`getRootVal()` 实例方法返回 `self.key` 实例属性，用于读取当前节点保存的数据项。

```python
    def getRightChild(self):
        return self.rightChild

    def getLeftChild(self):
        return self.leftChild

    def setRootVal(self, obj):
        self.key = obj

    def getRootVal(self):
        return self.key
```

# 二叉树构建与操作示例
通过连续调用类构造器与实例方法，可以逐步构建并修改一棵二叉树的结构。
```python
r = BinaryTree('a')                       # 调用 BinaryTree() 类构造器创建根节点 'a'，赋给变量 r
r.insertLeft('b')                         # 调用 r 的 insertLeft() 实例方法，插入左子节点 'b'
r.insertRight('c')                        # 调用 r 的 insertRight() 实例方法，插入右子节点 'c'
r.getRightChild().setRootVal('hello')     # 先调用 getRightChild() 实例方法获取右子树对象，再链式调用 setRootVal() 实例方法将其值由 'c' 改为 'hello'
r.getLeftChild().insertRight('d')         # 先调用 getLeftChild() 实例方法获取左子节点 'b'，再链式调用 insertRight() 实例方法为其插入右子节点 'd'
```

>[!notes] 链式调用的底层依据
>由于 `getLeftChild()` 和 `getRightChild()` 实例方法返回的本身就是一个 `BinaryTree` 类对象（子树），因此可以直接在其返回值后继续通过点号 `.` 链式调用 `setRootVal()` 或 `insertRight()` 等 `BinaryTree` 类的实例方法。
>最终生成的树结构为：根节点 `'a'`，左子节点为 `'b'`（且 `'b'` 拥有右子节点 `'d'`），右子节点的值由 `'c'` 更新为 `'hello'`
