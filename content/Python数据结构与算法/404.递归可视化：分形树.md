# 递归可视化：图示与海龟作图系统
## 递归调用的视觉影像
前面的种种递归算法 [[401.什么是递归|什么是递归]] 展现了其简单而强大的一面，但仅凭数值与字符串计算较难建立直观的空间概念。
通过递归作图，可以将抽象的递归调用与回溯过程直接转化为可视化的视觉影像。
## Python 的海龟作图系统（`turtle` module）
`turtle` 模块是 Python 内置的标准库模块，随时可用，以 LOGO 语言的创意为基础 [[19.海龟作图|海龟作图]]。
其核心意象为模拟一只海龟在沙滩上爬行而留下的足迹。
>[!notes] `turtle` 模块核心类、函数与实例方法角色说明
>`turtle.Turtle()` 类（构造器）：实例化并返回一个海龟画笔对象 `t`。
>`turtle.done()` 函数：结束作图并启动事件循环，保持画布窗口不立即关闭。
>**爬行（海龟画笔对象 `t` 的实例方法）**
>`t.forward(n)` 方法：控制海龟向当前朝向爬行（前进）`n` 像素距离。
>`t.backward(n)` 方法：控制海龟沿当前朝向的反方向后退 `n` 像素距离（不改变海龟朝向）。
>**转向（海龟画笔对象 `t` 的实例方法）**
>`t.left(a)` 方法：控制海龟在当前朝向基础上向左（逆时针）旋转 `a` 度。
>`t.right(a)` 方法：控制海龟在当前朝向基础上向右（顺时针）旋转 `a` 度。
>**抬笔放笔（海龟画笔对象 `t` 的实例方法）**
>`t.penup()` 方法：抬起画笔，后续海龟移动时不留下线条轨迹。
>`t.pendown()` 方法：放下画笔，后续海龟移动时正常绘制线条轨迹。
>**笔属性与显示（海龟画笔对象 `t` 的实例方法）**
>`t.pensize(s)` 方法：设置画笔线条的粗细宽度为 `s`。
>`t.pencolor(c)` 方法：设置画笔线条的颜色为字符串 `c`。
>`t.hideturtle()` 方法：隐藏画布上的海龟箭头图标。
# 一个递归作图的例子：螺旋
## 结合递归三定律分析螺旋作图
对照 [[401.什么是递归#递归“三定律”|递归三定律]]，绘制折线方螺旋的过程完全具备递归的三大要素：
**基本结束条件（最小规模）**：当待绘制的线段长度变量 `lineLen <= 0` 时，规模达到最小，不执行任何绘图操作，直接退出当前函数调用。
**向基本结束条件演进（减小规模）**：每次画完一条边并右转 $90^\circ$ 后，将下一次需要绘制的边长减少 $5$（`lineLen - 5`），使其逐步逼近 `0`。
**调用自身**：在函数末尾调用 `drawSpiral(t, lineLen - 5)` 函数自身，继续绘制内圈更短的螺旋折线。
![[file-20261102150248893.png|183]]
## 螺旋作图代码实现
```python
# 导入内置的 turtle 海龟作图模块
import turtle

# 调用 turtle 模块的 Turtle() 类（构造器），实例化全局海龟画笔对象 t
t = turtle.Turtle()

# 定义绘制螺旋线的递归函数 drawSpiral()
# t：接收海龟画笔实例对象参数；lineLen：当前待绘制的边长数值变量
def drawSpiral(t, lineLen):
    # 基本结束条件（最小规模）：当边长变量 lineLen 大于 0 时才继续画，小于等于 0 直接退出
    if lineLen > 0:
        # 调用画笔对象 t 的 forward() 实例方法，向前绘制长度为 lineLen 的直线段
        t.forward(lineLen)
        # 调用画笔对象 t 的 right() 实例方法，向右旋转 90 度
        t.right(90)
        # 减小规模（边长减 5）并递归调用 drawSpiral() 函数自身
        drawSpiral(t, lineLen - 5)

# 调用 drawSpiral() 递归函数，传入画笔对象 t 与初始边长 100
drawSpiral(t, 100)

# 调用 turtle 模块的 done() 函数，保持窗口显示
turtle.done()
```
# 分形树：自相似递归图形
## 自然界中的分形与自相似性
自然现象中所具备的分形特性，使得计算机可以通过分形算法生成非常逼真的自然场景（如树木枝干、蕨类植物叶片、叶脉纹理等）。
**分形（Fractal）** 是在不同尺度上都具有相似性的事物 [[19.海龟作图#分形(fractal)的基本概念|分形的基本概念]]。
观察一棵自然生长的树，它的每个分叉和每条树枝，实际上都具有整棵树的外形特征（都是逐步分叉的）。
## 二叉分形树的递归几何分解
基于自相似特性，我们可以把一棵树从空间几何结构上分解为三个部分：**树干**、**右边倾斜的小树**、**左边倾斜的小树**。
这种几何分解关系可以表示为一个直观的视觉等式：
![[file-20261102150414291.png|277]]
分解后的左右两棵小树依然是规模更小的二叉树，正好符合递归的定义：**对自身的调用**。
# 分形树：代码实现与执行机制
[[19.海龟作图#调用递归画树]]
## 分形树完整 Python 源码
```python
# 导入内置的 turtle 海龟作图模块
import turtle

# 定义绘制二叉分形树的递归函数 tree()
# branch_len：当前层待绘制的树干长度参数变量
def tree(branch_len):
    # 基本结束条件：树干太短（小于等于 5）时不画，直接退出当前层递归
    if branch_len > 5:  # 树干太短不画，即递归结束条件
        # 调用画笔对象 t 的 forward() 实例方法，向前画出当前层的主树干
        t.forward(branch_len)  # 画树干
        # 调用画笔对象 t 的 right() 实例方法，向右倾斜 20 度，准备画右子树
        t.right(20)  # 右倾斜20度
        # 减小规模（树干减 15）并递归调用 tree() 函数自身，绘制右边的小树
        tree(branch_len - 15)  # 递归调用，画右边的小树，树干减15
        # 调用画笔对象 t 的 left() 实例方法，向左回转 40 度（抵消右倾 20 度并左倾 20 度）
        t.left(40)  # 向左回40度，即左倾斜20度
        # 减小规模（树干减 15）并递归调用 tree() 函数自身，绘制左边的小树
        tree(branch_len - 15)  # 递归调用，画左边的小树，树干减15
        # 调用画笔对象 t 的 right() 实例方法，向右回转 20 度，使画笔朝向恢复回正
        t.right(20)  # 向右回20度，即回正
        # 调用画笔对象 t 的 backward() 实例方法，让海龟沿当前主干原路退回起点位置
        t.backward(branch_len)  # 海龟退回原位置

# 调用 turtle 模块的 Turtle() 类（构造器），实例化全局海龟画笔对象 t
t = turtle.Turtle()
# 调用画笔对象 t 的 left() 实例方法，向左旋转 90 度使海龟朝向正上方（默认朝右）
t.left(90)
# 调用画笔对象 t 的 penup() 实例方法抬起画笔
t.penup()
# 调用画笔对象 t 的 backward() 实例方法，向后（向下）退 100 像素，将树根起点下移
t.backward(100)
# 调用画笔对象 t 的 pendown() 实例方法放下画笔，准备开始作图
t.pendown()
# 调用画笔对象 t 的 pencolor() 实例方法，设置树枝颜色为绿色 'green'
t.pencolor('green')
# 调用画笔对象 t 的 pensize() 实例方法，设置画笔线条粗细为 2
t.pensize(2)
# 调用 tree() 递归函数，绘制初始主干长度为 75 的二叉分形树
tree(75)  # 画树干长度75的二叉树
# 调用画笔对象 t 的 hideturtle() 实例方法，隐藏海龟图标以展示完整树冠
t.hideturtle()
# 调用 turtle 模块的 done() 函数，结束作图并保持窗口显示
turtle.done()
```
## 单层控制流设计与调用栈回溯机制
### 单层递归的四步几何闭环
编写与理解 `tree(branch_len)` 函数时，核心在于把握 **单层递归的控制流顺序**，确保海龟在完成当前层任务后严格恢复初始状态（位置与角度闭环）：
**第一步（画主干）**：在满足 `branch_len > 5` 的条件下，调用 `t.forward(branch_len)` 方法向前画出当前层的主干，此时海龟停在主干顶端（分叉点）。
**第二步（右偏并嫁接右子树）**：调用 `t.right(20)` 方法使海龟右偏 $20^\circ$，随即调用 `tree(branch_len - 15)` 函数自身。此时当前层在第 8 行 **压栈暂停** [[403.递归调用的实现|递归调用的实现]]，等待右侧整棵小树全部绘制完毕并原路退回分叉点。
**第三步（左转跨过中线并嫁接左子树）**：当右子树递归调用出栈返回时，海龟仍处于分叉点且朝向右偏 $20^\circ$ 的方向。为了画左偏 $20^\circ$ 的对称左子树，必须调用 `t.left(40)` 方法向左旋转 $40^\circ$（$20^\circ$ 回正 $+ 20^\circ$ 左偏），随后再次调用 `tree(branch_len - 15)` 函数自身并 **压栈暂停**，去完成左侧整棵小树的绘制。
**第四步（回正并退回起点）**：当左子树也全部出栈返回后，海龟在分叉点朝向左偏 $20^\circ$。此时必须调用 `t.right(20)` 方法将朝向回正为当前主干方向，再调用 `t.backward(branch_len)` 方法退回当前树干的底部起点。只有当前层彻底恢复原状后函数才执行完毕，向更上一层父调用出栈返回。

>[!attention] 为什么螺旋不需要 `backward()`，而分形树必须 `backward()`？
>在 `drawSpiral()` 函数中，每次递归调用 `drawSpiral(t, lineLen - 5)` 都位于函数的最后一行（尾递归形式），画笔只需顺着螺旋终点一路向内旋转前进，触底后无需回到外圈起点做其他分支。
>而在 `tree()` 函数中，每个分叉点都需要先画右子树、再画左子树（二叉递归）。如果内层子调用结束时不通过 `t.right(20)` 和 `t.backward(branch_len)` 方法恢复画笔的朝向与起点坐标，上一层函数从暂停点恢复执行时，海龟就会停留在末梢树叶的位置上直接画下一根树枝，导致整棵树的空间结构彻底错乱。

>[!question] 深度追踪：`tree(75)` 是如何在最深层触底并转向的？
>当调用 `tree(75)` 函数时，程序会沿着第 8 行（右子树调用）连续压栈：`tree(75)` $\to$ `tree(60)` $\to$ `tree(45)` $\to$ `tree(30)` $\to$ `tree(15)` $\to$ `tree(0)`，表现为海龟一路向右上角最末端钻到底。
>当进入 `tree(0)` 函数时，第 5 行 `if 0 > 5:` 判断为 `False`，触发 **基本结束条件** 直接出栈返回到 `tree(15)` 函数的第 8 行之后。
>随后 `tree(15)` 函数恢复执行第 9 行 `t.left(40)` 方法转向左侧，并在第 10 行再次调用 `tree(0)` 函数（同样立即触底返回），接着执行第 11、12 行回正并退回 `tree(15)` 的起点，完成最右上角第一个小“Y”字分叉的闭合，再逐层出栈回退。
