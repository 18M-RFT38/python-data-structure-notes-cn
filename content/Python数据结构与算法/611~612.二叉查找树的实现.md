# 插入操作：put 与 \_put
## BinarySearchTree.put() 实例方法
`put()` **实例方法**写在 `BinarySearchTree` **类**中，用于向 BST 插入 `key-val` 关联对。

首先检查 `self.root` **实例属性**是否为空（树中是否已有节点）。
若 `self.root` 为 `None`（空树），那么key就成为root，即直接调用 `TreeNode()` **类构造器**创建节点并赋值给 `self.root` **实例属性**。
若 `self.root` 非空，则调用内部递归**实例方法** `_put(key, val, self.root)` 从根节点开始寻找插入位置。

无论走哪条分支，最后都会将 `self.size` **实例属性**加 `1`。

```python
# 以下方法均定义在 BinarySearchTree 类中
def put(self, key, val):
    # 判断 root 实例属性是否已有根节点引用
    if self.root:
        # 树非空，调用内部递归实例方法 _put() 从根节点向下定位
        self._put(key, val, self.root)
    else:
        # 树为空，调用 TreeNode() 类构造器创建根节点并绑定到 root 属性
        self.root = TreeNode(key, val)
    # 更新 size 实例属性，节点总数加 1
    self.size = self.size + 1
```
## BinarySearchTree.\_put() 递归辅助方法
`_put(self, key, val, currentNode)`  **实例方法** 通过比较待插入 `key` 与 `currentNode.key` **实例属性**的大小，沿树向下[[401.什么是递归|递归]]定位空位。

如果 `key` 小于 `currentNode.key`，就看向 `currentNode` 的左子树。
若 `currentNode` 已有左子节点，递归调用 `self._put(key, val, currentNode.leftChild)`把key放到左子树合适的位置里去；
若没有左子节点，则调用 `TreeNode()` **类构造器**创建新节点，让key成为左子节点即赋值给 `currentNode.leftChild` **实例属性**，并传入 `parent=currentNode` 维护双向引用。

如果 `key` 大于（或等于）`currentNode.key`，则看向 `currentNode` 的右子树。
若 `currentNode` 已有右子节点，递归调用 `self._put(key, val, currentNode.rightChild)`把key放到右子树合适的位置里去；
若没有右子节点，则创建新 `TreeNode` 实例并让key成为右子节点即赋值给 `currentNode.rightChild` **实例属性**。同样地，传入 `parent=currentNode` 维护双向引用。

```python
def _put(self, key, val, currentNode):
    # 待插入 key 小于当前节点 key，进入左子树分支
    if key < currentNode.key:
        # 调用 TreeNode 实例方法 hasLeftChild() 判断左子节点是否存在
        if currentNode.hasLeftChild():
            # 存在左子节点，继续向左子树递归
            self._put(key, val, currentNode.leftChild)
        else:
            # 不存在左子节点，创建 TreeNode 实例作为左子节点并绑定 parent 属性
            currentNode.leftChild = TreeNode(key, val, parent=currentNode)
    
    # 待插入 key 大于当前节点 key，进入右子树分支
    else:
        # 调用 TreeNode 实例方法 hasRightChild() 判断右子节点是否存在
        if currentNode.hasRightChild():
            # 存在右子节点，继续向右子树递归
            self._put(key, val, currentNode.rightChild)
        else:
            # 不存在右子节点，创建 TreeNode 实例作为右子节点并绑定 parent 属性
            currentNode.rightChild = TreeNode(key, val, parent=currentNode)
```

## 索引赋值：\_\_setitem\_\_() 特殊方法
通过定义 `__setitem__()` **特殊方法**（[[22.类定义中的特殊方法|类定义中的特殊方法]]），即可让 `BinarySearchTree` 实例支持字典风格的下标赋值语法
（例如 `myZipTree['PKU'] = 100871`）。

```python
# 定义魔术方法 __setitem__()，支持 tree[k] = v 的赋值语法
def __setitem__(self, k, v):
    # 内部直接调用 put() 实例方法
    self.put(k, v)
```
![[file-20261120161715752.png|183]]
>[!notice]
>def `__setitem__` 本身不负责插入树节点，它只是把这个字典赋值的魔术方法的效果改成给二叉查找树插入节点。
>
>原来的插入二叉查找树节点写法（不用魔术方法）：
mytree.put(3, "red")
加了 __setitem__ 之后，等价写法，更好看，像字典：
mytree[3] = "red"
功能完全一样，只是语法糖。
# 查找操作：get 与 \_get
## BinarySearchTree.get() 与 \_get() 方法
BinarySearchTree类中的`get(self, key)` **实例方法**用于在树中查找指定 `key` 对应的节点，并取出其 `payload` **实例属性**。

首先判断 `self.root` **实例属性**是否存在。
若树非空，则调用内部递归**实例方法** `_get(key, self.root)` 获取目标 `TreeNode` 实例；
若返回值 `res` 非空，返回 `res.payload` **实例属性**，否则返回 `None`。
若是空树，也返回`None`。

`_get(self, key, currentNode)` **实例方法**负责递归向下搜索：
遇到空节点（currentNode不存在）返回 `None`；
`currentNode.key == key` 时找到key所在的节点（命中key），并返回 `currentNode`；
在`key < currentNode.key` 时向左子树递归寻找key的所在节点；否则向右子树递归。

```python
def get(self, key):
    # 先判断 root 实例属性是否存在（树是否为空）
    if self.root:
        # 调用内部递归实例方法 _get() 返回节点对象或 None
        res = self._get(key, self.root)
        if res:
            # 找到目标节点，返回其 payload 实例属性
            return res.payload
        else:
            return None
    else:
        return None

def _get(self, key, currentNode):
    # 递归基线条件：当前节点为空，查找失败
    if not currentNode:
        return None
    # 命中目标 key，返回当前 TreeNode 实例
    elif currentNode.key == key:
        return currentNode
    # 目标 key 更小，向左子节点递归
    elif key < currentNode.key:
        return self._get(key, currentNode.leftChild)
    # 目标 key 更大，向右子节点递归
    else:
        return self._get(key, currentNode.rightChild)
```
## 索引取值与归属判断：__getitem__() 与 __contains__()
实现 `__getitem__()` **特殊方法**后，可通过`val = myZipTree['PKU']` 这样的字典风格语法直接获取对应的值。

实现 `__contains__()` **特殊方法**后，可通过 `'PKU' in myZipTree` 语法使用 `in` 运算符进行成员归属判断，内部调用 `_get(key, self.root)` 判断节点是否存在并返回布尔值。

```python
# 定义魔术方法 __getitem__()，支持使用 val = tree[key] 的方式用索引取值
def __getitem__(self, key):
    return self.get(key)

# 定义魔术方法 __contains__()，支持 key in tree 归属判断
def __contains__(self, key):
    if self._get(key, self.root):
        return True
    else:
        return False
```

# 迭代器：__iter__() 中序遍历
## TreeNode.__iter__() 递归生成器
我们可以用for循环枚举字典中的所有key，ADT Map也应该实现这样的迭代器功能。

为了像遍历 Python 字典一样使用 `for key in mytree:` 来枚举 BST 中的所有 `key`，需要在 `BinarySearchTree` **类**中定义 `__iter__()` **特殊方法**作为对外入口，遍历的核心逻辑放在 TreeNode 的 `__iter__` 里面实现。
（在 [[610.二叉查找树及操作#BinarySearchTree 类|BinarySearchTree 类]] 中直接委托给 `self.root.__iter__()`，BST类中的`__iter__()`直接调用的[[610.二叉查找树及操作#TreeNode 类|TreeNode类]]中的同名方法）。
>[! note]
>1. `self` 是 BST 的实例（也就是 mytree）
>2. `self.root` 是 BST 的一个成员属性，它**要么是 None，要么是一个 TreeNode 的实例对象** 
>比如 `self.root = TreeNode(5, "abc")`，那 `self.root` 就是一个 TreeNode 的实例对象
>3. 当 `self.root` 是一个 TreeNode 对象的时候： `self.root.__iter__()` 的意思就是:这个 TreeNode 对象，去调用它自己身上定义的 `__iter__` 方法
>

`TreeNode` **类**中的 `__iter__()` **特殊方法**是一个基于 `yield` 关键字（[[26.推导式与生成器|生成器]]）和for迭代的递归函数，yield是对每次迭代的返回值。
按照“左子树 $\rightarrow$ 当前节点 `key` $\rightarrow$ 右子树”的**中序遍历**顺序依次返回键值。（是树中序遍历的迭代）

```python
# 以下方法定义在 TreeNode 类中
def __iter__(self):
    if self:
        # 若存在左子节点，通过 for 循环递归触发左子树的 __iter__() 魔术方法
        if self.hasLeftChild():
            for elem in self.leftChild:
                yield elem
        
        # 产出当前节点的 key 实例属性
        yield self.key
        
        # 若存在右子节点，通过 for 循环递归触发右子树的 __iter__() 魔术方法
        if self.hasRightChild():
            for elem in self.rightChild:
                yield elem
```

>[!notes] 中序迭代的有序性
>由于 BST 满足左子树键值小于根节点、右子树键值大于根节点的性质，
>通过中序遍历迭代器枚举出的 `key` 序列天然是从小到大有序排列的。
# 删除操作：delete 与 remove
## BinarySearchTree.delete() 与 __delitem__()
`delete(self, key)` **实例方法**是删除操作的入口：
先使用 `_get(key, self.root)` 找到待删除的节点，再调用 `self.remove(nodeToRemove)` **实例方法**执行具体的树结构调整；
若找不到对应节点，则提示错误信息。
>[!note]
>raise
>使用方法：raise 异常类型(提示字符串)
>如 代码里这句：raise KeyError('Error, key not in tree')
`KeyError`：Python**内置异常类**（找不到键的异常）
括号里的字符串：自定义的错误提示信息，方便人看懂哪里出问题
也可以简写（不推荐，没有提示）：raise KeyError
也可以抛出别的异常，比如 `ValueError`、`IndexError`
 >一旦执行 `raise`：
 >1. **立刻终止当前这段代码的正常执行**，raise 后面的代码不会再运行；
 >2. 把这个异常向上抛，交给调用它的上层代码；
 >3. 如果上层代码**没有用 try-except 捕获这个异常**，程序直接崩溃，控制台打印报错信息。[[25.例外处理#try-except 语句|异常处理]]

当树中节点数 `self.size > 1` 时，
用`_get(key, self.root)`定位目标节点 `nodeToRemove` ，
然后调用 `self.remove(nodeToRemove)` 并将 `self.size` **实例属性**减 `1`。

当树中仅剩 `1` 个根节点（`self.size == 1`）且恰好是我们要删除的节点，直接将 `self.root` **实例属性**置为 `None`，并将 `self.size` 减 `1`。

```python
# 以下方法定义在 BinarySearchTree 类中
def delete(self, key):
    if self.size > 1:
        # 先调用 _get() 实例方法定位待删除的 TreeNode 实例
        nodeToRemove = self._get(key, self.root)
        if nodeToRemove:
            # 找到目标节点，调用 remove() 实例方法将其从树中移除
            self.remove(nodeToRemove)
            self.size = self.size - 1
        else:
            raise KeyError('Error, key not in tree')
    elif self.size == 1 and self.root.key == key:
        # 仅剩唯一根节点且命中，直接置空 root 属性
        self.root = None
        self.size = self.size - 1
    else:
        raise KeyError('Error, key not in tree')
```

同时定义 `__delitem__()` **特殊方法**，即可支持 `del myZipTree['PKU']` 语句删除键值对。
```python
# 定义魔术方法 __delitem__()，定义 del tree[key] 删除语法
def __delitem__(self, key):
    self.delete(key)
```
## BinarySearchTree.remove() 的三种删除情形
在 `delete()` 中用`_get(key, self.root)`找到 `currentNode` 后，最核心也最复杂的是 `remove(self, currentNode)` **实例方法**。
移除一个节点后必须仍然保持 BST 的大小顺序性质，因此按被删节点拥有的子节点数量分为三种情形处理。
### 情形 1：被删的节点没有子节点（叶节点）
直接删除。
叶节点下方没有子树，直接断开其父节点指向它的引用即可。
![[file-20261120194617517.png|371]]

通过 `currentNode.isLeaf()` **实例方法**判定后，判断 `currentNode` 是其父节点的左子节点还是右子节点，并将对应的 `leftChild` 或 `rightChild` **实例属性**设为 `None`。

```python
# 情形 1：currentNode 是叶节点（无任何子节点）
if currentNode.isLeaf():
    if currentNode == currentNode.parent.leftChild: #判断currentNode是否父节点的左孩子
        currentNode.parent.leftChild = None #断开父节点对currentNode的引用
    else: #判断是否父节点的左孩子
        currentNode.parent.rightChild = None #断开父节点对currentNode的引用
```
### 情形 2：被删节点有 1 个子节点
当被删节点只有 `1` 个子节点时，解决的基本思路是将这个唯一的子节点上移，直接替换掉被删节点的位置。
![[file-20261120195035963.png|399]]

由于需要同时维护父子双向指针，替换操作必须区分 **2 × 3 = 6 种情况**：
1.被删节点的唯一子节点是左子节点还是右子节点（2 种），
2.被删节点本身是其父节点的左子节点、右子节点还是整棵树的根节点（3 种）。

在理解这 6 种分支时，可以在纸上画出祖父节点、被删节点与唯一子节点的三层关系图，对照着修改上下双向指针会非常直观。
[[611~612+.BinarySearchTree.remove()图例#被删节点有 1 个子节点的6种情况]]

对于非根节点，只需两步指针修改：
将唯一子节点的 `parent` **实例属性**改为 `currentNode.parent`，
再将 `currentNode.parent` 对应的 `leftChild` 或 `rightChild` **实例属性**指向该唯一子节点。

对于根节点（`else` 分支），
直接调用 `currentNode.replaceNodeData()` **实例方法**，[[610.二叉查找树及操作#^1666cb]]
用唯一子节点的 `key`、`payload`、`leftChild`、`rightChild` **实例属性**原地覆盖该根节点。

```python
# 情形 2：currentNode 恰有 1 个子节点
else:
    # 情况 A：唯一子节点是左子节点
    if currentNode.hasLeftChild():
        if currentNode.isLeftChild():# ①当前节点是其父的左孩子，且A
            currentNode.leftChild.parent = currentNode.parent #唯一子节点的父节点引用给当前节点的父节点
            currentNode.parent.leftChild = currentNode.leftChild #当前节点的父节点（祖父节点）的左孩子指向唯一子节点
        elif currentNode.isRightChild():# ②当前节点是其父的右孩子，且A
            currentNode.leftChild.parent = currentNode.parent #同上
            currentNode.parent.rightChild = currentNode.leftChild #祖父节点的右孩子指向唯一子节点
        else:# ③当前节点是根节点，且A
            # 对当前节点调用 replaceNodeData() 实例方法原地替换数据与子树
            currentNode.replaceNodeData(
                currentNode.leftChild.key,# 传入唯一子节点的key，把当前节点的key换成子节点的key
                currentNode.leftChild.payload,# 传入唯一子节点的数据，把当前节点存的数据（payload=值）换成唯一子节点的数据
                currentNode.leftChild.leftChild,# 传入唯一子节点的左孩子，把当前节点的左孩子指针，指向唯一子节点的左孩子
                currentNode.leftChild.rightChild,# 传入唯一子节点的右孩子，把当前节点的右孩子指针，指向唯一子节点的右孩子
            )
            
    # 情况 B：唯一子节点是右子节点
    else:
        if currentNode.isLeftChild(): # ④当前节点是其父的左孩子，且B
            currentNode.rightChild.parent = currentNode.parent
            currentNode.parent.leftChild = currentNode.rightChild
        elif currentNode.isRightChild(): # ⑤当前节点是其父的右孩子，且B
            currentNode.rightChild.parent = currentNode.parent
            currentNode.parent.rightChild = currentNode.rightChild
        else:# ⑥当前节点是根节点，且B
            # 被删节点本身是根节点，用右子节点的数据原地替换
            currentNode.replaceNodeData(
                currentNode.rightChild.key,
                currentNode.rightChild.payload,
                currentNode.rightChild.leftChild,
                currentNode.rightChild.rightChild,
            )
```
### 情形 3：被删节点有 2 个子节点
当被删节点同时拥有左右两个子节点时，无法简单地将某个子节点直接上移替换。
此时必须找到另一个合适的节点来顶替被删节点，这个节点就是被删节点的**下一个 `key` 值节点**，即被删节点**右子树中 `key` 最小的节点**，称为**后继（Successor）**。
![[file-20261120211137244.png|473]]
	如图所示：二叉搜索树本质对应一个**从小到大排好的有序序列**,图种序列即为`2，5，7，9，11，16，17，29，35，38 `,`5` 是序列里其中一个数。删掉 5 之后，这个位置空出来了，我们需要找一个刚好大于`5`的数替补，维持整体顺序不变。既然大于`5`了，就一定在右子树里，而右子树里刚好大于5（即该右子树的最小key）的**后继**就是`7`了

`remove()` 中情形 3 的处理流程为：
调用 `currentNode.findSuccessor()` **实例方法**找到后继节点 `succ`；
调用 `succ.spliceOut()` **实例方法**将 `succ` 从树中原位置安全摘出；
最后将 `succ.key` 和 `succ.payload` **实例属性**赋给 `currentNode`。

```python
# 情形 3：currentNode 同时拥有左右两个子节点（内部节点）
elif currentNode.hasBothChildren():
    # 调用 TreeNode 实例方法 findSuccessor() 查找右子树中的最小节点
    succ = currentNode.findSuccessor()
    # 调用 TreeNode 实例方法 spliceOut() 将后继节点从原位置摘出
    succ.spliceOut()
    # 用后继节点的键值与数据项覆盖当前节点
    currentNode.key = succ.key
    currentNode.payload = succ.payload
```
#### 寻找后继：TreeNode.findSuccessor() 与 findMin()
在 `TreeNode` **类**中，`findSuccessor()` **实例方法**首先判断当前节点是否有右子节点。
在 `remove()` 的情形 3 中，`currentNode` 必定拥有左右两个子节点，
因此必然进入 `if self.hasRightChild():` 分支，调用 `self.rightChild.findMin()` **实例方法**；
`else` 分支在当前删除场景下不会遇到。

`findMin()` **实例方法**沿着 `leftChild` **实例属性**一路向左下角移动，直到某个节点不再有左子节点，该节点即为当前子树中的最小节点。
```python
# 以下方法定义在 TreeNode 类中
def findSuccessor(self):
    succ = None
    if self.hasRightChild():
        # 在右子树中调用 findMin() 实例方法寻找最小节点
        succ = self.rightChild.findMin()
    else:
        # 当前节点无右子树时的通用后继查找（remove 情形 3 不会进入此分支）
        if self.parent:
            if self.isLeftChild():
                succ = self.parent
            else:
                self.parent.rightChild = None
                succ = self.parent.findSuccessor()
                self.parent.rightChild = self
    return succ

def findMin(self):
    current = self
    # 不断沿着 leftChild 实例属性向左下角查找
    while current.hasLeftChild():
        current = current.leftChild
    return current
```
#### 摘出节点：TreeNode.spliceOut()
`spliceOut()` **实例方法**用于将找到的后继节点 `succ` 从原位置摘出。

由于 `succ` 是通过 `findMin()` 沿着左指针一路走到“左下角”找到的，它**绝对不可能再有左子节点**。
因此，在 `remove()` 的情形 3 中，`spliceOut()` 只会遇到两种情况：
后继节点本身是叶节点（直接置空其父节点对应指针），
或者后继节点仅带有一个右子节点（将右子节点上移顶替后继节点的位置，并修正双向指针）；
`if self.hasLeftChild():` 分支在此场景下不会遇到。

```python
# 以下方法定义在 TreeNode 类中
def spliceOut(self):
    # 情况 1：摘出叶节点
    if self.isLeaf():
        if self.isLeftChild():
            self.parent.leftChild = None
        else:
            self.parent.rightChild = None
    # 情况 2：摘出带有子节点的节点
    elif self.hasAnyChildren():
        if self.hasLeftChild():
            # remove 情形 3 中，后继节点不可能有左子节点，不会进入此分支
            if self.isLeftChild():
                self.parent.leftChild = self.leftChild
            else:
                self.parent.rightChild = self.leftChild
            self.leftChild.parent = self.parent
        
        else:
            # 摘出带右子节点的节点：让右子节点顶替当前节点位置
            if self.isLeftChild():
                self.parent.leftChild = self.rightChild
            else:
                self.parent.rightChild = self.rightChild
            self.rightChild.parent = self.parent
```
# 二叉查找树的算法分析（以 put 为例）
二叉查找树的性能决定因素在于树的**高度（最大层次）**，而树的高度又直接受数据项 `key` **插入顺序**的影响（[[202.大O表示法|大O表示法]]）。
## 随机分布与平衡情况
如果待插入的 `key` 列表是**随机分布**的，那么大于和小于根节点 `key` 的键值数量大致相等。
此时 BST 的高度约为 $\log_2 n$（$n$ 为节点总数），这样的树就是**平衡树**，`put()` **实例方法**的最差时间复杂度为 $O(\log_2 n)$。
## 极端有序分布与退化情况
如果 `key` 列表出现**极端分布**（例如按照从小到大的顺序依次插入 `10, 20, 30, 40, 50`），每个新节点都会挂在前一个节点的右指针上，整棵树退化为一条右斜单链。
![[file-20261120223836067.png|185]]
此时树的高度为 $n$，`put()` **实例方法**的性能退化为 $O(n)$，其余查找（`get`）和删除（`delete`）方法也会同样退化为 $O(n)$。

>这正是后续引入自平衡二叉查找树（如 AVL 树）的核心动机。
