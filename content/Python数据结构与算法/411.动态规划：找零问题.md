# 记忆化与动态规划的对比
## 记忆化（Memoization / 函数值缓存/备忘录）
中间结果记录可以很好解决找零兑换问题。
实际上，这种方法还不能称为动态规划，而是叫做 **“memoization（记忆化/函数值缓存）”** 的技术提高了递归解法的性能。

**无缓存（No Caching）**：每个多步请求都被逐一独立重复处理（Each Multi-Step Request Is Processed One-by-One）。
**有缓存（Caching）**：将计算过的中间数据保存在缓存（Cache）中，后续相同请求直接接收计算结果的副本（Subsequent Requests Receive a Copy of the Result）。
# 动态规划解法的核心思想
## 自底向上的递加策略
动态规划算法采用了一种 **更有条理的方式** 来得到问题的解。
找零兑换的动态规划算法从 **最简单的“1分钱找零”** 的最优解开始，**逐步递加上去**，直到我们需要的找零钱数。
在找零递加的过程中，设法保持 **每一分钱的递加都是最优解**，一直加到求解找零钱数，自然得到最优解。
## 最优子结构性质
递加的过程能保持最优解的 **关键** 是，其 **依赖于更少钱数最优解的简单计算**，而更少钱数的最优解已经得到了。
**问题的最优解包含了更小规模子问题的最优解**，这是一个最优化问题能够用动态规划策略解决的 **必要条件**。

以币值体系 $\{1, 5, 10, 25\}$ 求解 `originalamount` 找零兑换问题，具体状态转移公式如下：

$$numCoins = \min \begin{cases} 1 + numCoins(originalamount - 1) \\ 1 + numCoins(originalamount - 5) \\ 1 + numCoins(originalamount - 10) \\ 1 + numCoins(originalamount - 25) \end{cases}$$
# 动态规划算法：构建兑换表
## 解决11分钱的兑换问题
采用动态规划来解决11分钱的兑换问题，从1分钱兑换开始，逐步建立一个兑换表。
![[file-20261104132840144.png|257]]
计算11分钱的兑换法，执行如下三个步骤：
首先减去1分硬币，剩下10分钱查表最优解是 `1`，总硬币数为 $1 + 1 = 2$。
然后减去5分硬币，剩下6分钱查表最优解是 `2`，总硬币数为 $1 + 2 = 3$。
最后减去10分硬币，剩下1分钱查表最优解是 `1`，总硬币数为 $1 + 1 = 2$。
通过上述最小值比较得到11分钱的最优解：**2个硬币**。
![[file-20261104132908477.png|318]]
## 动态规划算法代码实现
```python
# 定义动态规划找零函数 dpMakeChange()
# 参数：coinValueList 列表对象（币值体系）、change 整型变量（目标找零钱数）、minCoins 列表对象（记录各分钱最少硬币数的兑换表）
def dpMakeChange(coinValueList, change, minCoins):
    # 调用 range() 类（构造器）生成从 1 到 change 的整数序列，从1分开始到change逐个计算最少硬币数
    for cents in range(1, change + 1):
        # 1. 初始化一个最大值（全部使用1分硬币兑换的情况），赋值给局部变量 coinCount
        coinCount = cents
        # 2. 减去每个硬币，向后查最少硬币数，同时记录总的最少数
        # 使用列表推导式筛选出小于等于当前钱数 cents 的硬币面值 c
        for j in [c for c in coinValueList if c <= cents]:
            # 访问 minCoins 列表对象的索引元素，判断查表所得子问题最优解加 1 是否小于当前 coinCount 变量
            if minCoins[cents - j] + 1 < coinCount:
                coinCount = minCoins[cents - j] + 1
        # 3. 得到当前最少硬币数，记录到 minCoins 列表对象中
        minCoins[cents] = coinCount
    # 循环结束，访问 minCoins 列表对象的索引属性返回最后一个结果（最优解）
    return minCoins[change]

# 调用 print() 函数输出调用 dpMakeChange() 函数的返回值
print(dpMakeChange([1, 5, 10, 21, 25], 63, [0] * 64))
```

## 动态规划的核心特征总结
 `dpMakeChange()` 函数 **并不是递归函数**。虽然这个问题是从递归算法开始解决，但最终我们得到了一个更有条理的高效 **非递归算法**。 
 动态规划中最主要的思想是：从 **最简单情况** 开始到达所需找零的循环，其每一步都 **依靠以前的最优解** 来得到本步骤的最优解，直到得到答案。
# 动态规划算法扩展：跟踪硬币组合
## 扩展思路与回溯原理
前面的算法已经得到了最少硬币的数量，但没有返回硬币如何组合。 
扩展算法的思路很简单，只需要在生成最优解列表同时 **跟踪记录** 所选择的那个硬币币值即可。
在得到最后的解后，减去选择的硬币币值，**回溯** 到表格之前的部分找零，就能逐步得到每一步所选择的硬币币值。
## 动态规划算法扩展代码
```python
# 定义扩展后的动态规划找零函数 dpMakeChange()，新增 coinsUsed 列表参数用于记录每一步最后加入的硬币币值
def dpMakeChange(coinValueList, change, minCoins, coinsUsed):
    # 调用 range() 类（构造器）遍历从 0 到 change 的每一分钱
    for cents in range(change + 1):
        coinCount = cents
        newCoin = 1  # 初始化局部变量 newCoin，默认新加硬币面值为 1
        for j in [c for c in coinValueList if c <= cents]:
            if minCoins[cents - j] + 1 < coinCount:
                coinCount = minCoins[cents - j] + 1
                newCoin = j  # 对应最小数量，记录当前所减的硬币面值到 newCoin 变量
        minCoins[cents] = coinCount
        coinsUsed[cents] = newCoin  # 将本步骤新加的1个硬币面值记录到 coinsUsed 列表对象中
    return minCoins[change]

# 定义打印硬币组合的回溯函数 printCoins()
def printCoins(coinsUsed, change):
    coin = change  # 初始化待回溯钱数变量 coin
    while coin > 0:
        # 访问 coinsUsed 列表对象的索引元素，获取当前钱数最后使用的硬币面值并赋值给 thisCoin 变量
        thisCoin = coinsUsed[coin]
        # 调用 print() 函数打印当前选中的硬币面值
        print(thisCoin)
        # 减去已选择的硬币币值，回溯到表格之前的部分找零
        coin = coin - thisCoin

# 定义测试变量并调用函数验证
amnt = 63
clist = [1, 5, 10, 21, 25]
coinsUsed = [0] * (amnt + 1)  # 初始化记录所选硬币的列表对象
coinCount = [0] * (amnt + 1)  # 初始化记录最少硬币数的列表对象

print("Making change for", amnt, "requires")
print(dpMakeChange(clist, amnt, coinCount, coinsUsed), "coins")
print("They are:")
printCoins(coinsUsed, amnt)
print("The used list is as follows:")
print(coinsUsed)
```
