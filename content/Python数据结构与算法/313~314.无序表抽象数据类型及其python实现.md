# 什么是列表（List）
## 列表的地位与基本概念
在前面基本数据结构的讨论中，采用 Python 原生的 `list` 数据类型实现了 [[301~302.线性结构及栈抽象数据类型#什么是栈|栈]]、[[308~309.队列抽象数据类型与热土豆问题#什么是队列|队列]] 等多种 [[301~302.线性结构及栈抽象数据类型#什么是线性结构|线性结构]]。

列表（List）是一种简单强大的数据集结构，提供了丰富的操作接口。
但并不是所有的编程语言都原生提供了 `List` 数据类型，有时候需要程序员自己从底层实现。
## 无序表的定义
列表是一种数据项按照 **相对位置** 存放的数据集。
特别的，被称为 **“无序表（unordered list）”** 。
其中数据项只按照存放位置来索引，如第 1 个、第 2 个……、最后一个等（数据项之间不按数值大小排序）。
为了简单起见，假设表中不存在重复数据项。

如一个考试分数的集合“54, 26, 93, 17, 77 和 31”，如果用无序表来表示，就是 `[54, 26, 93, 17, 77, 31]`。
# 抽象数据类型：无序表 List
## 操作定义
抽象数据类型无序表 `List` 由如下操作定义：
`List()`类构造器：创建一个空列表对象，无参数，返回值为空列表。
`add(item)`方法：添加一个新数据项 `item` 到列表中，假设 `item` 原先不存在于列表中，无返回值。
`remove(item)`方法：从列表中移除数据项 `item`，列表被修改，假设 `item` 原先应存在于表中，无返回值。
`search(item)`方法：在列表中查找数据项 `item`，返回布尔类型值（`True` 或 `False`）。
`isEmpty()`方法：检测并返回列表是否为空，返回布尔类型值。
`size()`方法：返回列表包含了多少数据项，返回值为整数。
`append(item)`方法：添加一个数据项 `item` 到表末尾，假设 `item` 原先不存在于列表中，无返回值。
`index(item)`方法：返回数据项 `item` 在表中的位置序号，假设 `item` 原先存在于表中，返回值为整数。
`insert(pos, item)`方法：将数据项 `item` 插入到位置 `pos`，假设 `item` 原先不存在于列表中，同时原列表具有足够多个数据项，能让 `item` 占据位置 `pos`，无返回值。
`pop()`方法：从列表末尾移除并返回数据项，假设原列表至少有 1 个数据项。
`pop(pos)`方法：移除并返回位置为 `pos` 的数据项，假设原列表存在位置 `pos`。
# 采用链表实现无序表
## 链式存储的基本思想
为了实现无序表数据结构，可以采用**链接表**（Linked List，简称链表）的方案。

虽然列表数据结构要求保持数据项的前后相对位置，但这种前后位置的保持，**并不要求数据项依次存放在连续的存储空间**。

如下图，数据项在内存中的存放位置并没有固定规则，可以完全分散。
只要在数据项之间建立显式的 **链接指向（引用指针）**，就可以保持其前后相对位置。
![[file-20261030194747663.png|294]]
在链表中，第一个和最后一个数据项需要显式标记出来：
第一个数据项是队首（Head），作为访问整条链表的入口。
最后一个数据项是队尾（End），其后继引用标记为空，表示后面再无数据了。
## 链表的基本元素：节点 Node
链表实现的最基本元素是节点（Node）。

按照 [[20.对象是什么？|对象 = 属性 + 方法]] 与 [[21.类的定义与调用#类的定义与调用|面向对象类的机制]]，将节点抽象为独立的 `Node` 类。

每个节点至少要包含 2 个信息（内部属性）：
`data`属性：数据项本身。
`next`属性：指向下一个节点的引用信息。
注意：`next` 属性为 `None` 的意义是“没有下一个节点了”（接地），这个边界标记非常重要。
![[file-20261030194839893.png|281]]
### Node 类的 Python 代码实现
```python
class Node:
    def __init__(self, initdata):
        # 初始化节点对象的内部属性
        self.data = initdata    # 数据项属性：保存数据项本身
        self.next = None        # 后继引用属性：初始为 None 表示没有下一个节点

    def getData(self):
        # 获取节点数据项方法
        return self.data

    def getNext(self):
        # 获取下一节点引用方法
        return self.next

    def setData(self, newdata):
        # 修改节点数据项方法
        self.data = newdata

    def setNext(self, newnext):
        # 修改下一节点引用方法
        self.next = newnext
```
实例化与方法调用示例：
```python
>>> temp = Node(93)      # 调用 Node() 类构造器创建包含 93 的节点对象 temp
>>> temp.getData()       # 调用 temp 对象的 getData() 方法获取数据项
93
```

可以采用链接节点的方式构建数据集来实现无序表 `UnorderedList` 类。

链表的第一个和最后一个节点最重要。如果想访问到链表中的所有节点，就必须从第一个节点开始沿着 `next` 链接遍历下去。
![[file-20261030195144462.png|312]]

所以无序表必须要有对第一个节点的引用信息：
在 `UnorderedList` 类中设立一个 `head` 属性，保存对第一个节点的引用。
空表的 `head` 属性为 `None`。
随着数据项的加入，无序表的 `head` 属性始终指向链条中的第一个节点。
![[file-20261030195044548.png|276]]
>[!attention] 对象与数据的解耦
>注意！无序表 `mylist` 对象本身并不直接包含数据项（数据项保存在各个独立的 `Node` 节点对象中）。
>`mylist` 对象内部包含的 `head` 属性只是对首个节点 `Node` 的引用。
![[file-20261030195259651.png|355]]
### UnorderedList 类构造器与 isEmpty() 方法
判断空表的 `isEmpty()` 方法很容易实现，只需检查 `self.head` 属性是否为 `None`：
```python
class UnorderedList:
    def __init__(self):
        # 初始化表头引用属性，空表时指向 None
        self.head = None

    def isEmpty(self):
        # 判空方法：检查 head 属性是否为 None
        return self.head == None
```
实例化与属性/方法测试：
```python
>>> mylist = UnorderedList()   # 调用 UnorderedList() 类构造器创建空无序表对象
>>> print(mylist.head)         # 访问 mylist 对象的 head 属性
None
>>> mylist.isEmpty()           # 调用 mylist 对象的 isEmpty() 方法
True
```

# 无序表核心方法的链表实现
## add(item) 方法：表头插入
### 插入位置的选择与性能考量
接下来考虑如何实现向无序表中添加数据项，实现 `add` 方法。
由于无序表并没有限定数据项之间的顺序，新数据项理论上可以加入到原表的任何位置。

由链表结构我们知道，要访问到整条链上的所有数据项，都必须从表头 `head` 开始沿着 `next` 链接逐个向后查找。
按照实现的性能考虑，应添加到 **最容易加入** 的位置上——所以添加新数据项最快捷的位置是 **表头**（整个链表的首位置），无需遍历。

![[file-20261030195441156.png|351]]
### 倒序形成过程
如果依次调用 `add` 方法加入 `31`、`77`、`17`、`93`、`26`、`54`：
`31` 是最先被加入的数据项，随着后续节点不断在表头插入，它被推到最后，成为链表中最后一个项。
而 `54` 是最后被加入的，直接挂在 `head` 处，成为链表第一个数据项。

最终形成的链表次序为：`54 -> 26 -> 93 -> 17 -> 77 -> 31`。
![[file-20261030195719575.png|236]]
### 代码实现与链接次序陷阱
```python
def add(self, item):
    # 调用 Node() 类构造器创建保存 item 的新节点对象 temp
    temp = Node(item)
    # Step 1：调用 temp 对象的 setNext() 方法，将新节点的 next 指向原表头首节点
    temp.setNext(self.head)
    # Step 2：修改 self.head 属性，使其指向新节点 temp
    self.head = temp
```

>[!attention] 链接次序绝对不可颠倒（防止断链）
>在 `add` 方法中，两步指针修改的链接次序很重要！
>如果次序错误，颠倒写成：
>```python
>self.head = temp              # 次序错误：先修改了 head 属性
>temp.setNext(self.head)       # 导致 temp 的 next 指向自身形成自环
>```
>一旦先执行 `self.head = temp`，外部对原链表首节点的唯一引用即被覆盖丢失，原链表中后续所有节点（`93 -> 17 -> 77 -> 31`）都将失去外部引用（no external reference），导致整条链表发生**断链**并造成数据丢失。

![[file-20261030201155049.png|336]]
## size() 方法：遍历计数
`size` 方法从链条头 `head` 开始遍历到表尾，同时用整型变量 `count` 累加经过的节点个数。
![[file-20261030200727516.png|289]]
```python
def size(self):
    current = self.head              # 将游标引用 current 指向表头属性 self.head
    count = 0                        # 初始化计数器变量 count
    while current != None:           # 只要当前节点不为 None，循环继续
        count = count + 1            # 累加节点计数
        current = current.getNext()  # 调用 current 节点的 getNext() 方法向后步进
    return count                     # 返回节点总数
```
## search(item) 方法
[[501.顺序查找算法及分析]]
`search` 方法从链表头 `head` 开始遍历到表尾，同时判断当前节点的数据项是否等于目标 `item`。
```python
def search(self, item):
    current = self.head              # 游标引用 current 从表头 self.head 出发
    found = False                    # 初始化布尔标志变量 found 为 False
    while current != None and not found:
        # 调用 current 节点的 getData() 方法获取数据项并与 item 比较
        if current.getData() == item:
            found = True             # 找到目标，修改标志变量为 True
        else:
            # 未找到，调用 getNext() 方法令 current 移向下一个节点
            current = current.getNext()
    return found
```
## remove(item) 方法：双指针协同删除
### 删除难点与前驱指针维护
首先要找到 `item`，这个寻位过程跟 `search` 一样，但在删除节点时，需要特别的技巧。

当找到目标时，`current` 指向的是当前匹配数据项的节点。
而删除需要把 **前一个节点** 的 `next` 指向 `current` 的下一个节点。
由于单向链表无法由当前节点逆向回溯前前面的节点，所以我们在移动 `current` 查找的同时，还要额外维护前一个（`previous`）节点的引用。
![[file-20261030200859227.png|325]]
### 两种删除情况的区分
找到 `item` 之后，`current` 指向 `item` 节点，`previous` 指向前一个节点，开始执行删除，需要区分两种情况。

`current` 是首个节点：
此时 `previous` 为 `None`。
直接让表头 `head` 属性指向 `current` 的 `next`
（即 `self.head = current.getNext()`）。

`current` 是位于链条中间的节点：
此时 `previous` 不为 `None`。
调用 `previous` 节点的 `setNext()` 方法，让 `previous` 指向 `current` 的 `next`
（即 `previous.setNext(current.getNext())`）。
![[file-20261030201407537.png|313]]
### remove(item) 代码实现
```python
def remove(self, item):
    current = self.head
    previous = None                           # 放置前驱指针 previous，初始为 None
    found = False                             # 放置布尔 Flag 标志变量
    
    # 寻位循环：寻找待删除节点
    while not found:
        if current.getData() == item:         # 调用 getData() 方法比对数据项
            found = True
        else:
            # 交替的引用：previous 先跟进到 current，current 再向后移动一步
            previous = current
            current = current.getNext()       # 调用 getNext() 方法步进
            
    # 删除的分支判断
    if previous == None:
        # 在首节点找到：直接修改 head 属性指向 current 的下一个节点
        self.head = current.getNext()
    else:
        # 在中间找到：调用 previous 的 setNext() 方法绕过 current 节点
        previous.setNext(current.getNext())
```

>[!notes] 底层存储逻辑对比：链表 vs Python 内置 list
>由此可以发现，Python 内置的列表 `list` 的底层，和我们用链表实现的逻辑是不一样的。
>[[6.容器类型#列表和元组|列表]] 是基于顺序存储（连续内存动态数组）实现的，在尾部 `append()` 最快捷（平摊 $O(1)$），而在表头 `insert(0, item)` 需要将后续所有元素向右搬移（$O(n)$）。
>而单向链表仅维护 `head` 引用，在表头 `add(item)` 最快捷（$O(1)$），若在表尾追加反而需要从头遍历整条链表（$O(n)$）。
