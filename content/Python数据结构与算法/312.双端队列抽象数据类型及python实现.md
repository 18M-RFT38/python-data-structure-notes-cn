# 什么是双端队列
双端队列 Deque 是一种有次序的数据集合。

跟队列相似，其两端可以称作“首 front”端与“尾 rear”端。
但与 [[308~309.队列抽象数据类型与热土豆问题#什么是队列|队列]] 不同的是，双端队列中的数据项既可以从队首加入，也可以从队尾加入；数据项同样可以从两端移除。

某种意义上说，双端队列集成了 [[301~302.线性结构及栈抽象数据类型#什么是栈|栈]] 和 [[308~309.队列抽象数据类型与热土豆问题#什么是队列|队列]] 的能力。

>[!notes] 双端队列并不具有内在的次序约束
>双端队列本身并不具有内在的 LIFO 或者 FIFO 特性。
>如果用双端队列来模拟栈或队列，**需要由使用者自行维护操作的一致性**——即自行决定每次只从固定一端进行添加与移除，而不是在两端随意操作。

# 抽象数据类型Deque
## 核心概念
抽象数据类型 Deque 是一个有次序的数据集。
数据项既可以从队首加入或移除，也可以从队尾加入或移除。
Deque 不强制任何一端的操作次序。
## 操作定义
抽象数据类型 Deque 由如下操作定义：

Deque()类构造器：创建一个空双端队列对象，返回值为 Deque 对象。
addFront(item)方法：将数据项 item 添加到队首，无返回值。
addRear(item)方法：将数据项 item 添加到队尾，无返回值。
removeFront()方法：从队首移除数据项，返回值为队首数据项，队列被修改。
removeRear()方法：从队尾移除数据项，返回值为队尾数据项，队列被修改。
isEmpty()方法：测试是否为空双端队列，返回值为布尔值（True 或 False）。
size()方法：返回双端队列中数据项的个数，返回值为整数。

# 用Python实现ADT Deque
## 面向对象实现方案
采用 Python 原生的动态数组 list 来容纳 Deque 的数据项。
按照 [[21.类的定义与调用#类的定义与调用|面向对象类的机制]] ，将 ADT Deque 封装为独立的 Class。

将 **List 下标 0** 作为双端队列的**尾端（Rear**），
**List 下标 -1** 作为双端队列的**首端（Front）**。
这样一来，队首操作对应列表末端的 append() 与 pop()，
队尾操作对应列表首端的 insert(0, item) 与 pop(0)。

实现源码如下：

```python
class Deque:
    def __init__(self):
        # 初始化内部列表容器
        self.items = []

    def isEmpty(self):
        # 判空方法：判断内部列表是否为空列表
        return self.items == []

    def addFront(self, item):
        # 队首入队方法：在 List 末端追加新项
        # 调用 list 对象的 append() 方法
        self.items.append(item)

    def addRear(self, item):
        # 队尾入队方法：在 List 首端插入新项
        # 调用 list 对象的 insert() 方法
        self.items.insert(0, item)

    def removeFront(self):
        # 队首出队方法：从 List 末端弹出项
        # 调用 list 对象的 pop() 方法
        return self.items.pop()

    def removeRear(self):
        # 队尾出队方法：从 List 首端弹出项
        # 调用 list 对象的 pop() 方法
        return self.items.pop(0)

    def size(self):
        # 查询大小方法：返回列表长度
        # 调用内置 len() 函数
        return len(self.items)
```

## 复杂度分析与实现权衡
在上述基准实现中：
addFront(item)方法与 removeFront()方法：时间复杂度为 $O(1)$。因为对应的 append() 与 pop() 操作在列表末端执行，无需搬移任何元素。
addRear(item)方法与 removeRear()方法：时间复杂度为 $O(n)$。因为对应的 insert(0, item) 与 pop(0) 操作在列表首端执行，原有所有元素都要在内存中整体向右或向左搬移一位。

>[!tips] 工程性能优化与 collections.deque
>在生产级代码或对性能有严苛要求的算法中，推荐使用 Python 标准库中的 collections.deque 双端队列。
>collections.deque 基于双向块链表（Block-linked List）构建，从左端或右端添加与弹出的操作均为稳定的 $O(1)$ 复杂度，两端性能对称。

# 双端队列的应用：回文词判定

## 问题背景
“回文词”指正读和反读都一样的词。
英文示例如 radar、madam、toot；
中文回文句如“上海自来水来自海上”“山东落花生花落东山”。
## 算法思路
用双端队列很容易解决“回文词”问题。

先将需要判定的词从队尾加入 deque。
再从两端同时移除字符并判定是否相同，直到 deque 中剩下 0 个或 1 个字符。
如果两端取出的字符始终一致，则原词是回文；一旦某一对字符不相等，则不是回文。

数据结构设计**不变量**：
采用双端队列存放待判定词的每一个字符。
字符从**队尾（rear）** 依次入队，因此队首对应原词的第一个字符，队尾对应原词的最后一个字符。

单次比对机制：
从**队首 removeFront() 取出第一个字符**，从**队尾 removeRear() 取出最后一个字符**，比对**二者是否相等**。
若相等则继续向内层字符收缩；若不等则立即判定不是回文，提前终止。
当队列中剩余 0 个或 1 个字符时，说明此前所有配对都一致，判定为回文。

## Python代码实现
```python
from pythonds.basic.deque import Deque

def palchecker(aString):
    # 实例化 Deque 类构造器创建字符双端队列
    chardeque = Deque()

    # 将字符串的每个字符逐一从队尾加入队列
    for ch in aString:
        chardeque.addRear(ch) # 调用 Deque 对象的 addRear() 方法

    # 初始化回文标记为 True
    stillEqual = True

    # 比对循环：队列中剩余字符大于 1 个且尚未发现不一致时继续
    while chardeque.size() > 1 and stillEqual: # 调用 Deque 对象的 size() 方法
        # 从队首取出第一个字符
        first = chardeque.removeFront()
        # 从队尾取出最后一个字符
        last = chardeque.removeRear()
        # 两端字符不一致则标记为非回文
        if first != last:
            stillEqual = False

    # 返回最终回文判定结果
    return stillEqual

# 测试用例调用
print(palchecker("lsdkjfskf")) # False
print(palchecker("radar"))     # True
```
