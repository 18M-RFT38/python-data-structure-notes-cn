# 被删节点有 1 个子节点的6种情况
被删节点的唯一子节点是左子节点还是右子节点（2 种），
被删节点本身是其父节点的左子节点、右子节点还是整棵树的根节点（3 种）。

|图号|N 的位置|C 的位置|核心操作|
|---|---|---|---|
|1|P 的左孩子|N 的左孩子|P.left = C; C.parent = P|
|2|P 的左孩子|N 的右孩子|P.left = C; C.parent = P|
|3|P 的右孩子|N 的左孩子|P.right = C; C.parent = P|
|4|P 的右孩子|N 的右孩子|P.right = C; C.parent = P|
|5|根节点|N 的左孩子|root = C; C.parent = null|
|6|根节点|N 的右孩子|root = C; C.parent = null|
