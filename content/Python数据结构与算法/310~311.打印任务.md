# 模拟算法：打印任务
## 什么是模拟算法
很多现实世界中的问题，由于随机因素过多或过程极为复杂，无法通过简单的代数公式直接推导出解析解。
[[104~105.算法与计算复杂性#计算复杂性 (Computational Complexity)|计算复杂性]]
**模拟（Simulation）** 是通过编写计算机程序，在计算机内部重现真实系统中的对象实体、交互行为与时间流逝过程，通过多次运行模拟并对运行结果进行统计分析，为现实中的模式设定与资源分配提供决策支持。

模拟算法常用于排队系统（银行网点、机场安检通道、共享打印机）、交通流模拟、网络数据包传输等领域。
## 打印任务的问题背景
多人共享一台打印机，采取“先到先服务”（FIFO）的队列策略来执行打印任务。

在这种设定下，一个首要的问题就是：这种打印作业系统的容量有多大？在能够接受的等待时间内，系统能容纳多少用户以多高频率提交多少打印任务？
### 具体的实例配置
一个实验室，在任意的一个小时内，大约有 10 名学生在场。
这一小时中，每人会发起 2 次左右的打印，每次 1～20 页。
打印机的性能是：
以草稿模式打印的话，每分钟 10 页（速度快，打印质量一般）。
以正常模式打印的话，打印质量好，但速度下降为每分钟 5 页。
### 决策支持问题
问题是：怎么设定打印机的模式，让大家在不会等太久的前提下尽量提高打印质量？
这是一个典型的**决策支持问题**，无法通过确定性规则直接计算得出。
我们要用一段程序来**模拟**这种打印任务场景，然后对程序运行结果进行**统计分析**，以支持对打印机模式设定的**决策**。

## 对象的属性定义
系统包含三个核心对象：打印任务、打印队列、打印机。
[[20.对象是什么？#对象的基本概念|对象 = 属性 + 方法]]
![[file-20261029210433378.png|183]]
### 打印任务（Task）
生成时间戳：记录作业被提交的时刻。
打印页数：每次打印作业包含的页数（1～20 页）。
### 打印队列（PrintQueue）
具有 FIFO（先进先出）性质的打印任务队列。
任务排队等待打印，先提交的作业先出队被打印。
### 打印机（Printer）
打印速度属性：每分钟打印页数（5 PPM 或 10 PPM）。
是否忙属性：当前是否有作业正在打印。
当前作业属性：正在打印的作业对象。
倒计时属性：当前作业剩余所需的打印秒数，回 0 表示打印完毕，可以处理下一个作业。
## 打印过程的数学建模
### 生成和提交打印任务
确定生成概率：实例设定为每小时会有 10 个学生提交共 20 个作业。
$$\frac{20 \text{ tasks}}{1 \text{ hour}} \times \frac{1 \text{ hour}}{60 \text{ minutes}} \times \frac{1 \text{ minute}}{60 \text{ seconds}} = \frac{1 \text{ task}}{180 \text{ seconds}}$$
平均每 180 秒会有 1 个作业生成并提交，离散化到每一秒的概率为 1/180。
确定打印页数：实例为 1～20 页，1～20 页之间出现的概率相同（均匀离散分布）。
### 实施打印
当前的打印作业：正在被打印机处理的作业。
打印结束倒计时：新作业开始打印时计算所需总秒数并启动倒计时，每过 1 秒减 1，减至 0 表示打印完毕，打印机转为空闲。
### 模拟时间
统一的时间框架：以**最小单位**（秒）均匀流逝的时间，设定模拟的总结束时间（如 1 小时 = 3600 秒）。
同步所有过程：在一个时间单位（秒）里，对**生成打印任务**和**实施打印**两个过程各处理一次。
# 打印任务模拟流程
## 时间流逝中的处理逻辑
创建打印队列对象。

时间按照秒的单位流逝（秒循环）：
按照概率生成打印作业，加入打印队列。
如果打印机空闲，且队列不空，则取出队首作业打印，记录此作业等待时间。
如果打印机忙，则按照打印速度进行 1 秒打印（内部倒计时减 1）。
如果当前作业打印完成，则打印机进入空闲。

时间用尽，开始统计平均等待时间和队列剩余未完成作业数。
## 作业时间的具体计算
### 作业的等待时间
生成作业时，记录生成的当前时间戳。
开始打印时，当前时间减去生成时间即可。

等待时间 = 开始打印时的当前秒数 - 任务提交时间戳。
>[!attention] 这里的等待时间是指在队列中排队等待的纯滞留耗时，不包含打印作业本身的打印服务时间。
### 作业的打印时间
生成作业时，随机记录作业的页数。
开始打印时，页数除以打印速度即可。

耗时秒数 = 页数 * 60 / 打印速度。
# Python面向对象代码实现
## 打印机类 Printer
```python
from pythonds.basic.queue import Queue
import random

class Printer:
    def __init__(self, ppm):
        self.pagerate = ppm        # 打印速度属性（每分钟打印页数）
        self.currentTask = None    # 打印任务属性（当前作业对象，None表示空闲）
        self.timeRemaining = 0     # 任务倒计时属性（单位：秒）

    def tick(self):                # 打印1秒方法
        if self.currentTask != None:
            self.timeRemaining = self.timeRemaining - 1
            if self.timeRemaining <= 0:
                self.currentTask = None

    def busy(self):                # 打印忙？方法
        if self.currentTask != None:
            return True
        else:
            return False

    def startNext(self, newtask):  # 打印新作业方法
        self.currentTask = newtask
        # 换算公式：页数 * 60秒 / 打印速度
        self.timeRemaining = newtask.getPages() * 60 / self.pagerate
```

## 任务类 Task 与作业生成函数
```python
class Task:
    def __init__(self, time):
        self.timestamp = time                        # 生成时间戳属性
        self.pages = random.randrange(1, 21)         # 打印页数属性：调用 random.randrange()函数 生成1~20随机整数

    def getStamp(self):                              # 获取生成时间戳方法
        return self.timestamp

    def getPages(self):                              # 获取打印页数方法
        return self.pages

    def waitTime(self, currenttime):                 # 计算等待时间方法
        return currenttime - self.timestamp

def newPrintTask():                                  # 1/180概率生成作业函数
    num = random.randrange(1, 181)                   # 调用 random.randrange()函数 生成1~180随机整数
    if num == 180:
        return True
    else:
        return False
```

## 模拟主函数 simulation
```python
def simulation(numSeconds, pagesPerMinute):
    labprinter = Printer(pagesPerMinute)             # 实例化 Printer类 创建打印机对象
    printQueue = Queue()                             # 实例化 Queue类 创建打印队列对象
    waitingtimes = []                                # 记录每个作业等待时间的列表

    for currentSecond in range(numSeconds):          # 时间流逝：按秒递增循环
        if newPrintTask():                           # 调用 newPrintTask()函数 判定是否产生新作业
            task = Task(currentSecond)               # 实例化 Task类 创建新任务对象
            printQueue.enqueue(task)                 # 调用 enqueue()方法 入队

        if (not labprinter.busy()) and (not printQueue.isEmpty()):
            nexttask = printQueue.dequeue()          # 调用 dequeue()方法 出队
            waitingtimes.append(nexttask.waitTime(currentSecond))  # 调用 waitTime()方法 并追加进列表
            labprinter.startNext(nexttask)           # 调用 startNext()方法 启动打印

        labprinter.tick()                            # 调用 tick()方法 推进1秒打印

    averageWait = sum(waitingtimes) / len(waitingtimes) if waitingtimes else 0.0  # 计算平均等待时间
    print("Average Wait %6.2f secs %3d tasks remaining." %
          (averageWait, printQueue.size()))          # 调用 size()方法 获取队列积压任务数
```

# 模拟运行与决策分析
## 正常模式（5 PPM）运行分析
按 5 PPM、1 小时（3600 秒）的设定，模拟运行 10 次。

```python
for i in range(10):
    simulation(3600, 5)
```

运行结果特征：
总平均等待时间为 93.1 秒。
最长的平均等待时间达到 164 秒，最短的平均等待时间为 26 秒。
10 次模拟中有 3 次模拟结束时还有作业没开始打印（队列积压）。

## 草稿模式（10 PPM）运行分析
提升打印速度到 10 PPM、1 小时（3600 秒）的设定，同样模拟运行 10 次。
```python
for i in range(10):
    simulation(3600, 10)
```
实测输出数据：
![[file-20261029211003063.png|248]]

运行结果特征：
总平均等待时间下降为 12 秒。
最长的平均等待时间为 35 秒，最短的平均等待时间为 0 秒（一提交立即打印）。
所有作业在模拟时间内全部打印完毕，没有剩余积压。

## 决策对比与建议
5 PPM 正常模式下，总平均等待时间为 93.1 秒，且存在约 30% 的概率出现下课后作业滞留未印的情况。
10 PPM 草稿模式下，总平均等待时间大幅缩短至 12 秒，等待时间下降近 87%，且任务清空率为 100%。

>[!tips] 运筹与决策建议
>如果实验室更看重打印质量，且能够接受 2~3 分钟的等待时间以及偶发的滞留，可以选择正常模式。
>如果学生对等待时间敏感，要求平均等待时间在 1 分钟以内且不希望下课后产生排队积压，应当将打印机设定为草稿模式。

>[!notes] 统计学补充：右截断数据
>注意在 5 PPM 模式中，3600 秒截止时仍在队列中排队的作业未被计入平均等待时间，因此 93.1 秒是偏乐观的统计值。实际排队体验比数据表现的更为拥堵。
