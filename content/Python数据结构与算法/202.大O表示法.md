# 大O表示法
## 问题规模
上一节实测计时发现，运行时间与具体机器、编程语言和运行时段都有关，需要一种与具体环境无关的指标。
**问题规模**是影响算法执行时间的主要因素。

在前 n 个整数累计求和的算法中，需要累计的整数个数合适作为问题规模的指标。
前 100,000 个整数求和对比前 1,000 个整数求和，算是同一问题的更大规模。

算法分析的目标，是要找出**问题规模**会怎么影响一个算法的执行时间。

## 时间度量：按赋值语句计数
一个算法所实施的**操作数量或步骤数**，可作为独立于具体程序、具体机器的度量指标。

**赋值语句**是一个合适的计量单位，原因在于一条赋值语句同时包含了（表达式）**计算**和（变量）**存储**两个基本资源。（且只有赋值语句同时有计算和存储两个功能的）

除了与计算资源无关的定义语句外，程序中主要就是三种控制流语句和赋值语句，而控制流仅仅起了组织语句的作用，并不实施处理。

### sumOfN 函数的计数

```python
def sumOfN(n):
    theSum = 0                  # 赋值1次
    for i in range(1, n + 1):
        theSum = theSum + i     # 循环赋值n次
    return theSum
```

函数 `sumOfN(n)` 先把 `theSum` 置 0，这是 1 次赋值；接着在 `range(1, n + 1)` 的循环里执行 `theSum = theSum + i`，共 n 次；`return` 不是赋值语句，不计入。

因此对于问题规模 n，赋值语句数量 $T(n)=1+n$。

## 大O化简方法
当 n 很小时，常数项可能起决定性作用；但当 n 越来越大，**最高次项**就越来越重要，其它项对结果的影响越来越小。同时最高次项前面的系数，对于该项的增长速度来说影响也不大。因此大O化简只做三件事：去掉低次项、去掉常数项、去掉最高次项的系数。

例1：$T(n)=1+n$。n 增大时常数 1 越来越无足轻重，去掉 1 保留 n，得 $O(n)$。

例2：$T(n)=5n^2+27n+1005$。n 很大时 $n^2$ 项主导，去掉 $27n+1005$ 和系数 5，得 $O(n^2)$。

## 常见的大O数量级
通常当 n 较小时难以确定数量级，当 n 增长到较大时才容易看出主要变化量级。

| $f(n)$ | 名称 |
|---|---|
| $1$ | 常数 |
| $\log(n)$ | 对数 |
| $n$ | 线性 |
| $n \cdot \log(n)$ | 对数线性 |
| $n^2$ | 平方 |
| $n^3$ | 立方 |

增长由慢到快：$1 < \log n < n < n\log n < n^2 < n^3 < 2^n$。

## 嵌套循环例题的分段计数
这段代码的赋值语句分为 4 个部分，逐段统计。

```python
a = 5
b = 6
c = 10                          # 常数级 3C

for i in range(n):              # 外层 n 次
    for j in range(n):          # 内层 n 次，共 n² 轮
        x = i * i
        y = j * j               # 循环体内三条赋值，合计 3n²
        z = i * j

for k in range(n):              # 循环 n 次，体内两条赋值，共 2n
    w = a * k + 45
    v = b * b

d = 33                          # 1C
```

开头三条常数赋值 `a = 5`、`b = 6`、`c = 10`，共 3 次。

外层 `for i in range(n)` 套内层 `for j in range(n)`，共 $n^2$ 轮；每轮体内 `x = i * i`、`y = j * j`、`z = i * j` 三条赋值，合计 $3n^2$。

`for k in range(n)` 循环执行 n 次，体内 `w = a * k + 45`、`v = b * b` 两条赋值，共 $2n$。

最后 `d = 33` 是 1 次常数赋值。

合计 $T(n)=3+3n^2+2n+1=3n^2+2n+4$，化简保留最高次项并去系数，得 $O(n^2)$。

## 小结
- $T(n)=1+n \Rightarrow O(n)$。
- $T(n)=5n^2+27n+1005 \Rightarrow O(n^2)$。
- $T(n)=3n^2+2n+4 \Rightarrow O(n^2)$。
