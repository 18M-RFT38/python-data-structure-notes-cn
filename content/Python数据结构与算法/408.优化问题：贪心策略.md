# 贪心策略与优化问题
## 找零兑换问题的贪心解法
找零兑换问题是一个经典的优化问题案例。

假设你需要为一家自动售货机厂家编写程序，要求每次找给顾客**最少数量**的硬币。
例如：顾客投入 $1 纸币，购买了 ¢37 的物品，需要找零 ¢63。
此时最少数量的硬币组合是：2个 quarter (¢25)、1个 dime (¢10) 和 3个 penny (¢1)，总共 6 个硬币。
![[file-20261102215901642.png|240]]
在解决这类问题时，人们常常凭直觉采用 **“贪心策略”** 。
具体的执行步骤通常如下：
从最大面值的硬币开始，尽可能多地使用该面值的硬币。
如果还有余额，则继续使用下一个最大面值的硬币，同样尽可能多地使用。
重复上述过程，直到使用最小面额的 penny (¢1) 将余额找齐为止。
## 贪心策略的局限性与失效
然而，贪心策略并非在所有场景下都能得到最优解。

假设由于特殊情况（例如老板将自动售货机出口到 Elbonia 国家），硬币体系中加入了一种面值为 ¢21 的新硬币。
在这种复杂的硬币体系下，如果继续使用贪心策略来找零 ¢63，按照规则会先使用两个 ¢25，剩余 ¢13 再由较小面额凑齐。
这会导致最终硬币数量多于直接使用三个 ¢21（即 21 * 3 = 63，仅需3个硬币）的最优解。
## 贪心策略找零代码实现
每次优先选择当前小于等于剩余找零的最大面值硬币，通过整除运算直接算出该面值最多能兑换的个数，再用求余数运算更新剩余找零金额。

```python
# 定义贪心策略找零函数 greedyMC()，接收硬币面值列表参数 coinValueList 和找零金额参数 change
def greedyMC(coinValueList, change):
    # 调用内置函数 sorted() 对列表参数 coinValueList 进行降序排序（设置关键字参数 reverse=True），返回从大到小排列的新列表变量 sortedCoins
    sortedCoins = sorted(coinValueList, reverse=True)
    # 定义局部整型变量 numCoins 并初始化为 0，用于累加硬币总数量
    numCoins = 0
    # 定义局部列表变量 coinResult，用于记录每种面值硬币的具体兑换结果
    coinResult = []
    
    # 使用 for 循环从大到小遍历排序后的硬币面值列表变量 sortedCoins 中的每个面值变量 coin
    for coin in sortedCoins:
        # 当剩余找零金额变量 change 大于等于当前硬币面值变量 coin 时，优先使用该最大面值
        if change >= coin:
            # 使用整除运算符 // 计算当前面值硬币最多可兑换的个数，赋值给局部变量 count
            count = change // coin
            # 将当前面值的兑换个数变量 count 累加到总硬币数变量 numCoins 中
            numCoins += count
            # 调用列表实例方法 append()，将元组 (面值, 个数) 添加到结果列表变量 coinResult 中
            coinResult.append((coin, count))
            # 使用求余运算符 % 计算兑换后的剩余找零金额，并更新变量 change
            change = change % coin
            
        # 若剩余找零金额变量 change 已降为 0，则无需继续尝试更小面值，使用 break 语句提前结束循环
        if change == 0:
            break
            
    # 返回最少硬币总数变量 numCoins 与具体兑换明细列表变量 coinResult 组成的元组
    return numCoins, coinResult

# 测试 1：标准美元硬币体系兑换 63 分（贪心策略有效，输出 6 个硬币：25*2 + 10*1 + 1*3）
print(greedyMC([1, 5, 10, 25], 63))

# 测试 2：特殊硬币体系（加入 21 分硬币）兑换 63 分（贪心策略失效，输出 6 个硬币，而实际最优解为 3 个 21 分硬币）
print(greedyMC([1, 5, 10, 21, 25], 63))
```

>[!attention] 贪心失效的根本原因
>贪心策略在每一步都只关注当前的局部最优（尽可能使用最大面值），而不会通盘考虑全局最优。在硬币面值体系不规则的情况下，局部最优的累加无法推导至全局最优解。
## 计算机科学中的优化问题
计算机科学领域中的许多算法，其核心目标都是为了寻找特定问题的最优解。

典型的优化问题除了上述的“最小数量集合”外，还包括：
寻找两个地理位置点之间的最短路径。
在数据拟合中找到能最好匹配一系列数据点的直线。
寻找满足一定约束条件的最小数据集合。
