两个单词互为变位词，指字母的种类和个数完全相同、只是排列顺序不同。
例如 `python` 和 `typhon`。
本节用四种不同的算法来解决"判断两个字符串是否互为变位词"的问题，并比较它们的操作次数。可以很好展示同一问题的不同数量级算法。

# 解法1：逐字检查
## 解题思路
将词1中的字符逐个拿到词2中检查是否存在。存在就**打勾**标记，防止同一个字符被重复检查。
如果每个字符都能找到，则两个词是变位词；只要有 1 个字符找不到，就不是变位词。

实现"打勾"标记的技巧，是把词2中已匹配位置的字符设为 `None`。
由于字符串是不可变类型、不能直接改其中某个字符，需要先把词复制到列表中，再修改列表元素，例如 `typhon` 先转成 `['t', 'y', 'p', 'h', 'o', 'n']`，匹配成功的位置改写为 `None`。
![[file-20261027201800038.png|312]]
```python
def anagramSolution1(s1, s2):
    alist = list(s2)#复制s2到列表
    pos1 = 0
    stillOK = True#设置flag
    while pos1 < len(s1) and stillOK:#循环s1的每个字符
        pos2 = 0
        found = False
        while pos2 < len(alist) and not found:
            if s1[pos1] == alist[pos2]:在s2逐个比较
                found = True
            else:
                pos2 = pos2 + 1
        if found:
            alist[pos2] = None#找到就打勾
        else:
            stillOK = False#未找到就失败
        pos1 = pos1 + 1
    return stillOK

print(anagramSolution1('abcd', 'dcba'))
```

函数 `anagramSolution1` 先把 `s2` 复制成列表 `alist`。外层 `while` 循环 `s1` 的每个字符，内层 `while` 在 `alist` 中逐个对比；命中就把该位置置为 `None`（打勾），未命中就令 `stillOK = False`、提前结束。
这是一个外层循环套内层循环的结构。
## 问题规模
词中包含的字符个数n。
主要部分在于两重循环。
外层循环遍历s1每个字符，将内层循环执行n次。
而内层循环在s2中查找字符，每个字符的对比次数，分别是1、2…n中的一个，而且各不相同。
所以总执行次数是1+2+3…+n
可知其数量级为O(n²)

# 解法2：排序比较
## 解题思路
把两个字符串都按照字母顺序排好序，再逐个字符对比：排序结果相同则是变位词，有任何一位不同就不是。以 `python`、`typhon` 为例，两者排序后都得到 `hnopty`，逐位对比一致。

```python
def anagramSolution2(s1, s2):
    #转为列表
    alist1 = list(s1)
    alist2 = list(s2)
    #分别排序
    alist1.sort()
    alist2.sort()
    pos = 0
    matches = True#设置flag
    while pos < len(s1) and matches:
        if alist1[pos] == alist2[pos]:#逐个对比
            pos = pos + 1
        else:
            matches = False
    return matches

print(anagramSolution2('abcde', 'edcba'))
```

函数 `anagramSolution2` 先把两个字符串各自转为列表并分别调用 `sort()` 方法排序，之后用一个 `while` 循环逐个对比排序后的结果。

>[!attention]
>实际实现时通常还应先比较两个字符串的长度。
## 问题规模
粗看上去，本算法只有一个循环，最多执行n次，数量级是O(n）。
但循环前面的两个sort并不是无代价的。
如果查询下后面的章节，会发现排序算法采用不同的解决方案，其运行时间数量级差不多是O(n²)或者O(n1ogn)，大过循环的O(n)。
所以本算法**时间主导的步骤**是**排序**步骤
本算法的**运行时间数量级就等于排序过程**的数量级O(n log n)
# 解法3：暴力法
暴力法的解题思路是：穷尽所有可能组合。
即将 `s1` 中出现的字符进行**全排列**，再查看 `s2` 是否出现在全排列列表中。这里最大的困难是产生 `s1` 所有字符的全排列。
	"全排列"：即把所有可能的组合都列举出来。

根据组合数学的结论，如果 $n$ 个字符进行全排列，其所有可能的字符串个数为 $n!$。
已知 $n!$ 的增长速度甚至超过 $2^n$。
对于 20 个字符长的词，将产生 $20! = 2{,}432{,}902{,}008{,}176{,}640{,}000$ 个候选词；即使每微秒处理 1 个候选词，也需要近 8 万年才能做完所有匹配。
![[file-20261027202530937.png|285]]

结论：暴力法恐怕不能算是个好算法。
# 解法4：计数比较

## 解题思路
对比两个词中每个字母出现的次数，如果 26 个字母出现的次数都相同，这两个字符串就一定是变位词。

具体做法是为每个词设置一个 26 位的计数器，先遍历每个词，在计数器中设定好每个字母出现的次数；计数完成后进入比较阶段，两个字符串的计数器相同，就输出是变位词的结论。
计数完成后进入比较阶段，看两个字符串的计数器是否相同，如果相同就输出是变位词的结论。

```python
def anagramSolution4(s1, s2):
    c1 = [0] * 26
    c2 = [0] * 26
    for i in range(len(s1)):
        pos = ord(s1[i]) - ord('a')
        c1[pos] = c1[pos] + 1#分别计数
    for i in range(len(s2)):
        pos = ord(s2[i]) - ord('a')
        c2[pos] = c2[pos] + 1#分别计数
    j = 0
    stillOK = True
    while j < 26 and stillOK:
        if c1[j] == c2[j]:
            j = j + 1
        else:
            stillOK = False
    return stillOK

print(anagramSolution4('apple', 'pleap'))
```
ord函数是一个内置函数，它用于返回一个字符的Unicode码点，即该字符在Unicode编码表中的数值。所以此处既然是英文字母，所以使用ascii码其实更优。
函数 `anagramSolution4` 先建立两个长度为 26 的计数器 `c1`、`c2`。前两个 `for` 循环分别计数，用 `ord(字母) - ord('a')` 把字母映射成 0 到 25 的下标、对应位置加 1；最后的 `while` 比较两个计数器，26 项全部相等才返回 `True`。

## 问题规模
### 操作次数
计数比较算法中有 3 个循环迭代，但不像解法1那样存在嵌套循环。前两个循环用于对字符串进行计数，操作次数等于字符串长度 $n$；第 3 个循环用于计数器比较，操作次数总是 26 次。
所以总操作次数 $T(n) = 2n + 26$，其数量级为 $O(n)$。
这是一个线性数量级的算法，是 4 个变位词判断算法中性能最优的。
### 存储空间
本算法依赖两个长度为 26 的计数器列表来保存字符计数，相比前 3 个算法需要更多的存储空间。如果考虑由大字符集构成的词（如中文具有上万不同字符），还会需要更多空间。

牺牲存储空间来换取运行时间，或者相反，这种在**时间空间之间的取舍和权衡**，在选择问题解法的过程中经常会出现。
