# 二叉查找树与 ADT Map
## ADT Map 的实现背景
[[513.抽象数据类型映射及python实现]]
在 **ADT Map** 的实现方案中，可以采用不同的数据结构和搜索算法来保存和查找 Key。
前面已经实现了两种方案：
**有序表数据结构 + 二分搜索算法**
**散列表数据结构 + 散列及冲突解决算法**
使用 **二叉查找树（Binary Search Tree，BST）** 保存 Key，同样可以实现 Key 的快速搜索。
## 复习 ADT Map 的核心操作
`Map()` 方法（构造器）：创建一个空映射。
`put(key, val)` 方法：将 `key-val` 关联对加入映射中；如果 `key` 已经存在，则将 `val` 替换旧关联值。
`get(key)` 方法：给定 `key`，返回关联的数据值；如不存在，则返回 `None`。
`del` 语句（对应 `__delitem__()` 魔术方法）：通过 `del map[key]` 的语句形式删除 `key-val` 关联。
`len()` 函数（对应 `__len__()` 魔术方法）：返回映射中 `key-val` 关联的数目。
`in` 运算符（对应 `__contains__()` 魔术方法）：通过 `key in map` 的语句形式，返回 `key` 是否存在于关联中（布尔值）。
# 二叉查找树 BST 的性质
比父节点小的 `key` 都出现在 **左子树**，比父节点大的 `key` 都出现在 **右子树**。
![[file-20261119145848918.png|287]]
按照 `70, 31, 93, 94, 14, 23, 73` 的顺序依次插入节点：
首先插入的 `70` 成为 **树根**。
`31` 比 `70` 小，放到 `70` 的 **左子节点**。
`93` 比 `70` 大，放到 `70` 的 **右子节点**。
`94` 比 `93` 大，放到 `93` 的 **右子节点**。
`14` 比 `31` 小，放到 `31` 的 **左子节点**。
`23` 比 `14` 大，放到 `14` 的 **右子节点**。
`73` 比 `93` 小，放到 `93` 的 **左子节点**。

>[!attention] 树形态敏感性
>插入顺序不同，生成的二叉查找树（BST）形态也不同（极端情况下若按有序序列插入，BST 会退化为单支链表，影响搜索性能）。
# 二叉搜索树的实现：节点和链接结构
实现二叉搜索树需要用到 `BinarySearchTree`（BST）和 `TreeNode` 两个 **类** [[21.类的定义与调用|类的定义与调用]]。
`BinarySearchTree` 类的实例对象通过 `root` **属性** 引用根节点（即 `TreeNode` 类的实例对象）。
## BinarySearchTree 类
`BinarySearchTree` 类用于表示整棵二叉查找树，维护树根引用与节点总数。
```python
# 定义二叉查找树类 BinarySearchTree
class BinarySearchTree:

    # 定义构造方法 __init__()
    def __init__(self):
        # 初始化 root 属性为 None，指向根节点 TreeNode 实例
        self.root = None
        # 初始化 size 属性为 0，记录树中节点数量
        self.size = 0

    # 定义普通实例方法 length()，返回树的大小
    def length(self):
        return self.size

    # 定义魔术方法 __len__()，支持内置函数 len() 直接获取树的大小
    def __len__(self):
        return self.size

    # 定义魔术方法 __iter__()，支持对树进行迭代遍历
    def __iter__(self):
        # 调用根节点对象的 __iter__() 魔术方法实现中序遍历
        return self.root.__iter__()
        # 只要你给类写了 `__iter__`，这个对象就可以被 for 循环遍历
```
## TreeNode 类
`TreeNode` 类用于封装树中的单个节点，包含键、值以及指向左右子节点和父节点的引用 **属性**，并提供节点状态判断与数据替换等 **实例方法**。
```python
# 定义树节点类 TreeNode
class TreeNode:

    # 定义构造方法 __init__()，设置默认参数 None
    def __init__(self, key, val, left=None, right=None, parent=None):
        self.key = key              # key 属性：存储节点的键值
        self.payload = val          # payload 属性：存储节点的数据项（有效载荷）
        self.leftChild = left       # leftChild 属性：引用左子节点
        self.rightChild = right     # rightChild 属性：引用右子节点
        self.parent = parent        # parent 属性：引用父节点

    # 定义实例方法 hasLeftChild()，判断当前节点是否存在左子节点
    def hasLeftChild(self):
        return self.leftChild

    # 定义实例方法 hasRightChild()，判断当前节点是否存在右子节点
    def hasRightChild(self):
        return self.rightChild

    # 定义实例方法 isLeftChild()，短路判断当前节点是否为其父节点的左子节点
    def isLeftChild(self):
        return self.parent and self.parent.leftChild == self

    # 定义实例方法 isRightChild()，短路判断当前节点是否为其父节点的右子节点
    def isRightChild(self):
        return self.parent and self.parent.rightChild == self

    # 定义实例方法 isRoot()，判断当前节点是否为根节点（无父节点）
    def isRoot(self):
        return not self.parent

    # 定义实例方法 isLeaf()，判断当前节点是否为叶节点（既无左子节点也无右子节点）
    def isLeaf(self):
        return not (self.rightChild or self.leftChild) 
        #`not (A or B)` 等价于 `not A and not B`

    # 定义实例方法 hasAnyChildren()，判断当前节点是否至少有一个子节点
    def hasAnyChildren(self):
        return self.rightChild or self.leftChild

    # 定义实例方法 hasBothChildren()，判断当前节点是否同时拥有左右两个子节点
    def hasBothChildren(self):
        return self.rightChild and self.leftChild

    # 定义实例方法 replaceNodeData()，不删除当前节点对象。只是替换当前节点的键值、数据项及左右子节点引用
    def replaceNodeData(self, key, value, lc, rc):
        self.key = key                      # 把当前节点的key换成新key
        self.payload = value                # 把当前节点存的数据（payload=值）换成新值
        self.leftChild = lc                 # 把当前节点的左孩子指针，指向新的左孩子lc
        self.rightChild = rc                # 把当前节点的右孩子指针，指向新的右孩子rc
        # 维护双向指针：调用实例方法 hasLeftChild()，若存在新左子节点，将其 parent 属性指向当前节点
        if self.hasLeftChild():
            self.leftChild.parent = self
        # 维护双向指针：调用实例方法 hasRightChild()，若存在新右子节点，将其 parent 属性指向当前节点
        if self.hasRightChild():
            self.rightChild.parent = self
```

### TreeNode 核心属性说明
`key` **属性**：保存节点的键，用于在二叉查找树中进行大小比较与定位。
`payload` **属性**：保存与 `key` 关联的数据值（有效载荷）。 
`leftChild` **属性**：指向当前节点的左子节点（`TreeNode` 实例或 `None`）。 
`rightChild` **属性**：指向当前节点的右子节点（`TreeNode` 实例或 `None`）。
`parent` **属性**：指向当前节点的父节点（`TreeNode` 实例或 `None`），便于回溯与节点删除操作。
### TreeNode 核心方法说明
`hasLeftChild()` **方法** / `hasRightChild()` **方法**：直接返回 `leftChild` 或 `rightChild` 属性，在布尔上下文中判断是否有对应子节点。 

`isLeftChild()` **方法** / `isRightChild()` **方法**：先判断 `self.parent` 是否存在（避免根节点调用时触发 `AttributeError`），再比较父节点的左/右子节点引用是否等于 `self`。
`isRoot()` **方法**：通过 `not self.parent` 判断当前节点是否为整棵树的根节点。 
`isLeaf()` **方法**：通过 `not (self.rightChild or self.leftChild)` 判断当前节点是否为叶子节点。 

`hasAnyChildren()` **方法** / `hasBothChildren()` **方法**：分别利用逻辑 `or` 和 `and` 判断节点是否拥有任意子节点或同时拥有两个子节点。

`replaceNodeData()` **方法**：更新当前节点的数据和子节点指针后，同步修正新左右子节点的 `parent` **属性**，确保双向链接关系一致。
