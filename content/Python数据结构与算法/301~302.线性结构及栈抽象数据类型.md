# 什么是线性结构

**线性结构**是一种有序数据项的集合，其中每个数据项都有==唯一的前驱和后继==。

除了**第一个没有前驱，最后一个没有后继**。新的数据项加入到数据集中时，只会加入到原有某个数据项之前或之后。具有这种性质的数据集，就称为**线性结构**（Line Structure）。

线性结构总有两端，在不同的情况下，两端的称呼也不同。
有时候称为“左”“右”端、“前”“后”端、“顶”“底”端
![[file-20261027210544327.png|364]]

两端的称呼并不是关键，不同线性结构的关键区别在于**数据项增减的方式**。有的结构只允许数据项从一端添加，而有的结构则允许数据项从两端移除。
![[file-20261027205236757.png|360]]
![[file-20261027205258657.png|400]]
（拿取衣服和盘子：从顶端放/拿，后进先出）
（排队：从后端加人，前端走人，先进先出）

课程从 4 个最简单但功能强大的结构入手研究数据结构：**栈 Stack、队列 Queue、双端队列 Deque、列表 List**。
这些数据集的共同点在于，数据项之间只存在先后的次序关系，都是线性结构。
这些线性结构是应用最广泛的数据结构，它们出现在各种算法中，用来解决大量重要问题。
# 什么是栈

栈是一种有序的数据项集合，只允许在**栈顶**（top）一端进行添加和移除。
另一端则为**栈底**（bottom/base）。
![[file-20261027205837955.png|234]]

距离栈底越近的数据项，留在栈中的时间就越长；而最新加入栈顶的数据项会被最先移除。这种次序通常称为**后进先出**，即**LIFO**（Last In First Out）。
这是一种基于数据项保存时间的次序：保存时间越短的离栈顶越近，保存时间越长的离栈底越近。

栈的特性：反转次序
即进栈和出栈的次序正好相反。
![[file-20261027205948468.png|396]]
（第一个进栈的最后出来，而最后进栈的会第一个出来）

这种访问次序反转的特性，我们在某些计算机操作上碰到过。
如浏览器的“后退back”按钮，最先back的是最近访问的网页
Word的“Undo”按钮，最先撤销的是最近操作
![[file-20261027210249192.png|220]]

# 抽象数据类型Stack
## 核心概念
抽象数据类型“栈”是一个有次序的数据集。
每个数据项仅从“栈顶”一端加入到数据集中、从数据集中移除。
栈具有后进先出（LIFO）的特性。
![[file-20261027220050842.png|303]]
## 操作定义
抽象数据类型“栈”定义为如下的操作：
Stack()类构造器：创建一个空栈，不包含任何数据项。
push(item)方法：将 item 加入栈顶，无返回值。
pop()方法：将栈顶数据项移除，并返回，栈被修改。
peek()方法：“窥视”栈顶数据项，返回栈顶的数据项但不移除，栈不被修改。
isEmpty()方法：返回栈是否为空栈。
size()方法：返回栈中有多少个数据项。

## 用Python实现ADT Stack
### 面向对象机制
在清楚地定义了抽象数据类型Stack之后，看看如何用Python来实现它。

Python的面向对象机制，可以用来实现用户自定义类型：
将 ADT Stack 实现为 Python 的一个 Class；
将 ADT Stack 的操作实现为 Class 的方法。

由于 Stack 是一个数据集，所以可以采用 Python 的原生数据集来实现，课程选用最常用的数据集 List 来实现。
### List末端作为栈顶的实现
Stack 的两端对应 List 设置的细节：可以将 List 的任意一端（index=0 或者 -1）设置为栈顶。

我们先选用 List 的末端（index=-1）作为栈顶。
这样栈的操作就可以通过对 List 的 `append` 方法和 `pop` 方法来实现，非常简单。
![[file-20261027220228918.png|364]]

```python
class Stack:
    def __init__(self):
        self.items = []

    def isEmpty(self):
        return self.items == []

    def push(self, item):
        self.items.append(item)

    def pop(self):
        return self.items.pop()

    def peek(self):
        return self.items[len(self.items)-1]

    def size(self):
        return len(self.items)
```

### 另一个实现版本：List首端作为栈顶
如果我们把 List 的另一端（首端 index=0）作为 Stack 的栈顶，同样也可以实现 Stack。 原理为从 index=0 处进行 `push` 与 `pop` 交互。
![[file-20261027220554481.png|436]]
#### 接口稳定与性能对比
不同的实现方案保持了 ADT 接口的稳定性，但性能有所不同。
**栈顶首端的版本**：其 `push` 方法与 `pop` 方法的时间复杂度为 $O(n)$。
**栈顶尾端的版本**：其 `push` 方法与 `pop` 方法的时间复杂度为 $O(1)$。
