# 什么是队列
队列是一种有次序的数据集合。

其特征是新数据项的添加总发生在一端（**通常称为“尾端”rear**），而现存数据项的移除总发生在另一端（**通常称为“首端 ”front**）。

当数据项加入队列，**首先出现在队尾**，随着队首数据项的移除，它逐渐接近队首。
新加入的数据项必须在数据集末尾等待，而已等待时间最长的数据项则是队首。

这种次序安排的原则称为 **先进先出** ，即 **FIFO** （First-in First-out），或者称为“先到先服务”（first-come first-served）。
队列**仅有一个入口和一个出口**，不允许数据项直接插入队中，也不允许从中间移除数据项。

>[!notes] 线性结构对比
>队列与 [[301~302.线性结构及栈抽象数据类型#什么是栈|栈]] 一样，都是受限的 [[301~302.线性结构及栈抽象数据类型#什么是线性结构|线性结构]] 。
>核心区别在于数据项增减的方式与发生位置：栈是单端操作的后进先出（LIFO），队列是双端操作的先进先出（FIFO）。
## 计算机科学中的队列例子
队列的例子不仅出现在日常生活的排队中，在操作系统和硬件交互中更是极其核心的底层结构。
### 打印队列
一台打印机通常面向多个用户或程序提供打印服务。
打印机的机械打印速度比程序提交打印请求的速度要慢得多。
当有任务正在打印时，后来的打印请求就排成队列，以 FIFO 先进先出的形式在内存/外存缓冲池中等待被顺序处理。
![[file-20261029202624627.png|250]]
### 操作系统进程调度
操作系统核心采用多个队列来对系统中同时运行的进程进行高效调度。
由于系统中**活跃的进程数远多于 CPU 物理核心数**，且有些进程还需要**等待不同类型的 I/O 事件**。
![[file-20261029202751213.png|248]]

调度原则综合了“先到先服务”与“CPU及外设资源充分利用”两个出发点。

调度系统分为**就绪队列（Ready Queue**）与多种**等待队列（Waiting Queues）**：
就绪队列中的进程排队等待获得 **CPU 时间片**执行；
正在运行的进程若发起 I/O 请求，则**阻塞（Block）** 并移入对应的等待队列；
等待的 I/O 事件完成后，进程重新被移回就绪队列尾部等待下一次调度。
### 键盘输入缓冲
用户键盘敲击并不会瞬时显示在屏幕上。
操作系统提供了一个具有队列性质的键盘缓冲区，将尚未显示的敲击字符扫描码暂存其中。
队列的先进先出性质保证了击键字符的输入顺序与屏幕显示的次序完全一致。
# 抽象数据类型Queue
## 核心概念
抽象数据类型 Queue 是一个**有次序的数据集**。
数据项仅添加到 **“尾 rear”端**，而且仅从 **“首 front”端**移除。
Queue 具有 **FIFO** 的操作次序。
## 操作定义
抽象数据类型 Queue 由如下操作定义：
Queue()类构造器：创建一个空队列对象，返回值为 Queue 对象。
enqueue(item)方法：将数据项 item 添加到队尾，无返回值。
dequeue()方法：从队首移除数据项，返回值为队首数据项，队列被修改。
isEmpty()方法：测试是否为空队列，返回值为布尔值（True 或 False）。
size()方法：返回队列中数据项的个数，返回值为整数。

# 用Python实现ADT Queue
## 面向对象实现方案
采用 Python 原生的动态数组 list 来容纳 Queue 的数据项。
按照 [[21.类的定义与调用#类的定义与调用|面向对象类的机制]] ，将 ADT Queue 封装为独立的 Class。

将 **List 首端（索引 0）** 作为队列**尾端（Rear）**，
**List 的末端（索引 -1）** 作为队列**首端（Front）**。
实现源码如下：

```python
class Queue:
    def __init__(self):
        # 初始化内部列表容器
        self.items = []

    def isEmpty(self):
        # 判空方法：判断内部列表是否为空列表
        return self.items == []

    def enqueue(self, item):
        # 入队方法：在 List 首端插入新项作为队尾
        # 调用 list 对象的 insert() 方法
        self.items.insert(0, item)

    def dequeue(self):
        # 出队方法：从 List 末端弹出项作为队首
        # 调用 list 对象的 pop() 方法
        return self.items.pop()

    def size(self):
        # 查询大小方法：返回列表长度
        # 调用内置 len() 函数
        return len(self.items)
```

## 复杂度分析与实现权衡
在上述基准实现中：
enqueue(item)方法：时间复杂度为 $O(n)$。因为向列表首端 insert(0, item) 时，列表内原有的所有元素都要在内存中整体向右搬移一位。
dequeue()方法：时间复杂度为 $O(1)$。列表末端的 pop() 操作无需搬移任何元素。

首尾倒过来的实现方案：
如果将 List 的末端作为队尾，List 的首端作为队首。
此时 enqueue() 对应列表的 append() 方法，时间复杂度降为 $O(1)$；
而 dequeue() 对应列表的 pop(0) 方法，时间复杂度升为 $O(n)$。

无论如何倒换映射方向，基于单原生 List 实现的队列总有一端操作为 $O(n)$。

>[!tips] 工程性能优化与 collections.deque
>在生产级代码或对性能有严苛要求的算法中，推荐使用 Python 标准库中的 collections.deque 双端队列。
>deque 基于双向块链表（Block-linked List）构建，从左端或右端添加与弹出的操作均为稳定的 $O(1)$ 复杂度。

# 队列的应用：热土豆问题（约瑟夫问题）
## 问题背景与原型
热土豆问题来源于儿童游戏“击鼓传花”的变种。
孩子们围成一圈，快速传递一个烫手的“热土豆”。
当鼓声停止时，手里拿着热土豆的孩子立即淘汰出列。

如果去掉外部鼓声的随机性，改为每轮固定传递固定人数，就演变为了计算机科学与离散数学中著名的“约瑟夫问题”（Josephus Problem）。
传说犹太历史学家约瑟夫斯和 39 名同胞在反抗罗马失败后困于洞穴，众人决定围坐成一圈殉难，报数 1 到 7，报到 7 的人被处决。约瑟夫斯通过计算算出了最终安全的位置，成为最后活下来的人。
![[file-20261029203412565.png|156]]

## 算法建模与队列设计
使用队列来模拟热土豆问题。
算法接收参加游戏的人名列表 namelist 以及传土豆的次数常数 num，最终返回最后剩下的生还者姓名。
![[file-20261029203427897.png|216]]

设计**不变量**：
采用队列存放所有参加游戏的人名。
按照传递土豆的方向，将人名从队首排到队尾。
在模拟游戏过程中， **队首始终是当前持有土豆的人** 。

单次传递机制：
模拟土豆的传递极其巧妙：无需物理移动“土豆”变量，只需将队首的人出队，随即再将其加入到队尾。
原本排在队首第二位的人自动晋升为新的队首，相当于土豆自然传递到了下一个人手中。

淘汰机制：
连续进行 num 次“出队再入队”的传递后，此时队首的人就是持有土豆且必须被淘汰出局的人。
直接调用 dequeue() 将队首的人移除，不再将其加入队尾。
如此周而复始，直到队列中仅剩下 1 个人（size() == 1）。
![[file-20261029203542992.png|185]]
## Python代码实现
```python
from pythonds.basic.queue import Queue

def hotPotato(namelist, num):
    # 实例化 Queue 类构造器创建模拟队列
    simqueue = Queue()
    
    # 将所有人名逐一加入队列
    for name in namelist:
        simqueue.enqueue(name) # 调用 Queue 对象的 enqueue() 方法
    
    # 淘汰循环：只要队列中人数大于 1，游戏继续
    while simqueue.size() > 1: # 调用 Queue 对象的 size() 方法
        # 循环执行 num 次传递
        for i in range(num):
            # 一次传递：队首出队，立即从队尾入队
            # 嵌套调用 dequeue() 方法与 enqueue() 方法
            simqueue.enqueue(simqueue.dequeue())
        
        # 传递 num 次后，手持土豆的队首者出队淘汰，不再入队
        simqueue.dequeue()
    
    # 返回队列中唯一剩下的生还者人名
    return simqueue.dequeue()

# 测试用例调用
# 传入名单列表与传递步长 7，调用自定义 hotPotato() 函数
winner = hotPotato(["Bill", "David", "Susan", "Jane", "Kent", "Brad"], 7)
print(winner)
```
