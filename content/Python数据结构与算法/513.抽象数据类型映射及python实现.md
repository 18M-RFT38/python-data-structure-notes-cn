# 抽象数据类型“映射”：ADT Map
## 基本概念与结构特征
Python最有用的数据类型之一是 [[6.容器类型#字典|字典]]。
字典是一种可以保存 `key-data` **键值对** 的数据类型，其中关键码 `key` 可用于查询关联的数据值 `data`。
这种键值关联的方法称为 **“映射Map”**。
`ADT Map` 的结构是 **键-值关联的无序集合**。
关键码具有 **唯一性**，通过关键码可以唯一确定一个数据值。
## ADT Map定义的操作
**`Map()` 类（构造器）**：创建一个空映射，返回空映射对象。
**`put(key, val)` 实例方法**：将 `key-val` 关联对加入映射中；如果 `key` 已存在，将 `val` 替换旧关联值。
**`get(key)` 实例方法**：给定 `key`，返回关联的数据值；如不存在，则返回 `None`。
**`del` 语句**：通过 `del map[key]` 的语句形式删除 `key-val` 关联。
**`len()` 内置函数**：返回映射中 `key-val` 关联的数目。
**`in` 运算符**：通过 `key in map` 的语句形式，返回 `key` 是否存在于关联中，结果为布尔值。
# 实现ADT Map
## 核心结构设计：HashTable类
使用一个 `HashTable` **类** [[21.类的定义与调用|类的定义与调用]] 来实现 `ADT Map`，该类包含了两个平行 [[6.容器类型#创建列表|列表]] 作为实例属性成员：
**`slots` 实例属性（列表）**：用于保存 `key`，作为 **散列表** 来处理，这样可以迅速查找到指定的 `key`。
**`data` 实例属性（列表）**：平行的列表，用于保存数据项。
在 `slots` 列表查找到一个 `key` 的位置以后，在 `data` 列表对应 **相同位置** 的数据项即为关联数据。
>[!attention] 散列表大小的选择
>注意散列表的大小，虽然可以是任意数，但考虑到要让冲突解决算法能有效工作，应该选择为 **素数**。
```python
# 定义 HashTable 类实现 ADT Map
class HashTable:
    # 定义 __init__() 构造方法初始化实例对象
    def __init__(self):
        # 设置实例属性 size 为素数 11，表示散列表初始大小
        self.size = 11
        # 初始化实例属性 slots 列表，用于保存 key（初始全为 None）
        self.slots = [None] * self.size
        # 初始化平行的实例属性 data 列表，用于保存数据项（初始全为 None）
        self.data = [None] * self.size
```
## put方法与散列/再散列实现
`hashfunction()` 实例方法采用了 **简单求余方法** 来实现散列函数，而冲突解决则采用 **线性探测“加1”** 再散列函数（即 `rehash()` 实例方法）。
**`put(self, key, data)` 实例方法的三种处理分支**： **`key` 不存在，未冲突**：目标散列槽位为空（`None`），直接写入 `key` 与 `data`。 **`key` 已存在，替换 `val`**：目标散列槽位已存放相同的 `key`，直接用新 `data` 替换原数据。 **散列冲突，再散列**：目标槽位被其他 `key` 占用，调用 `rehash()` 实例方法顺延探测，直到找到 **空槽**（填入新键值）或者找到相同的 **`key`**（替换旧数据）。
```Python
    # 定义散列实例方法：采用简单求余法计算初始散列值
    def hashfunction(self, key):
        # 读取实例属性 size 进行求余运算
        return key % self.size

    # 定义再散列实例方法：采用线性探测“+1”解决散列冲突
    def rehash(self, oldhash):
        # 读取实例属性 size 进行加 1 求余运算
        return (oldhash + 1) % self.size

    # 定义 put() 实例方法：写入或更新键值对
    def put(self, key, data):
        # 调用实例方法 hashfunction() 计算初始散列值
        hashvalue = self.hashfunction(key)

        # 分支1：key不存在，未发生冲突，直接存入对应槽位
        if self.slots[hashvalue] == None:
            self.slots[hashvalue] = key
            self.data[hashvalue] = data
        else:
            # 分支2：key已存在于初始槽位，直接替换 data（replace）
            if self.slots[hashvalue] == key:
                self.data[hashvalue] = data  # replace
            # 分支3：发生散列冲突，调用 rehash() 实例方法再散列探测
            else:
                nextslot = self.rehash(hashvalue)
                # 循环探测：直到找到空槽（None）或者找到相同的 key
                while self.slots[nextslot] != None and \
                      self.slots[nextslot] != key:
                    nextslot = self.rehash(nextslot)

                # 找到空槽，填入新 key 和 data
                if self.slots[nextslot] == None:
                    self.slots[nextslot] = key
                    self.data[nextslot] = data
                # 找到相同的 key，替换旧 data
                else:
                    self.data[nextslot] = data  # replace
```
## get方法实现
**`get(self, key)` 实例方法的查找逻辑**：
**标记查找起点**：调用 `hashfunction()` 实例方法计算散列值并标记为起点 `startslot`。 
**循环探测找 `key`**：当槽位非空、未找到且未停止时持续检索。 **未找到 `key` 的处理**：调用 `rehash()` 实例方法继续找；若 `position` 回到起点 `startslot`，说明已遍历全表，标记 `stop = True` 停止查找。
```Python
    # 定义 get() 实例方法：根据 key 查询关联的 data
    def get(self, key):
        # 调用实例方法 hashfunction() 标记散列值为查找起点
        startslot = self.hashfunction(key)

        data = None
        stop = False
        found = False
        position = startslot
        # 找 key，直到遇到空槽（None）、找到目标或回到起点
        while self.slots[position] != None and \
              not found and not stop:
            # 命中目标 key，提取平行列表 data 对应位置的数据项
            if self.slots[position] == key:
                found = True
                data = self.data[position]
            # 未找到 key，调用实例方法 rehash() 再散列继续找
            else:
                position = self.rehash(position)
                # 回到起点，说明遍历完整个散列表仍未找到，停止循环
                if position == startslot:
                    stop = True
        return data
```
## 附加代码：特殊方法实现 `[]` 访问
通过实现 Python 的特殊方法（魔术方法），使 `HashTable` 实例对象支持字典风格的 `[]` 索引取值与赋值语法：
```Python
    # 定义 __getitem__() 特殊实例方法：实现 H[key] 索引读取访问
    def __getitem__(self, key):
        # 内部调用实例方法 get()
        return self.get(key)

    # 定义 __setitem__() 特殊实例方法：实现 H[key] = data 索引赋值写入
    def __setitem__(self, key, data):
        # 内部调用实例方法 put()
        self.put(key, data)
```

# 散列算法分析
## 复杂度与负载因子 $\lambda$
散列在最好的情况下，可以提供 **$O(1)$ 常数级时间复杂度** 的查找性能。 由于散列冲突的存在，查找比较次数就没有这么简单。 评估散列冲突的最重要信息就是 **负载因子 $\lambda$**： **如果 $\lambda$ 较小**：散列冲突的几率就小，数据项通常会保存在其所属的散列槽中。 **如果 $\lambda$ 较大**：意味着散列表填充较满，冲突会越来越多，冲突解决也越复杂，也就需要更多的比较来找到空槽；如果采用数据链的话，意味着每条链上的数据项增多。
## 平均比对次数公式
### 线性探测的开放定址法（$\lambda$ 在 $0 \sim 1$ 之间）
**成功的查找**，平均需要比对次数为：
$$\frac{1}{2}\left(1 + \frac{1}{1 - \lambda}\right)$$
**不成功的查找**，平均比对次数为：
$$\frac{1}{2}\left(1 + \left(\frac{1}{1 - \lambda}\right)^2\right)$$
### 数据链法解决冲突（$\lambda$ 可大于 $1$）
**成功的查找**，平均需要比对次数为：

$$1 + \frac{\lambda}{2}$$
**不成功的查找**，平均比对次数为：
$$\lambda$$
